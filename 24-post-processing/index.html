01 / 从真值到预测：完整对齐

真值是原本应该存在的字符。删除 D 表示漏识别，插入 I 表示多识别。M 匹配成本为0，S / D / I 各为1。空格会参与比较，前导零和重复字符始终保留。

真值预测操作

∅ 表示缺口，␠ 表示实际空格。字面连字符 “-” 仍是普通字符。颜色之外，每列也显示操作字母与名称。

矩阵与平局规则是怎样对应到代码的？

d[i,j] 表示真值前 i 个字符变成预测前 j 个字符的最少编辑数。第一行是插入次数，第一列是删除次数。每格比较左上角 + 匹配/替换成本、上方 +1、左方 +1。

d[i,j] = min(d[i−1,j−1] + [truth[i−1] ≠ prediction[j−1]], d[i−1,j]+1, d[i,j−1]+1)

右下角给出距离。回溯从右下角走向左上角，平局按 M → S → D → I。12 → 21 有不止一种最短路径，本模块固定选择两次替换。这保证可复现，却不能证明照片里究竟发生了哪种物理错误。

核心算法与矩阵均来自 shared/24-post-processing。码点不是字素簇：组合重音可能包含多个码点，数字0–9没有这种歧义。

            CER、整串正确率与 WER 有什么区别？
            
microCER = Σ(S+D+I) / Σ真实字符数。两图分别为 12 → 12 和 1203 → 123 时，microCER为1/6，整串正确率为1/2。每图CER直接平均得到1/8，是另一种加权方式。

            
WER先约定切词，再用相同的编辑对齐：read the book → read book 漏1个词，WER = 。本章按空白分词；中文切词需要额外规则。不带空格的一整串数字会被当成一个词，WER难以解释漏了几个数字。

            
1 → 1111 多3个字符，CER为300%；不能截成100%，也不能把1−CER当作通用准确率。无有效样本时显示“无分母”，不会显示0%错误。

调整α会同时改变分子与分母。α较大时各词概率趋近1/V；降低零频率风险的同时，也削弱已见计数差异。历史未见时落入未知词桶。

N-gram、平滑与限制
            
Bigram只保留前一个词作为历史。Add-one概率为 (C(h,w)+1)/(C(h)+V)。本例V=7（五个普通词、结束符、未知词），the后book计数2、back计数1，总计3，因此概率分别为3/10和2/10。

            
这个实验没有图像证据、真实OCR混淆矩阵、右侧上下文、Beam Search或完整句子解码。分数只是排序值。任意数字没有可依赖的自然语言词频先验；不能去掉前导零、合并重复数字或根据答案补字。

自测1：00110 → 0110的CER与整串正确率？
删除一次，CER=1/5=20%；整串不完全一致，该图正确率为0。重复0的具体缺口位置由回溯平局规则决定。

        
自测2：为什么失败空预测不能从分母删除？
它是对有效输入的识别失败。305 → 空串应计3次删除；剔除会选择性隐去困难样本，改变端到端口径。

        
自测3：置信度0.99，是否说明99%的现场照片能识别正确？
不能。单次模型得分没有替代真实标签评估，模型还可能未校准或遇到分布变化。准确率需要独立有标签照片和明确分母。

        
自测4：没有任何标签时CER应显示什么？
null / 无分母。它既不代表0%错误，也不代表100%正确；仍显示总数、待标注数和排除数。
