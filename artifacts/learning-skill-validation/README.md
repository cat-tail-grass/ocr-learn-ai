## 2026-09-18：补齐逐章委派约束

根据使用者的补充要求，现规定：主会话先完成大纲和教学安排，保存单章 tasks 任务单，向独立上下文的章节子代理提供必要材料；一次生成一章；子代理回报后，由主会话读取实际产物验收、退回修订或推进下一章。每批交付几章不改变逐章串行的执行方式。

[逐章委派协议](../../skills/build-learning-course/references/chapter-delegation.md)明确了上下文内容、文件边界、回报字段、状态维护和中断后的继续方式。子代理可以交回 draft，由主会话决定 verified；使用者校准保持独立。初始化器同时生成 tasks 目录和分工说明。缺少子代理能力时先交付大纲与任务单，只有使用者明确接受才改由主会话生成。

更新后重新运行12项运行回归和技能格式检查，均通过。独立子代理只读审查发现：已验收章节返修前应先撤回旧验收状态；现已补明主会话在派发前将 verified 改回 draft，复验后恢复。该审查覆盖了初始化、大纲、任务单、回报、验收、串行推进和中断恢复的指令一致性，没有执行真实章节生成。下文两个学科样本是2026-09-17版的迁移验证，保留原始记录；它们不能充当这次新增任务单与逐章委派协议的端到端行为验证。

| 阶段路线、目录、搜索、公式、阅读位置和实验入口 | 随包提供实际站点代码，课程目录和入口由 course.json 配置，无需原 OCR 仓库 |

## 实测发现并修复的问题

1. **从符号链接路径启动时可能静默退出。** macOS 临时目录可有两种路径表示，原入口判断可能无法识别主程序。已改为比较实际路径，新增真实回归，并从解压后的包重新运行验证。
2. **待生成章节的目录行挤在一起。** 这些行使用非链接元素，原样式仅覆盖链接。已将布局应用到所有章节行，保留链接才有的悬停效果。
3. **英语纠错题存在语境歧义。** `read` 的书面形式也可能表示过去时，不应脱离语境直接判错。试用样本改用 `drink/drinks`，并明确“现在每晚的习惯”。这是具体题目的修正，没有扩成所有学科都要遵守的额外规则。

数学样本另修正了表格中绝对值竖线的转义，以及将直线精确预测误称为有误差近似的表述；已复验表格列数与数值。首轮浏览器检查中还发现两处等待/可见性假设错误，修正的是检查脚本，原失败记录保留在样本审查目录中。

## 结论的适用范围

本次验收覆盖技能包、阅读站运行，以及两个主题的一节标杆。尚未进行整套课程连续生成、真实学习者效果测试、领域专家评审，也未验证所有宿主工具、模型和浏览器。英语的开放表达采用参考尺度自评，不宣称程序能够判定所有语义、口语或发音问题。

“开箱即用”在这里指完整技能目录已包含教学规则、站点模板、初始化与检查工具；首次构建仍需要 Node.js 和联网安装依赖。模型负责按流程完成内容、验证和修订。用户对标杆的认可是一项真实的输入，不能由生成器自行宣布完成。
