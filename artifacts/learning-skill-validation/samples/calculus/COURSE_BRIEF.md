# 学习目标与约定

## 已知基础与可验收终点

使用者自述：会基础代数，知道函数和坐标，尚未学过极限。授课语言为中文，每周投入 3 小时。默认具备带符号四则运算、代入、平方展开的经验；标杆仍将这些关键步骤写出，未知熟练程度不记为已经掌握。

学习终点是：面对简单函数，能说明“在哪一点、哪个量相对哪个量变化”，求出导数并解释它作为瞬时变化率的意义，而不是只写一个公式。

完成课程的可观察能力：

1. 给定函数、位置和非零增量，正确列出并计算差商，说明单位。
2. 用左右两侧趋近解释极限；知道有限张数表不能替代一般性理由。
3. 从定义求平方、立方、常数、一次函数的导数，并运用和与常数倍规则求三次以内多项式的导数。
4. 从定义理解倒数和平方根的导数，写明定义域；本课只验收 `1/x` 的 `x≠0` 和 `√x` 的 `x>0`。
5. 区分函数值、某点导数与导函数；用导数给出切线或小增量的近似并检查近似误差。
6. 以 `|x|` 在 0 的左右差商说明不可导，不把画得光滑或数值看似稳定当作证明。

## 范围与取舍

计划 8 周，每周 3 小时，合计约 24 小时。它是可调整的学习安排，不是掌握保证；如果作答暴露前置缺口，优先用下周时间补练。

纳入：平均变化率、割线、有限极限的直觉和左右两侧、导数定义、导函数、三次以内多项式、`1/x`、`√x`、绝对值尖点、切线和局部近似、量纲和解释。

不纳入：积分、级数、多变量、微分方程、三角/指数/对数求导、一般乘积/商/链式法则、完整的极限严格证明体系。这些知识可在达到当前终点后另开路线，不影响本课的验收目标。

## 节奏与交付状态

每周建议三次各 60 分钟：第一次读例题并手算；第二次操作、对照与解释；第三次独立作答、订正与复述。正式路线逐章推进，阶段任务用于判断是否需要补练。

首次只准备完整路线与第 03 章标杆。第 01、02 章仍待准备；标杆提供自足的前置补给，不假定它们已经交付或学会。其他计划章节的 `web/node=false` 表示目前没有实际入口，日后按学习作用增加并登记。
