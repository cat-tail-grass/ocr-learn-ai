## 这门课的边界

完成后，你应能用差商解释一点的导数，求三次以内多项式、倒数函数和平方根函数在适用位置的导数，写出单位和局部变化的含义，识别尖点等不可导情形。

本轮不包含积分、无穷级数、多元微积分、微分方程，也不要求背完整求导表或掌握严格的极限证明。它是围绕你当前终点的一元微积分导数课程。

## 本地打开与复算

在项目目录使用 Node.js 22.18.0 或更新版本。第一次安装依赖后启动：

```sh
npm install
SITE_PORT=4317 npm run dev
```

打开 http://127.0.0.1:4317/。讲义保存后更新，实验修改后刷新网页；目录配置变更后重启服务。

```sh
npm run check
npm run check:examples
npm run build
SITE_PORT=4317 npm run preview
```

开发服务与静态预览共用 4317 端口，先关闭其中一个再启动另一个。交付时使用构建后的静态预览。后续重新安装可用 `npm ci`；仓库保留锁文件。
