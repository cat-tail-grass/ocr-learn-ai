## 问题、修订与复验

1. 作者写入 Markdown 表格时，绝对值表达式的竖线需要转义。已修正对应两份讲义；浏览器实际检查表格列数和 `|h|/h` 内容，确认未再拆列。这是内容编排修正，未改技能包。
2. 复核网页解释时，将“非零增量下这是近似”改成逐次比较预测与真实变化，避免把直线上的精确结果也误称为有误差的近似。数字格式仅把实际 0 显示成 0，避免将极小非零值强行显示为 0。
3. 首轮浏览器检查为 8/10 组通过，原始失败报告保留在 `browser-validation-first.json`。一项在 Vue 路由 URL 已改变但正文尚未更新时过早断言；另一项误用宽屏隐藏的移动目录入口。检查脚本改为等路线标题出现，并在宽屏使用可见的右侧目录后，10/10 组实际通过。这两项是检查脚本的错误假设，没有把失败隐藏或归为页面缺陷。
4. 收到上层通知后，从当前技能包同步了 course-config.mjs、check-course.mjs、site.mjs 的入口识别修复，以及默认 course.css 的待准备章节布局修复。本课程没有亲自触发原先的符号链接启动缺陷，故不报告为本课复现的问题。没有编辑技能包。
