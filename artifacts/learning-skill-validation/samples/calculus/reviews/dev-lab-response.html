动手理解 · 第 03 章标杆

从割线到一点的导数

保留一个非零增量，观察平均变化率如何从左右两侧接近。先预测数字，再改变输入；代数理由决定导数，图与表帮助你看见过程。

输入与操作

−3 ≤ a ≤ 3；0.000001 ≤ |h| ≤ 2。h > 0 在右侧，h < 0 在左侧。图像范围会随输入调整。

平方函数导数来自讲义中的展开与约去；本页没有用“最小步长的差商”冒充精确导数。

    试一试，再解释

    1. 默认例子 a=2、h=0.5 的差商为何是 4.5，而导数是 4？依次写出 4、6.25 和 2.25 的含义。
    2. 把 h 改为 0.1，再从另一侧观察。预测 4.1 与 3.9，然后核对。缩小增量时，两侧差商靠近谁？
    3. 设 a=1、h=0.5，在平方与直线之间切换。为什么直线的差商不随增量改变？
    4. 观察尖点预设，解释左右的 1 和 −1 为什么不能取平均后充当导数。再试 h=0，读懂错误反馈后恢复初始例子。
    完成后查看判断依据

    默认输出变化为 6.25−4=2.25，除以 0.5 得 4.5；平方函数在 a=2 的一般差商为 4+h，其极限为 4。a=1 时平方差商为 2+h，而直线 2x+1 的差商恒为 2。绝对值在 0 的两侧差商固定为 −1 和 1，没有共同极限；零增量不能用于差商除法。
