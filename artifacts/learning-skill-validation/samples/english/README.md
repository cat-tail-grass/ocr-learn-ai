# 说清日常与眼下 · 英语起步课

**6 周、每周 3 小时，把基础单词连成有清楚含义的日常表达。** 中文讲解，英语例句；每周分三次，每次 60 分钟。

课程终点是一次 6–8 句的生活分享和 4 轮简短问答，并能解释表达选择的含义差别。课程不要求学习编程。

## 从这里开始

本次已交付完整路线和第 1 章标杆课。先读 [平时还是眼下：两种现在时](01-routine-and-now/README.md)，再打开该章网页练习，体验表达对照、情境选句、补全纠错和自由表达自评。

**标杆课待之后校准。** 第 2–6 章目前是路线，显示“待准备”；材料检查通过不代表你已掌握。

## 每周怎么学

1. 第一次 60 分钟：读情境示范，遮住答案复述，再改变一个条件。
2. 第二次 60 分钟：操作网页练习，记录“我想说什么、我写了什么、听者会怎样理解”。
3. 第三次 60 分钟：自测、核对理由，完成自己的生活表达，隔一天再口头说一次。

口头练习可以独自进行；本次不提供语音识别或发音评分。网页不上传作答，自由表达可下载到自己的设备。
