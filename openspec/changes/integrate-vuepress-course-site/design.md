## Context

现有26章以README、HTML、Node三件套交付；课程正文约1.29万行，包含公式、手算、代码、自测和参考资料。22个browser.js由esbuild打包，11–13直接加载共享脚本；17/20/25依赖本地模型与样例，25/26通过同源localStorage传递记录。

用户已确定VuePress整合方向，并要求子代理执行局部模块、主代理协调和最终完成。本变更只建立新的实施契约；旧课程任务已归档，实拍待办单独保留。完整方案为`docs/VUEPRESS_INTEGRATION_PLAN.md`。

## Goals / Non-Goals

### Goals

- 26章完整正文持续从原README生成，提供连续阅读、章节内定位、搜索及实验入口。
- 文档与实验产出为同一可预览和部署的静态站点，根路径和子目录均可用。
- 通过有限上下文、明确接口、互斥写入、独立验收及主代理审查控制集成质量。
- 保持课程三件套、Node运行、模型推理、训练桥说明和评估记录语义。

### Non-Goals

- 账户、评论、打卡、浏览器内Node执行或在线编辑。
- 全部实验改写为Vue组件、重新训练冻结模型、调整OCR算法以提高演示分数。
- 实拍采集、未见照片预演和托管平台发布；前两项继续记在实拍待办中。

## Decisions

### 1. 原文件作为内容源

VuePress的sourceDir使用项目根目录，`pagePatterns`显式选择首页、26章README和辅助阅读文档。通过课程目录配置生成标题/编号/阶段、sidebar、prev/next与实验入口；不创建第二套手工维护的正文。附录不进入01→26的章节链。

页面读取原始路径，使用页面扩展注入元信息；链接转换作用于Markdown节点，不能全局替换代码块中的路径或表达式。原始理论、数值、自测和来源保持完整。

### 2. 主题、公式与搜索

VuePress 2 + Vite +官方默认主题，少量布局扩展提供章首操作、本章目录及排版。公式使用KaTeX和markdown-math，启用bracket/dollar两种分隔符；搜索使用SlimSearch并索引正文，验证中英文术语。

依赖实际安装时检查peerDependencies和Node engine，锁定可用的核心/主题/插件组合。当前核验VuePress next为2.0.0-rc.31、Node要求≥22.18.0，仓库Node 24符合；RC升级须重新验证。VuePress及新增工具用`.mjs`，根package不改为`type: module`，保留CommonJS示例。

### 3. 文档与实验地址

| 用途 | 不含base的地址 |
|---|---|
| 第N章阅读 | `/<chapter>/` |
| 第N章实验 | `/labs/<chapter>/index.html` |
| 实验共享脚本 | `/labs/shared/...` |
| 模型与样例 | `/labs/<所属章节>/...` |

实验默认以普通HTML链接新标签打开，实验顶部能返回对应阅读页。所有路径从同一`base`与目录契约生成；VuePress辅助方法仅用于文档侧，静态HTML和bundle中的硬编码路径也必须适配。

### 4. 静态资源与构建

显式清单描述实际实验依赖，包括HTML、bundle、公共样式/UMD脚本、模型与样例；保持`labs/`内部相对目录关系。完整数据下载缓存和无关构建日志不随站点输出。

构建顺序为实验打包→资源装配→VuePress构建，任一阶段失败停止。开发监听README及实验源码，实验变动重新构建相关bundle并同步资源。`npm run preview`针对最终dist验证；默认使用127.0.0.1:4173，兼容现有训练桥来源。

17章训练桥仍是本机服务。验证桥接来源、配置和数据接口，不为验收站点而重训或覆盖已保存模型。25/26保持同源与原存储键；换域名/端口通过现有JSON导入导出迁移记录。

### 5. 先定接口再并行

主代理在实现任务1.x中完成并记录下列契约，相关修改须经主代理协调后同步给消费者：

| 契约 | 必需内容 |
|---|---|
| 课程目录 | `id`、`slug`、`stage`、`source`；标题从README提取；01–26顺序唯一 |
| 页面元信息 | `courseId`、`chapterTitle`、`docPath`、`labPath`、`nodeCommand`、`prev`、`next` |
| 页面组件 | A消费元信息；C消费页面路径和内容；主代理在config/client中注册 |
| 地址解析 | 文档路径、labs路径、base合成、返回入口和固定localhost地址替换规则 |
| 资源装配 | 清单输入、public输出、缺资源报错、构建/监听生命周期 |
| 验收证据 | 模块报告目录、验证命令、退出状态、截图/输出、阻塞与待办 |

### 6. 子代理和主代理的写入范围

| 角色 | 责任与独占写入范围 |
|---|---|
| 主代理 | package.json/lockfile、`.vuepress/config.mjs`、client/catalog、页面元信息插件、全局文档/OpenSpec；冻结接口、派发、审查、合并和总体验收 |
| A 布局导航 | `.vuepress/components/**`、`.vuepress/styles/**`；阶段目录、章首入口、上下章呈现、本章目录与响应式排版 |
| B 实验资源 | 显式实验资源清单、prepare-labs/dev-site/build-site脚本、`shared/course.js`及经派发的实验路径适配；打包、base与返回入口 |
| C 正文与搜索 | Markdown链接/兼容插件、搜索相关配置模块；有边界的原README格式修正，不重写已复核理论 |
| D 独立验收 | 站点浏览器/集成验证脚本及自己的报告；检查A/B/C结果，不同时改写它们正在实现的文件 |

每个代理另有独立模块报告路径。B的具体实验文件列表、C的README列表、各自测试文件名在派发时由主代理明确，不授予笼统的全仓编辑范围。发现范围外问题先报告，主代理重新分配或在模块结束后集成修正。

采用子代理工具和小上下文任务，默认`fork_context: false`；不给子代理复制整段历史。多个角色可处于同一共享工作区，不能假设自动存在独立worktree。共享工作区以文件所有权约束并行写入；需要隔离时由主代理显式创建并管理工作区，保留用户既有未提交成果。

### 7. 派发上下文与结果协议

每次派发必须包含目标、需求编号、依赖版本、最少必要文件、接口和路径约定、独占写范围、保护的产物、所需验证及报告位置。子代理只加载与任务相关的内容；接口依赖不足时向主代理报告，主代理补充决定后继续。

交付需列出：完成的需求/任务、改动文件、关键决定与接口、实际运行的验证及结果、已知限制/未决项。阶段消息不是最终验收证据。主代理查看diff并核对证据后，才能更新任务状态。

A/B/C在公共契约可用后并行；D可先准备验收用例，主代理接入代表章并修复接口问题后，D对整合站点独立执行验收。D发现的问题退回责任模块修复，复验后主代理负责最终汇总。

子代理异常、额度或上下文限制时需尽可能留下阶段结果；主代理保持相关任务未完成，及时关闭无用代理并将剩余工作重新拆分。确需主代理接管时登记范围与原因，不用“已派发”或“进程结束”代替完成。

## Risks / Trade-offs

- 独立HTML保留完整实验上下文和画布空间，同时需要明确资源清单、返回路径和同源配置；代表章先验证这些依赖。
- VuePress的Vue模板编译与原Markdown有语法差异，需实际检查公式、代码字面量与details；修复以格式兼容为边界。
- 并行只减少单个上下文的范围；正确性仍由接口、独立检查和主代理验收提供，不能因为分了子进程就宣称质量已保证。
- 现有工作区有未提交的完整课程；主代理在派发前记录基线，不提交、回滚或覆盖无关成果。
- 更换来源会改变localStorage可见范围，保持25/26同源并验证JSON导入导出；不将合成流程验证称为实拍成绩。

5. 主代理运行必要回归、核对模型/记录语义和材料完整性，更新指南、报告和OpenSpec实际进度。
