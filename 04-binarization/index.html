⚫⚪ 04. 二值化 (Binarization)

📚 什么是二值化？

二值化将灰度图像（256级灰度）转换为只有黑（0）和白（255）两种颜色的图像。 这是 OCR 预处理的关键步骤，用于明确分离文字（前景）和背景。

// 二值化核心逻辑 if (grayValue >= threshold) { pixel = 255; // 白色（背景） } else { pixel = 0; // 黑色（文字） }

📖 Otsu 算法原理

/** * Otsu 算法 - 自动计算最佳阈值 * * 核心思想：找到使类间方差最大的阈值 * 类间方差 = w0 × w1 × (μ0 - μ1)² * * w0, w1 = 前景和背景的像素比例 * μ0, μ1 = 前景和背景的平均灰度值 */ function calculateOtsuThreshold(histogram) { const total = histogram.reduce((a, b) => a + b, 0); let sum = 0; for (let i = 0; i < 256; i++) { sum += i * histogram[i]; } let sumB = 0, wB = 0, wF = 0; let maxVariance = 0, threshold = 0; for (let t = 0; t < 256; t++) { wB += histogram[t]; // 前景权重 if (wB === 0) continue; wF = total - wB; // 背景权重 if (wF === 0) break; sumB += t * histogram[t]; const mB = sumB / wB; // 前景均值 const mF = (sum - sumB) / wF; // 背景均值 // 类间方差 const variance = wB * wF * (mB - mF) * (mB - mF); if (variance > maxVariance) { maxVariance = variance; threshold = t; } } return threshold; }

📖 自适应阈值原理

🔧 为什么需要自适应阈值？

全局阈值（固定/Otsu）对光照不均的图像效果不佳。自适应阈值为每个像素单独计算阈值， 基于其局部邻域的均值动态调整，能有效处理阴影、渐变背景等问题。

参数影响

blockSize
邻域大小（奇数）
推荐 11-31
C
常数偏移量
推荐 2-10
mean - C
局部阈值公式
/** * 自适应阈值二值化 * * 核心思想：每个像素的阈值 = 邻域均值 - 常数C * * 适用场景： * - 光照不均匀的图像 * - 有阴影或渐变背景的文档 * - 扫描质量不佳的文档 */ function binarizeAdaptive(imageData, blockSize, C) { const { width, height, data } = imageData; const halfBlock = Math.floor(blockSize / 2); for (let y = 0; y < height; y++) { for (let x = 0; x < width; x++) { // Step 1: 计算邻域均值 let sum = 0, count = 0; for (let dy = -halfBlock; dy <= halfBlock; dy++) { for (let dx = -halfBlock; dx <= halfBlock; dx++) { const nx = x + dx, ny = y + dy; if (nx >= 0 && nx < width && ny >= 0 && ny < height) { sum += data[(ny * width + nx) * 4]; count++; } } } const mean = sum / count; // Step 2: 计算局部阈值并二值化 const threshold = mean - C; const idx = (y * width + x) * 4; const binary = data[idx] >= threshold ? 255 : 0; result[idx] = result[idx + 1] = result[idx + 2] = binary; } } }
