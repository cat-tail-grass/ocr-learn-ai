## 核心概念

### 1. 什么是二值化？

二值化将灰度图像转换为只有**黑（0）和白（255）**两种颜色的图像。

```
灰度图像（256级）         二值图像（2级）
┌─────────────────┐      ┌─────────────┐
│ 0-255 连续灰度  │  →   │ 只有 0 或 255│
└─────────────────┘      └─────────────┘

转换规则：
if (gray >= threshold)
    pixel = 255 (白色/背景)
else
    pixel = 0   (黑色/文字)
```

### 2. 为什么要二值化？

| 原因 | 说明 |
|------|------|
| **简化数据** | 从 256 级简化为 2 级，计算量大减 |
| **分离前景背景** | 明确区分文字（前景）和背景 |
| **便于后续处理** | 连通域分析、形态学操作都需要二值图 |
| **减少噪声影响** | 排除中间灰度级的干扰 |

### 3. 阈值的选择

阈值（Threshold）是分界点，决定哪些像素变白、哪些变黑。

```
灰度值:  0 ─────────── threshold ─────────── 255
         黑色区域(文字)     ↑     白色区域(背景)
                        分界点
```

**阈值选择的挑战**：
- 阈值过高 → 文字变细甚至断裂
- 阈值过低 → 文字变粗，背景噪声增多

### 4. 三种二值化方法

#### 方法一：固定阈值 (Fixed Threshold)

手动指定一个固定的阈值（如 128）。

```javascript
threshold = 128;  // 手动设定
if (gray >= threshold) pixel = 255;
else pixel = 0;
```

**优点**：简单快速  
**缺点**：需要人工调整，不适应光照变化

#### 方法二：Otsu 算法 (大津算法) ⭐ 重点

自动计算最佳阈值，基于**类间方差最大化**原理。

```
原理：找到一个阈值，使得：
- 前景像素（< threshold）的均值与整体均值的差距
- 背景像素（≥ threshold）的均值与整体均值的差距
这两部分的加权方差之和最大
```

**优点**：自动化，效果通常很好  
**缺点**：假设直方图是双峰分布

#### 方法三：自适应阈值 (Adaptive Threshold)

每个像素的阈值根据其**局部邻域**动态计算。

```
对于位置 (x, y) 的像素：
threshold(x,y) = mean(邻域) - C
```

**优点**：处理光照不均的图像效果好  
**缺点**：计算量较大

## Otsu 算法详解

### 数学原理

设图像有 L 个灰度级（0 到 L-1），总像素数为 N。

1. **计算每个灰度值的概率**：`p(i) = n(i) / N`

2. **遍历所有可能的阈值 t**：
   - 前景权重：`w0(t) = Σp(i)` (i < t)
   - 背景权重：`w1(t) = Σp(i)` (i ≥ t)
   - 前景均值：`μ0(t) = Σ(i × p(i)) / w0(t)`
   - 背景均值：`μ1(t) = Σ(i × p(i)) / w1(t)`
   - 类间方差：`σ²(t) = w0 × w1 × (μ0 - μ1)²`

3. **选择使 σ²(t) 最大的 t 作为最佳阈值**

### 直观理解

```
直方图：

频率
 │     ▓▓                ▓▓
 │    ▓▓▓▓              ▓▓▓▓
 │   ▓▓▓▓▓▓            ▓▓▓▓▓▓
 │  ▓▓▓▓▓▓▓▓          ▓▓▓▓▓▓▓▓
 └────────────────────────────── 灰度值
    前景(文字)  ↑    背景(纸张)
            Otsu阈值
            (双峰之间的谷)
```

Otsu 算法寻找的是使两个峰分离最好的阈值。

## 与 OCR 的关联

二值化是 OCR 预处理的核心步骤：

```
彩色图 → 灰度图 → [二值图] → 去噪 → 文字检测 → 文字识别
                    ↑
                 当前学习
```

| 影响 | 说明 |
|------|------|
| 文字清晰度 | 阈值合适时文字边缘清晰 |
| 噪声控制 | 不当的阈值会引入噪点 |
| 后续处理 | 连通域分析、形态学操作都依赖二值图 |
