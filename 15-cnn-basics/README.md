## 1. 从滤波到卷积层：同一个窗口计算，更丰富的表示

### 动机与直觉

如果把28×28灰度图直接交给全连接层，每个输出都能连接全部784个像素。图像中相邻像素往往共同构成局部笔画，而且同一种笔画可能出现在不同位置。卷积层把这两个假设编码进结构：一次只看局部窗口，在不同位置用同一套权重寻找相同模式。

这种预先写进结构的假设叫“归纳偏置”：我们认为局部笔画和重复出现的形状值得优先考虑。它减少了需要学的参数，但也限制了每层能直接连接的位置；不是所有图像问题都必须采用这种结构。

### 卷积与互相关的精确定义

离散一维数学卷积常写成 `Y[t]=Σᵤ K[u]X[t−u]`。滑窗实现它时需相对于互相关翻转核。深度学习库的常规二维卷积使用**不翻核的互相关**，本章与该约定一致。官方 [`Conv2d`](https://docs.pytorch.org/docs/2.14/generated/torch.nn.Conv2d.html) 明确给出跨输入通道的互相关定义。

先看单通道、stride1、无填充：

```text
Y[y,x] = b + Σky Σkx K[ky,kx] × X[y+ky,x+kx]
```

X 是输入数值矩阵，K 是卷积核里的权重，Y 是输出；b 是最后加一次的偏置，本节算例取 0。y、x 是输出的行列位置，ky、kx 是核内的行列位置。Σ 表示把核内所有位置的乘积相加。

下面把核放在输入左上角：它只盖住 `[1,2;4,5]` 这四个数。对应乘以核里的 `[1,2;3,4]` 再相加，得到左上输出；向右移动一格，就计算下一个输出。

### 用非对称核手算，才能看出翻核差异

```text
X = [1 2 3]       K = [1 2]
    [4 5 6]           [3 4]
    [7 8 9]

Y[0,0] = 1×1 + 2×2 + 4×3 + 5×4 = 37
Y[0,1] = 2×1 + 3×2 + 5×3 + 6×4 = 47
Y[1,0] = 4×1 + 5×2 + 7×3 + 8×4 = 67
Y[1,1] = 5×1 + 6×2 + 8×3 + 9×4 = 77
```

若先把K翻转180°成 `[4,3;2,1]`，左上输出为23，不是37。第05章常用的对称均值/高斯核无法暴露这个差异，因此不能拿对称核作为翻核约定的测试。

### 实现与边界

`conv2d` 在共享模块中按“输出通道→输出行→输出列→输入通道→核行→核列”逐层循环。输入窗口超出图像时按零处理。输出保留负值与小数，不能用 `Uint8ClampedArray` 存特征图，否则负响应会被提前截断。

核越大，一次看到的区域越大，计算和参数也更多；小核叠加可以扩大感受野并穿插非线性。固定去噪核通常按先验设计，本章教学核也手工设计；可训练CNN的权重则通过目标损失学习，不能看到“卷积”二字就认为它已经学到了字符特征。

## 2. 多通道：一个输出滤波器不是一张二维小纸片

### 形状与内存约定

第 01 章的 RGBA 把一个像素的四个数放在一起。这里换成适合看卷积的**多张数值平面**：每个通道是一整张二维矩阵，先存完一个通道，再存下一个。这个顺序叫 CHW，C 是通道数，H 是高，W 是宽。

CNN 中“通道”不总是颜色。输入 RGB 的三个通道表示颜色；中间层的多个通道表示不同滤波器算出的响应。Alpha 也不会自动成为 CNN 的第四个输入通道，要按模型的输入处理规则决定。

本章一次只算一张图，因此没有 batch（批次）轴。为区分进入与离开卷积层的通道，分别写 Cin（输入通道数）和 Cout（输出通道数）；Kh、Kw 是核的高、宽。



| 对象 | 形状 | 含义 |
|---|---|---|
| 输入 X | `[Cin,H,W]` | 输入通道、高、宽 |
| 权重 K | `[Cout,Cin,Kh,Kw]` | 输出通道、输入通道、核高、核宽 |
| 偏置 b | `[Cout]` | 每个输出通道一个偏置 |
| 输出 Y | `[Cout,Hout,Wout]` | 输出通道、高、宽 |

一个输出滤波器的完整形状是 `[Cin,Kh,Kw]`，不是只有 `[Kh,Kw]`。它对所有输入通道分别做互相关后相加，产生一张特征图。`Cout` 个这样的滤波器产生 `Cout` 张特征图。普通卷积下输出通道数由滤波器个数决定，与RGB的3没有必须相等的关系。

```text
Y[o,y,x] = b[o] + Σc Σky Σkx K[o,c,ky,kx] × X[c,y+ky,x+kx]
```

公式中的 o 选第几个输出通道，c 遍历所有输入通道。看下节的例子时，固定 o=0，先分别算两个输入通道的贡献，再加起来得到**同一个输出位置**，不要把两项贡献误当成两张输出图。

程序把上面的多维表存成一维数组。iy、ix 是已经换算好的输入行列坐标，Hout、Wout 是输出的高宽；以下索引依次跳过完整通道、完整行，再找到列：

```javascript
const inputIndex = (c * H + iy) * W + ix;
const kernelIndex = ((o * Cin + c) * Kh + ky) * Kw + kx;
const outputIndex = (o * Hout + y) * Wout + x;
```

框架也可能使用NHWC或NCHW。N是batch，H/W/C是相同概念但排列不同；转换需要移动元素，不能只改shape标记。

### 两通道手算

```text
X的通道0         X的通道1
[1 2 3]          [1 1 1]
[4 5 6]          [1 1 1]
[7 8 9]          [1 1 1]

K[输出0,输入0]   K[输出0,输入1]
[1  0]           [1 1]
[0 −1]           [1 1]
```

偏置为0.5，左上输出：

```text
通道0贡献：1×1 + 2×0 + 4×0 + 5×(−1) = −4
通道1贡献：1+1+1+1=4
Y[0,0,0]=−4+4+0.5=0.5
```

其余三个位置也是0.5，因此最终形状为 `[1,2,2]`。若给两个输入通道各加一次偏置，结果会错误地变成1。

浏览器可将输入通道数从1改成2。第二通道全1，其核切片全为1/9；完整3×3窗口的贡献恰好为1。这样能直接看到“新增通道贡献相加”，而不是只看shape变化。

### 实现步骤、参数影响与局限

1. 验证输入通道数等于核的第二维。
2. 固定一个输出o和空间位置y/x，把累加器初始化为b[o]。
3. 遍历全部输入通道，分别累加窗口乘积。
4. 写入一个Y[o,y,x]；不要保留一个额外的输入通道轴。

输入通道增加，普通卷积每个输出滤波器的参数和乘加随之线性增加。输出通道增加，则特征图、参数与乘加也线性增加。1×1卷积仍然能够混合通道；它不混合邻接空间位置。分组卷积、深度可分离卷积改变了通道连接规则，本章未实现，不能把这里的参数公式直接套到这些变体。

## 3. stride 与 padding：把形状公式从滑窗边界推出来

### 步幅为什么存在

stride控制窗口移动多少格。stride1逐位置扫描；stride2只在每隔一格的起点计算，能够减少空间尺寸和计算量，也可能跳过细节。padding在边缘外补值，让核能覆盖原图边缘，并控制输出大小。

本章支持高宽分别设置：stride=`[Sh,Sw]` 中 Sh 是竖直步幅、Sw 是水平步幅；padding=`[Ph,Pw]` 中 Ph 是顶部和底部**各补的行数**，Pw 是左边和右边**各补的列数**。补入的数都是 0。

例如 `[Ph,Pw]=[1,2]` 会让总高度增加 2、总宽度增加 4。下面先用普通连续核和全部通道连接；代码中对应 dilation=1、groups=1，意思是核元素间不留空隙，也不把输入通道拆成独立组。

### 推导输出高度

填充后高度是 `H+2Ph`。第y个输出窗口的顶部在填充图上的 `ySh`，最下面的元素位置为 `ySh+Kh−1`，必须满足：

```text
ySh + Kh − 1 ≤ H + 2Ph − 1
y ≤ (H+2Ph−Kh)/Sh
```

y从0开始取整数，因此数量是：

```text
Hout = floor((H+2Ph−Kh)/Sh)+1
Wout = floor((W+2Pw−Kw)/Sw)+1
```

有效输出需两者都大于0。更一般带膨胀卷积时核的有效尺寸是 `D(K−1)+1`，但本章参数中没有dilation选项。

### 数值对照

输入仍为 `[1,2,3;4,5,6;7,8,9]`，核2×2且全部为1，不加偏置：

| S | P | Hout×Wout | 实际输出 | 观察 |
|---:|---:|---|---|---|
| 1 | 0 | 2×2 | `[12,16;24,28]` | 每个完整窗口 |
| 2 | 0 | 1×1 | `[12]` | 末端不足一个步幅的窗口丢弃 |
| 2 | 1 | 2×2 | `[1,5;11,28]` | 边缘窗口包含补零 |

最后一行左上窗口是 `[0,0;0,1]`，输出1；右上是 `[0,0;2,3]`，输出5。坐标映射必须扣掉padding：

```javascript
const iy = y * Sh + ky - Ph;
const ix = x * Sw + kx - Pw;
```

### VALID、SAME 与实现范围

VALID对应不填充。常见SAME在stride1且奇数核时，可由 `P=(K−1)/2` 保持尺寸；但不能笼统说“same就是加一圈0”。stride>1时，框架的SAME通常根据目标输出大小计算所需填充，并可能不对称。例如H=6、K=3、S=2，目标高度ceil(6/2)=3，总需1行填充，本章的对称P无法精确表示这种上下不等的方案。

本模块只接受数值padding，不支持字符串 `same`。边界零值可能使窗口响应偏低，还会引入与位置有关的信息。可在浏览器把笔画移到边缘，对比P0/P1；填充可以保留尺寸，但不会凭空恢复图外真实笔画。

## 4. 参数共享、感受野与计算量

### 共享什么，为什么能节省参数

局部连接先限制每个输出只连接 `CinKhKw` 个输入；参数共享再要求同一输出通道的所有空间位置使用**同一个核和偏置**。位置越多，参数被使用的次数越多，参数本身不增加。

例如一个灰度输入、一个 3×3 核，无论它在图上滑动多少次，都只是重复使用 9 个核权重和 1 个偏置。换一个输出通道，才需要另一套权重。把输出通道数推广为 Cout，得到：

```text
Pconv = Cout × (Cin×Kh×Kw + 1)
```

为了公平比较，固定输入与输出形状：

```text
Plocal = Hout×Wout×Cout×(Cin×Kh×Kw+1)  // 局部连接但不共享
Pdense = Hout×Wout×Cout×(Cin×H×W+1)    // 全连接到相同输出
```

### 28×28灰度图的完整算例

8个3×3滤波器，S1、P1，输出 `[8,28,28]`：

| 连接方式 | 参数量 | 算式 |
|---|---:|---|
| 共享卷积 | 80 | 8×(9+1) |
| 不共享的局部连接 | 62,720 | 28×28×8×(9+1) |
| 同输出形状的全连接 | 4,923,520 | 28×28×8×(784+1) |

“CNN比MLP少参数”要在明确输入、输出和连接方式下比较，不能拿一个输出标量的MLP与八张完整特征图不加说明地比较。

### 少参数不等于少做所有运算

理论窗口乘加数量约为：

```text
MACs = Hout×Wout×Cout×Cin×Kh×Kw
     = 28×28×8×1×3×3 = 56,448
```

这里一个MAC表示一次乘加，不把乘和加算成两个FLOP；忽略偏置、激活和内存开销。该理论计数包含补零窗口位置；本章循环跳过超界零位置，所以实际非零乘法次数会略少。

把输入从28×28放大到56×56、保持S1/P1，卷积参数仍然80，输出元素和理论MACs变成4倍。参数内存、激活内存、运算量是三个不同指标。

### 感受野为什么会扩大

感受野是“追溯一个输出，最初哪些输入像素可能影响它”。一个 3×3 卷积输出依赖原图 3×3 区域；下一层再组合邻近输出，就会看到更大的原图区块。

用 r 表示这个区域的边长，j 表示相邻两个输出中心在**原图**上隔多少像素。输入层每个点只对应自己，所以初始 r=1、j=1。本式 K 表示方形核的边长，不是前面整张权重矩阵；S 是本层步幅。更新时都要使用旧的 r、j：

```text
r_new = r_old + (K−1)×j_old
j_new = j_old × S
```

例：3×3卷积S1后r=3、j=1；2×2池化S2后r=4、j=2；再3×3卷积S1后r=8、j=2。这是几何上的理论支持范围，不等于训练后每个输入像素具有相同实际影响。

**局限：**空间共享意味着相同局部图案使用相同检测规则，适合可在不同位置出现的笔画；若任务强依赖绝对位置，需要其他结构表达。边界与降采样会破坏严格的平移对应关系，后续全连接头也可能重新引入位置敏感性。

## 5. ReLU：特征图为什么不立即转成一张普通灰度图

卷积输出是有符号的特征响应。手工竖线核 `[-1,2,-1]` 会对某些区域给负响应；这些数值是计算结果，不是合法显示像素的限制范围。

ReLU对每个元素执行 `A=max(0,Y)`，保留正响应，负响应置0，不改变形状。它使多层线性卷积之间具有非线性；若连续只有线性操作，表达能力会受限制。

手算 `Y=[−2,0;1.5,3]`，得到 `A=[0,0;1.5,3]`。反传时，G_A 是后面层传来的“损失对激活值的变化率”，G_Y 是要传给卷积输出的变化率。Y>0 时 ReLU 原样通过，所以 G_Y=G_A；Y<0 时输出固定为 0，所以 G_Y=0。这可合写为 `G_Y=G_A×1[Y>0]`，在 Y=0 处选 0。这个导数约定与第14章一致；极端情况下，一个通道可能对所有样本都被截为0。

`relu(input)` 创建同形状新张量，原卷积输出仍可显示和调试。浏览器将负数着浅红色、正数着浅绿色并打印数值，随后单独显示ReLU结果，避免“显示时截断”和“网络激活”混为一步。

## 6. 池化：压缩空间分辨率，并明确它损失的信息

### 动机与定义

局部特征图往往比最终分类所需的空间精度更细。池化把一个窗口汇总为一个值，让下一层处理更小的图。本章池化逐通道进行，不混合输入通道，也没有可学习参数。

对窗口Ω，大小为Kh×Kw：

```text
最大池化：P[c,y,x] = max(i,j∈Ω) A[c,i,j]
平均池化：P[c,y,x] = (1/(KhKw)) Σ(i,j∈Ω) A[c,i,j]
```

最大池化强调最强响应，平均池化统计平均响应强度。输入若为C×H×W，无填充下输出空间尺寸用第3节的floor公式，通道C不变。

### 手算与方法对照

```text
输入4×4：
[1 2 | 0 4]
[3 8 | 5 6]
[----+----]
[2 1 | 7 0]
[0 3 | 1 9]

2×2窗口、stride2：
最大池化=[8,6;3,9]
平均池化=[3.5,3.75;1.5,4.25]
```

第一个窗口：max(1,2,3,8)=8，mean=(1+2+3+8)/4=3.5。若只有一个强噪点，最大池化也会强调它；平均池化会稀释局部尖峰，但可能弱化细笔画。

| 方案 | 更强调的内容 | 主要代价 |
|---|---|---|
| 最大池化 | 局部最强响应 | 峰值噪声敏感，其他位置丢失 |
| 平均池化 | 局部平均强度 | 强响应被稀释，细节平滑 |
| stride卷积 | 可学习的降采样 | 有参数，仍会受采样影响 |
| 不降采样 | 保留空间细节 | 激活内存和后续计算更大 |

### 对应循环与负值/边缘规则

1. 算出OH/OW，分配 `[C,OH,OW]`。
2. 每个通道独立遍历窗口。
3. 最大池化累加器从 `−Infinity` 开始，不能从0开始，因为输入可能全负。
4. 平均池化每个元素贡献 `v/(KhKw)`。
5. 本章无padding、采用floor，窗口不足的右边与底边直接不计算。

Node特意使用 `[-4,-2,99;-3,-1,99;99,99,99]`：窗口2、stride2，只得到max=−1或mean=−2.5，所有边缘99都未进入窗口。这验证边界行为，也说明小笔画可能被丢弃。有关标准最大池化的窗口、步幅与floor/ceil区别，可对照[官方 MaxPool2d 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.MaxPool2d.html)。

### 池化反向是怎样的

先解释“上游导数”：后面的网络已算出损失对这个池化输出的变化率，把它传回来，记为 g。现在池化层要把它分给对这个输出有影响的输入。

以 `[1,2;3,8]` 为例，假设 g=2。平均池化中每个数对平均值贡献 1/4，因此各自收到 `2/4=0.5`；最大池化在当前输入附近只取决于右下的 8，所以梯度是 `[0,0;0,2]`。一般窗口为 Kh×Kw 时，平均分给每处 `g/(KhKw)`；窗口重叠时，同一输入收到的贡献还要累加。

例如3×3输入只有中心为9，其余为0，2×2窗口stride1产生4个9。若4个输出的上游导数均为1，中心收到4，而不是1。若最大值并列，函数在该点不光滑，本章明确选择行优先遇到的第一个最大值作为梯度接收位置。

`pool2dBackward` 按同样窗口重新寻找最大值位置。真实训练中常缓存最大值索引提高效率；这里保留直接遍历便于理解。最大池化对窗口内小位移可能保持同值，但没有保证整网严格平移不变。

## 7. 图像梯度与训练梯度：名字相近，自变量不同

### 三种导数不要混淆

| 名称 | 数学对象 | 描述什么 | 用途 |
|---|---|---|---|
| 图像空间梯度 | ∂I/∂x、∂I/∂y | 亮度沿空间坐标如何变化 | Sobel边缘、HOG |
| 输入梯度 | ∂L/∂X | 损失随输入元素如何变化 | 反传给前一层、敏感性分析 |
| 参数梯度 | ∂L/∂K、∂L/∂b | 损失随权重/偏置如何变化 | 更新模型参数 |

卷积核可以手工设为Sobel，也可以是训练参数。前向用了卷积操作，不代表得到的响应就是反向传播梯度；输入梯度与图像本身同形状，也不表示它是亮度的空间导数。

### 由一个乘法得到全部反传公式

用 L 表示一个标量损失，用 G 表示后面层传来的导数。`G[o,y,x]` 的意思是：“这一格卷积输出 Y 稍微变化，最终损失怎样变化？”它不是另一张输入图片。

先只看一项乘法。若 `Y=K×X`，增大 K 的影响按 X 放大，增大 X 的影响按 K 放大，再乘损失对 Y 的导数 G，就得到下面三条。`+=` 表示累加，因为同一个参数或像素可能通过多个输出影响损失：

```text
∂L/∂K += G × X
∂L/∂X += G × K
∂L/∂b += G
```

带stride/padding时，取 `iy=ySh+ky−Ph`、`ix=xSw+kx−Pw`：

```text
dK[o,c,ky,kx] = Σy Σx G[o,y,x] × X[c,iy,ix]
db[o] = Σy Σx G[o,y,x]
dX[c,iy,ix] += G[o,y,x] × K[o,c,ky,kx]
```

超界输入是常数0，不是待优化变量，不给它存梯度。dK跨输出空间位置求和，因为同一个参数在很多窗口被反复使用；dX跨输出通道和重叠窗口求和，因为同一个输入会影响多个输出。

### 手算共享权重梯度

第2节的两通道例子，令 `L=ΣY`，所以G的4个元素全为1。

```text
dK[0,0,0,0] = 1+2+4+5 = 12
dK[0,0,0,1] = 2+3+5+6 = 16
dK[0,0,1,0] = 4+5+7+8 = 24
dK[0,0,1,1] = 5+6+8+9 = 28
第二通道的4个核元素梯度均为4
db[0] = 1+1+1+1 = 4
```

再用全1的3×3输入和全1的2×2核，G也全1，输入梯度为：

```text
[1 2 1]
[2 4 2]
[1 2 1]
```

中心被四个窗口使用，角点只被一次使用。这张矩阵直接展示路径累加的必要性。

### 如何证明实现正确，怎样真正下降一步

`conv2dBackward` 接受外部upstream，调用者负责定义损失是否取平均。它本身不除以图像面积，也不更新权重。Jest使用独立标量目标 `L=ΣYᵢGᵢ`，对两输入通道、两输出通道、矩形核、非对称步幅/对称零填充组合，逐个扰动所有输入、核和偏置，比较中心差分与解析导数。

另一个能训练的小目标：输入 `[1,0,2;-1,1,3]`，核 `[0.1,-0.2;0.3,0.1]`，S1/P0，无偏置。前向Y=[−0.1,0.2]，定义 `L=½ΣY²=0.025`，于是upstream=Y。

```text
dK=[−0.1,0.4;0.3,0.5]
η=0.01 → K_new=[0.101,−0.204;0.297,0.095]
Y_new=[−0.101,0.174]
L_new=½(0.101²+0.174²)=0.0202385
```

Node实际执行并断言损失下降。这个目标只把卷积输出推向0，用于证明梯度能驱动学习；它没有分类意义。完整CNN训练还要把分类损失经Softmax/Dense/Flatten/Pool/ReLU继续传回卷积。本章实现卷积与池化的局部反向，不声称训练了后面的固定CNN。

## 8. 连接完整 CNN：Flatten、Dense 与 Softmax

### 为什么需要分类头

卷积输出多张空间特征图，分类需要一个按类别排列的得分向量。Flatten先把这些响应按固定次序排列，Dense为不同位置/通道分配分类权重，Softmax把logits归一化为总和1的得分。

本章的微型结构：

```text
输入                [1,6,6]
Conv：2个3×3核      [2,4,4]   S1/P0
ReLU                [2,4,4]
MaxPool：2×2,S2     [2,2,2]
Flatten             [8]
Dense               [2]
Softmax             [2]       标签顺序 [竖线,横线]
```

| 层 | 参数量 | 计算 |
|---|---:|---|
| Conv | 20 | 2×(1×3×3+1) |
| ReLU、Pool、Flatten | 0 | 没有可学习参数 |
| Dense | 18 | 2×(8+1) |
| 总计 | 38 | 所有权重均由本章人为设置 |

### 固定核如何响应笔画

竖线核V与横线核H：

```text
V = (1/6)×[−1 2 −1]      H = (1/6)×[−1 −1 −1]
          [−1 2 −1]                [ 2  2  2]
          [−1 2 −1]                [−1 −1 −1]
```

输入第2列全1，其余为0（从0计数）。V在包含中心列的窗口得到 `(2+2+2)/6=1`，在偏到两侧的窗口得到−0.5；H对贯穿整列的线条响应为0。

所以竖线对应卷积输出0号通道的每一行都是 `[−0.5,1,−0.5,0]`，1号通道为0。ReLU后为 `[0,1,0,0]`，池化0号通道为 `[1,0;1,0]`。

### Flatten次序、全连接与概率手算

CHW表示先输出通道0全部空间位置，再通道1。`flatten`复制数组，不重排也不借用原引用：

```text
features=[1,0,1,0, 0,0,0,0]
```

Dense的第0行给前4个元素权重1/4，其余0；第1行给后4个元素权重1/4，其余0，偏置均0。于是竖线输入的 `logits=[0.5,0]`。

这里的 logits 是两个还没归一化的类别分数 z，分别对应“竖线、横线”。Softmax 要先给每个分数取指数，再除以所有指数之和，使两项总和为 1。k 是当前类别索引，j 用来遍历全部类别，m 是最大的那个分数：

```text
p[k]=exp(z[k]−m)/Σj exp(z[j]−m)，m=max(z)
```

减去m不改变结果，因为所有分子分母都乘了同一个 `exp(−m)`；它避免大logit时exp溢出。

```text
p(竖线)=exp(0)/(exp(0)+exp(−0.5))≈0.6224593312
p(横线)≈0.3775406688
```

将输入改成第2行全1，Flatten=[0,0,0,0,1,1,0,0]，logits=[0,0.5]，两个得分互换。Node和浏览器均显示这些具体中间值，而不只打印最终标签。

**局限：**Dense连接到全部Flatten元素，依赖输入尺寸和排列；任意改前层尺寸，分类头维度必须同步改变。本章`tinyCNNForward`固定接受 `[1,6,6]`。全局平均池化可汇总各通道空间位置并允许不同尺寸，但也会舍弃位置细节；这里只作概念对比。

## 9. 交互实验、实测结果与可见失败

### 推荐操作顺序

1. 保持默认单通道、竖线位置2、S1/P0，核对第8节所有矩阵和得分。
2. 改成横线，看哪个输出通道出现正响应；原输入、卷积、ReLU与池化均可直接比较。
3. 改成两个输入通道，看全1通道怎样贡献到两个输出通道；输出仍为2个。
4. 固定图案切换stride与padding，手算Hout/Wout，与页面形状链对照。
5. 切换最大/平均池化，对比相同ReLU结果的汇总；不要误以为它们换了卷积核。
6. 把位置改成边缘0或5，观察固定CNN的响应可能消失。第二块“完整CNN”始终使用固定S1/P0/MaxPool，避免工作台shape变化误接到固定Dense。
7. 展开矩阵编辑器，输入6行6列的0到1数值，制造断笔或灰度变化；点击“清为空白”查看相同得分；点击恢复回到当前线条预设。
8. 输入错误维度或非数值，界面明确提示失败，并标明下方保留的是上一次有效结果。

所有二维表格按数值着色，并保留文字，不依赖颜色辨认结果。数值显示保留两位小数，悬停可查看原值；README和Node提供完整精度算例。

### 默认实验的实际数值

| 实验 | 实测结果 |
|---|---|
| 非对称2×2核互相关 | `[37,47;67,77]` |
| 两输入通道、偏置0.5 | 一个2×2输出通道，全部0.5 |
| 全1核、S2/P1 | `[1,5;11,28]` |

这些是固定小矩阵或合成图案的计算结果，不是MNIST、真实字迹或手机照片准确率。并列时底层argmax返回第一个类别是确定性规则，浏览器会说明“不能区分”，不把它包装成有依据的分类。

### 平移等变性与不变性的区别

在无限网格或不受边界影响的区域，stride1共享卷积对输入平移会产生对应的输出平移，这称为等变。分类不变则要求输入平移后类别结果不变，是不同性质。stride>1、池化采样相位、裁剪边界和固定全连接头都可能影响最终结果。

本章位移对照直接显示0到5的位置得分，不把“CNN适合图像”概括为“CNN天然不怕平移”。真实OCR中仍需合理居中、留白和数据增强。

## 10. LeNet-5：经典思想与本实验的范围

LeNet-5把局部连接、共享权重与下采样组合用于字符识别。原论文的经典维度链为：

```text
32×32输入
→ C1：6×28×28
→ S2：6×14×14
→ C3：16×10×10
→ S4：16×5×5
→ C5：120
→ F6：84
→ 10个输出
```

这里的S2/S4是带可学习缩放与偏置的下采样，C3使用部分通道连接，原版输出为RBF单元。把现代常见的全连接卷积+ReLU+MaxPool+Softmax写成“原版LeNet-5”会混淆历史架构与教学改编。以上核验自作者提供的[原论文](https://leon.bottou.org/publications/pdf/ieee-1998.pdf)的网络结构图及相关章节，见[作者论文页](https://bottou.org/papers/lecun-98h)。

本章保留“卷积→非线性→下采样→分类”的入门思路，采用1×6×6的可手算输入、两个手工核和两类输出，没有复现完整LeNet训练与数据评估。后续课程才会使用真实手写数据训练字符分类器。

## 11. 共享接口与实现边界

统一张量结构：

```javascript
{ shape: [C,H,W], data: Float64Array(C*H*W) }
```

核为四阶，Dense权重为二阶。张量可含任意有限实数；浏览器矩阵编辑器另限制原始像素到[0,1]。

```javascript
const cnn = require('../shared/15-cnn-basics');
const image = cnn.makeLineImage({ orientation: 'vertical', position: 2 });
const model = cnn.createTinyCNN();
const y = cnn.conv2d(image, model.kernel, { stride: 1, padding: 0, bias: model.convBias });
const a = cnn.relu(y);
const pooled = cnn.pool2d(a, { size: 2, stride: 2, mode: 'max' });
const result = cnn.tinyCNNForward(image, model);
```

| 接口 | 输入/返回 |
|---|---|
| `tensor(shape,data?)` | 校验shape与元素数，复制数据；省略data创建全0张量 |
| `outputShape(inputShape,kernelShape,options)` | CHW/OIHW→输出CHW；非法维度或空输出报错 |
| `conv2d(input,kernel,{stride,padding,bias})` | 单样本互相关，返回新输出张量；偏置默认0 |
| `conv2dBackward(input,kernel,upstream,options)` | 返回 `{dInput,dKernel,dBias}`；不平均、不更新 |
| `relu(input)` | 同形状的新张量，负值置0 |
| `pool2d(input,{size,stride,mode})` | mode=`max/average`；默认size2、stride=size；无填充 |
| `pool2dBackward(input,upstream,options)` | 新输入梯度；重叠贡献累加，最大值并列取第一个 |
| `flatten(input)` | CHW顺序的一维副本 |
| `dense(input,weights,bias?)` | weights形状 `[outputs,inputs]`，返回logits向量 |
| `softmax(logits)` | 稳定概率向量；非空、有限输入 |
| `parameterCount(kernelShape,inputShape,options)` | 输出形状，卷积/局部不共享/全连接参数与理论MACs |
| `makeLineImage(options)` | 默认1×6×6、竖线位置2；orientation为vertical/horizontal |
| `createTinyCNN()` | 新建手工核/偏置/分类权重及标签数组 |
| `tinyCNNForward(input,model?,{poolMode})` | 返回卷积、激活、池化、特征、logits、概率、标签与参数数 |

所有算法输入都不原地修改，局部训练示例由调用者显式更新核。stride/size支持正整数或高宽二元数组；padding支持非负整数或高宽二元数组。不支持batch、dilation、groups、非对称边界、ceil池化或完整CNN自动求导。虽然接口允许其他小尺寸张量，六重循环不是生产级高性能卷积内核。

## 12. 常见误区与排障

| 现象/说法 | 应检查的原因 | 对应实验 |
|---|---|---|
| 数值与官方库不同 | CHW/NHWC、OIHW/HWIO顺序，是否翻核 | 非对称核37/23对照 |
| 输入3通道却输出3×16张图 | 通道贡献没有求和 | 两输入通道只得一个输出 |
| 偏置结果成倍偏移 | 把bias放进输入通道循环 | −4+4+0.5手算 |
| stride2的shape多一行 | floor/ceil或padding左右含义混淆 | 第3节输出推导 |
| CNN负响应消失 | 用了像素型Uint8数组或提前截断 | Conv与ReLU分开显示 |
| max池化全负输入变成0 | 累加器从0初始化错误 | max=−1对照 |
| 数值梯度相差面积倍数 | backward自行做了未约定的平均 | L=ΣY时db=4 |
| 中心输入梯度只有1 | 多窗口路径写成赋值，没有累加 | 中心梯度=4 |
| 换padding后Dense报错 | Flatten长度改变，分类头未匹配 | 工作台与固定CNN分开 |
| 空白仍有类别 | Softmax必须归一化，argmax存在并列规则 | `[0.5,0.5]`并非识别证据 |
| “卷积核就是边缘检测器” | 先验核与任务学习参数混为一谈 | 手工核标注及局部损失 |

## 14. 分享重点与下一章联系

分享可从第05章的一个滤波窗口开始，给它加第二输入通道，手算相加；再改变stride/padding，推导窗口个数；接着比较80、62,720和4,923,520个参数；最后沿38参数CNN逐层走到两个得分，并展示边缘/空白失败。

最值得让听众复述的是：一个滤波器跨全部输入通道；共享的是权重而不是计算结果；形状变化必须逐层核对；反向中共享对应梯度累加；平移等变不等于分类不变；学习能力需要真实训练与独立数据验证。

下一章用TensorFlow.js张量、模型定义、训练和保存加载来组织这些运算。框架能加速和自动求导，但仍需由开发者确认输入布局、损失、形状、数据划分和实验边界。本章共享模块不依赖后续框架代码。
