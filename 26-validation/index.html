怎样理解这些数字？

CER = (替换 + 删除 + 插入) / 真实字符总数。多个样本按总字符数汇总，额外插入很多数字时可超过 100%。

整串完全正确率 = 完全一致的照片数 / 有标签有效照片数。模型置信度不参与这两个分母，也不代表实际准确率。
