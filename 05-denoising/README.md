## 核心概念

### 1. 什么是图像噪声？

噪声是图像中**不期望的随机干扰**，会影响图像质量和后续处理效果。

```
原始图像（清晰）          含噪声图像（模糊/有杂点）
┌─────────────────┐      ┌─────────────────┐
│    OCR 文字     │  →   │  O*C#R 文&字    │
└─────────────────┘      └─────────────────┘
                              ↑
                         噪声干扰
```

### 2. 常见噪声类型

#### 高斯噪声 (Gaussian Noise)

- **特点**：服从正态分布，影响整体图像
- **来源**：传感器热噪声、电子干扰
- **视觉效果**：通常呈现随机颗粒；模糊是空间混合，不等同于加性噪声

```
正态分布：大部分噪声集中在均值附近
       ▲
       │    ╭─╮
       │   ╭╯ ╰╮
       │  ╭╯   ╰╮
       │ ╭╯     ╰╮
       └──────────── 噪声值
           μ (均值)
```

#### 椒盐噪声 (Salt-and-Pepper Noise)

- **特点**：随机出现的黑点（椒）和白点（盐）
- **来源**：图像传输错误、相机坏点
- **视觉效果**：图像上有明显的黑白点

```
原图：             加椒盐噪声后：
████████████      █●██●███●███
████████████  →   ██○█████●██●
████████████      ●██████○████
                  ○=白点(盐) ●=黑点(椒)
```

### 3. 卷积操作 (Convolution) ⭐ 重点

卷积是图像处理的**核心操作**，通过滤波器核（Kernel）对图像进行处理。

```
原理：用一个小矩阵（Kernel）在图像上滑动，
     对每个位置计算加权和，得到新的像素值

        Kernel (3×3)
        ┌───┬───┬───┐
        │ a │ b │ c │
        ├───┼───┼───┤
        │ d │ e │ f │
        ├───┼───┼───┤
        │ g │ h │ i │
        └───┴───┴───┘
              ↓
    新像素值 = Σ(Kernel × 对应像素)
```

#### 卷积与相关要区分

令核尺寸为 k×k（正奇数），r=(k−1)/2，中心化核为 K(j,i)，i/j∈[−r,r]，图像为 I(y,x)。

```
相关：S(y,x) = ΣⱼΣᵢ K(j,i) I(y+j,x+i)
卷积：S(y,x) = ΣⱼΣᵢ K(j,i) I(y−j,x−i)
```

不翻核的滑动相乘是**相关**。卷积等价于先把核旋转180°再做相关。本项目 `correlate` 实现相关，`convolve` 实现卷积；均值和高斯核中心对称，两者结果相同。反例：一行 `[10,20,40]`，核仅中心左侧为1，中心相关结果为10，而卷积为40。

共享实现只读灰度 R，保留中心 alpha，返回 H×W×4 图像；最后 `Math.round` 并裁剪到0–255。这是8-bit平滑教学接口，带负权重的边缘响应会丢失负数，不能代替浮点梯度算子。中值是非线性排序操作，不能用一个固定卷积核实现。

#### 卷积计算示例

```
图像区域:        Kernel (均值):      计算:
┌───┬───┬───┐   ┌───┬───┬───┐
│100│120│110│   │1/9│1/9│1/9│
├───┼───┼───┤   ├───┼───┼───┤
│ 90│255│130│ × │1/9│1/9│1/9│ = (100+120+110+90+255+130+80+95+105)/9
├───┼───┼───┤   ├───┼───┼───┤
│ 80│ 95│105│   │1/9│1/9│1/9│   = 1085/9 ≈ 120.556，四舍五入为121
└───┴───┴───┘   └───┴───┴───┘

中心像素255被平滑为121；仅凭局部输出不能断言还原了真实像素
```

### 4. 边界处理

当卷积核移动到图像边缘时，部分区域超出图像范围，需要特殊处理。

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **补零** (Zero Padding) | 超出部分视为0 | 简单实现 |
| **边缘复制** (Replicate) | 复制最近边缘像素 | 避免边缘变暗 |
| **不重复边缘反射** (Reflect-101) | 镜像复制边缘 | 更自然的过渡 |
| **忽略边界** (Valid) | 只处理完整区域 | 输出尺寸变小 |

```
原图:  [A B C D E]
       
补零:      [0 0 | A B C D E | 0 0]
边缘复制:  [A A | A B C D E | E E]
镜像反射:  [C B | A B C D E | D C]
```

---

本章实现使用**边缘复制**，输出尺寸不变。例如 `[10,20]` 用3点均值，左端为 `(10+10+20)/3`，不是 `(0+10+20)/3`。上表其余方式仅作概念对照；不同库的 reflect 名称需核对是否重复边缘样本。

## 三种滤波方法

### 1. 均值滤波 (Mean Filter / Box Filter)

用邻域内所有像素的**平均值**替代中心像素。

```
3×3 均值核:
┌─────┬─────┬─────┐
│ 1/9 │ 1/9 │ 1/9 │
├─────┼─────┼─────┤
│ 1/9 │ 1/9 │ 1/9 │
├─────┼─────┼─────┤
│ 1/9 │ 1/9 │ 1/9 │
└─────┴─────┴─────┘

公式: output(x,y) = (1/k²) × Σ input(x+i, y+j)，k为核边长，求和覆盖k²个位置
```

**优点**：
- 实现简单
- 计算速度快

**缺点**：
- 模糊图像边缘
- 对椒盐噪声效果差

### 2. 高斯滤波 (Gaussian Filter)

用邻域内像素的**加权平均**替代中心像素，权重服从高斯分布。

```
高斯分布: 离中心越近，权重越大

3×3 高斯核 (σ=1.0):
┌────────┬────────┬────────┐
│ 0.0751 │ 0.1238 │ 0.0751 │
├────────┼────────┼────────┤
│ 0.1238 │ 0.2042 │ 0.1238 │  中心权重最大
├────────┼────────┼────────┤
│ 0.0751 │ 0.1238 │ 0.0751 │
└────────┴────────┴────────┘
        (权重总和 = 1)
```

#### 高斯核公式

```
G(x, y) = (1 / 2πσ²) × e^(-(x² + y²) / 2σ²)

σ (sigma): 标准差，控制模糊程度
- σ 越大 → 模糊越强
- σ 越小 → 模糊越弱
```

实际先在有限 k×k 网格上取 `exp(−(i²+j²)/(2σ²))`，再除以全部权重之和。连续密度前的 `1/(2πσ²)` 会约去；有限窗口不归一化会改变常量图的亮度。上表仅保留4位小数，显示值总和可能有舍入误差。

sigma 单位是像素；固定核尺寸时 sigma→0 接近单位核，sigma 很大趋近均值核，模糊不会无限增长。较大 sigma 需要较大的窗口才接近未截断高斯；常见从约 ±3σ 截断。本 API 要求 sigma>0，非法值报错；正偶数 size 沿用课程兼容约定自动加1，中值滤波也如此。

**优点**：
- 同样会模糊边缘；与均值核相比，权重更集中，效果取决于实际参数
- 更自然的模糊效果

**缺点**：
- 计算量比均值滤波大
- 对椒盐噪声效果仍不理想

### 3. 中值滤波 (Median Filter)

用邻域内像素的**中值**替代中心像素。

```
邻域像素: [100, 110, 120, 130, 255, 90, 95, 105, 115]
               ↓
排序后:   [90, 95, 100, 105, 110, 115, 120, 130, 255]
               ↓
中值:     110 (第5个位置)

结果: 异常值 255 被有效过滤
```

**优点**：
- 对椒盐噪声效果极佳
- 保留边缘效果好

**缺点**：
- 计算量较大（需要排序）
- 对高斯噪声效果一般

---

### 中值滤波的反例和成本

3×3中值由9个样本的第5个决定。4个椒噪声配5个正常常量128仍输出128；5个椒配4个128会输出0。正常细线的三个黑像素夹在六个白像素中也会被抹去。因此“保边”“椒盐克星”都是场景相关描述，不能保证更高识别率。

本实现均值/高斯直接扫描核，O(WHk²)，中值每处排序约 O(WHk² log(k²))。高斯核可分离，均值可用积分图优化；这里保留直观的二维循环，并未实现这些加速。

### 噪声模型与可重复实验

高斯噪声模型为 `I_noisy=clip(round(I+σZ),0,255)`，Z~N(0,1)，每个像素用 Box–Muller 产生一个Z。sigma 是**裁剪前**的标准差；靠近黑白极值时会截断并产生偏差，输出噪声已不严格正态。本接口的彩色输入在同一像素三通道共享扰动，属于教学简化；不宣称完整相机噪声模型。sigma=0 是恒等变换。

椒盐 density=p 表示每个像素独立以p概率被替换，选中后黑白各50%。选中像素数期望为WHp，不是固定数量；如果原来就是相同黑白值，外观不会改变。旧式反复随机抽坐标有放回，会让高密度实际覆盖率偏低。现实现逐像素抽取，p=0不变，p=1每个像素都被替换。

Node 和 HTML 演示注入固定种子20260911，便于同参数重放；共享函数仍可传入其他 random。比较各滤波器时必须使用同一幅含噪图。

### PSNR：测量什么，不能证明什么

对尺寸相同、位置对齐的8-bit灰度参考 I 与结果 J，N=WH：

```
MSE = (1/N) Σ(I−J)²
PSNR = 10 log₁₀(255² / MSE) dB
```

本章只对灰度R通道计算，RGB三通道相同，不把alpha算进误差。相同图像 MSE=0，PSNR=+∞；不同尺寸、空图或彩色输入报错。两个像素从 `[0,255]` 变为 `[0,0]`，MSE=32512.5，PSNR≈3.0103dB。PSNR变大只代表对这幅参考的均方误差变小，没有通用30dB合格线，也不保证OCR笔画保留或识别准确率更高。上传图仅作为“加噪前参考”，不代表无噪真值。

## 三种滤波器对比

| 特性 | 均值滤波 | 高斯滤波 | 中值滤波 |
|------|---------|---------|---------|
| **原理** | 简单平均 | 加权平均 | 取中值 |
| **计算速度** | ⭐⭐⭐ 快 | ⭐⭐ 中 | ⭐ 慢 |
| **边缘保持** | ⭐ 差 | ⭐⭐ 中 | ⭐⭐⭐ 好 |
| **高斯噪声** | ⭐⭐ 可 | ⭐⭐⭐ 好 | ⭐⭐ 可 |
| **椒盐噪声** | ⭐ 差 | ⭐ 差 | ⭐⭐⭐ 极好 |
| **OCR推荐** | 一般 | 推荐 | 强烈推荐 |

以上是定性经验对照，受图像、噪声和参数影响；没有固定的优胜滤波器。

### 选择策略

```
识别噪声类型
    │
    ├─→ 高斯噪声 ──→ 高斯滤波（或均值滤波）
    │
    ├─→ 椒盐噪声 ──→ 中值滤波
    │
    └─→ 混合噪声 ──→ 先中值滤波去椒盐，再高斯滤波去高斯
```

## 与 OCR 的关联

去噪在 OCR 预处理链中的位置：

```
彩色图 → 灰度图 → [均值/高斯去噪] → 二值图 → 形态学 → 文字检测 → 文字识别
                             ↑
                        当前学习
```

| 影响 | 说明 |
|------|------|
| 减少误识别 | 噪点可能被误认为文字笔画 |
| 改善边缘 | 清晰的文字边缘有助于识别 |
| 后续处理 | 减少连通域分析的干扰 |

**注意**：二值图可用中值滤波（仍保持0/255），但均值/高斯会产生中间灰度，应在二值化前使用，或在平滑后重新二值化。去噪过度会模糊甚至抹去笔画。

## 自测问题

学完本章后，你应该能回答以下问题：

1. 高斯噪声和椒盐噪声有什么区别？
2. 卷积操作的基本原理是什么？
3. 为什么中值滤波对椒盐噪声效果特别好？
4. 如何选择合适的滤波器核大小？

<details>
<summary>点击查看答案</summary>

1. 高斯噪声是服从正态分布的连续噪声，影响整体；椒盐噪声是随机出现的极值点（黑白点）
2. 数学卷积先翻转核，再滑动计算加权和；不翻核是互相关。对称均值/高斯核两者相同。
3. 稀疏极值被排到两端时中位数较稳定；同向极值占多数时仍可能输出0/255，細笔画也会被删。
4. 核越大去噪效果越强但细节损失越多；通常3×3或5×5足够

</details>
