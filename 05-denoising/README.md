## 核心概念

### 1. 什么是图像噪声？

噪声是图像中**不期望的随机干扰**，会影响图像质量和后续处理效果。

```
原始图像（清晰）          含噪声图像（模糊/有杂点）
┌─────────────────┐      ┌─────────────────┐
│    OCR 文字     │  →   │  O*C#R 文&字    │
└─────────────────┘      └─────────────────┘
                              ↑
                         噪声干扰
```

### 2. 常见噪声类型

#### 高斯噪声 (Gaussian Noise)

- **特点**：服从正态分布，影响整体图像
- **来源**：传感器热噪声、电子干扰
- **视觉效果**：图像看起来"模糊"或"有雾"

```
正态分布：大部分噪声集中在均值附近
       ▲
       │    ╭─╮
       │   ╭╯ ╰╮
       │  ╭╯   ╰╮
       │ ╭╯     ╰╮
       └──────────── 噪声值
           μ (均值)
```

#### 椒盐噪声 (Salt-and-Pepper Noise)

- **特点**：随机出现的黑点（椒）和白点（盐）
- **来源**：图像传输错误、相机坏点
- **视觉效果**：图像上有明显的黑白点

```
原图：             加椒盐噪声后：
████████████      █●██●███●███
████████████  →   ██○█████●██●
████████████      ●██████○████
                  ○=白点(盐) ●=黑点(椒)
```

### 3. 卷积操作 (Convolution) ⭐ 重点

卷积是图像处理的**核心操作**，通过滤波器核（Kernel）对图像进行处理。

```
原理：用一个小矩阵（Kernel）在图像上滑动，
     对每个位置计算加权和，得到新的像素值

        Kernel (3×3)
        ┌───┬───┬───┐
        │ a │ b │ c │
        ├───┼───┼───┤
        │ d │ e │ f │
        ├───┼───┼───┤
        │ g │ h │ i │
        └───┴───┴───┘
              ↓
    新像素值 = Σ(Kernel × 对应像素)
```

#### 卷积计算示例

```
图像区域:        Kernel (均值):      计算:
┌───┬───┬───┐   ┌───┬───┬───┐
│100│120│110│   │1/9│1/9│1/9│
├───┼───┼───┤   ├───┼───┼───┤
│ 90│255│130│ × │1/9│1/9│1/9│ = (100+120+110+90+255+130+80+95+105)/9
├───┼───┼───┤   ├───┼───┼───┤
│ 80│ 95│105│   │1/9│1/9│1/9│   = 1085/9 ≈ 120
└───┴───┴───┘   └───┴───┴───┘

中心像素 255 被平滑为 120（噪点被消除）
```

### 4. 边界处理

当卷积核移动到图像边缘时，部分区域超出图像范围，需要特殊处理。

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **补零** (Zero Padding) | 超出部分视为0 | 简单实现 |
| **边缘复制** (Replicate) | 复制最近边缘像素 | 避免边缘变暗 |
| **镜像反射** (Reflect) | 镜像复制边缘 | 更自然的过渡 |
| **忽略边界** (Valid) | 只处理完整区域 | 输出尺寸变小 |

```
原图:  [A B C D E]
       
补零:      [0 0 | A B C D E | 0 0]
边缘复制:  [A A | A B C D E | E E]
镜像反射:  [C B | A B C D E | D C]
```

## 三种滤波方法

### 1. 均值滤波 (Mean Filter / Box Filter)

用邻域内所有像素的**平均值**替代中心像素。

```
3×3 均值核:
┌─────┬─────┬─────┐
│ 1/9 │ 1/9 │ 1/9 │
├─────┼─────┼─────┤
│ 1/9 │ 1/9 │ 1/9 │
├─────┼─────┼─────┤
│ 1/9 │ 1/9 │ 1/9 │
└─────┴─────┴─────┘

公式: output(x,y) = (1/n) × Σ input(x+i, y+j)
```

**优点**：
- 实现简单
- 计算速度快

**缺点**：
- 模糊图像边缘
- 对椒盐噪声效果差

### 2. 高斯滤波 (Gaussian Filter)

用邻域内像素的**加权平均**替代中心像素，权重服从高斯分布。

```
高斯分布: 离中心越近，权重越大

3×3 高斯核 (σ=1.0):
┌────────┬────────┬────────┐
│ 0.0751 │ 0.1238 │ 0.0751 │
├────────┼────────┼────────┤
│ 0.1238 │ 0.2042 │ 0.1238 │  中心权重最大
├────────┼────────┼────────┤
│ 0.0751 │ 0.1238 │ 0.0751 │
└────────┴────────┴────────┘
        (权重总和 = 1)
```

#### 高斯核公式

```
G(x, y) = (1 / 2πσ²) × e^(-(x² + y²) / 2σ²)

σ (sigma): 标准差，控制模糊程度
- σ 越大 → 模糊越强
- σ 越小 → 模糊越弱
```

**优点**：
- 保留更多边缘细节
- 更自然的模糊效果

**缺点**：
- 计算量比均值滤波大
- 对椒盐噪声效果仍不理想

### 3. 中值滤波 (Median Filter)

用邻域内像素的**中值**替代中心像素。

```
邻域像素: [100, 110, 120, 130, 255, 90, 95, 105, 115]
               ↓
排序后:   [90, 95, 100, 105, 110, 115, 120, 130, 255]
               ↓
中值:     110 (第5个位置)

结果: 异常值 255 被有效过滤
```

**优点**：
- 对椒盐噪声效果极佳
- 保留边缘效果好

**缺点**：
- 计算量较大（需要排序）
- 对高斯噪声效果一般

## 三种滤波器对比

| 特性 | 均值滤波 | 高斯滤波 | 中值滤波 |
|------|---------|---------|---------|
| **原理** | 简单平均 | 加权平均 | 取中值 |
| **计算速度** | ⭐⭐⭐ 快 | ⭐⭐ 中 | ⭐ 慢 |
| **边缘保持** | ⭐ 差 | ⭐⭐ 中 | ⭐⭐⭐ 好 |
| **高斯噪声** | ⭐⭐ 可 | ⭐⭐⭐ 好 | ⭐⭐ 可 |
| **椒盐噪声** | ⭐ 差 | ⭐ 差 | ⭐⭐⭐ 极好 |
| **OCR推荐** | 一般 | 推荐 | 强烈推荐 |

### 选择策略

```
识别噪声类型
    │
    ├─→ 高斯噪声 ──→ 高斯滤波（或均值滤波）
    │
    ├─→ 椒盐噪声 ──→ 中值滤波
    │
    └─→ 混合噪声 ──→ 先中值滤波去椒盐，再高斯滤波去高斯
```

## 与 OCR 的关联

去噪在 OCR 预处理链中的位置：

```
彩色图 → 灰度图 → 二值图 → [去噪] → 形态学 → 文字检测 → 文字识别
                             ↑
                        当前学习
```

| 影响 | 说明 |
|------|------|
| 减少误识别 | 噪点可能被误认为文字笔画 |
| 改善边缘 | 清晰的文字边缘有助于识别 |
| 后续处理 | 减少连通域分析的干扰 |

**注意**：去噪过度会导致文字边缘模糊，需要权衡。

## 自测问题

学完本章后，你应该能回答以下问题：

1. 高斯噪声和椒盐噪声有什么区别？
2. 卷积操作的基本原理是什么？
3. 为什么中值滤波对椒盐噪声效果特别好？
4. 如何选择合适的滤波器核大小？

<details>
<summary>点击查看答案</summary>

1. 高斯噪声是服从正态分布的连续噪声，影响整体；椒盐噪声是随机出现的极值点（黑白点）
2. 用滤波器核在图像上滑动，对每个位置计算核与对应像素的加权和
3. 中值不受极值影响，椒盐噪声的极值（0或255）会被正常值替代
4. 核越大去噪效果越强但细节损失越多；通常3×3或5×5足够

</details>
