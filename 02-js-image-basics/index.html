📚 Canvas API 核心概念

Canvas 是 HTML5 提供的绑图容器，通过 JavaScript 可以进行图形绑制和图像处理。 对于 OCR 项目，Canvas 是我们操作图像像素的核心工具。

// 核心 API 一览 // 1. 获取 Canvas 和上下文 const canvas = document.getElementById('myCanvas'); const ctx = canvas.getContext('2d'); // 2. 绑制图片到 Canvas ctx.drawImage(img, 0, 0); // 3. 获取像素数据 const imageData = ctx.getImageData(0, 0, width, height); // 4. 修改像素后写回 ctx.putImageData(imageData, 0, 0); // 5. 导出为图片 const dataURL = canvas.toDataURL('image/png');

🔄 像素遍历与修改

学习如何遍历图像的每个像素并进行修改（需要先上传图片）

像素遍历是图像处理的基础。每个像素占用 4 个数组位置（R, G, B, A）。

// 像素遍历的两种方式 // 方式一：按像素索引遍历（更快） const data = imageData.data; for (let i = 0; i < data.length; i += 4) { const r = data[i]; // 红色 const g = data[i + 1]; // 绿色 const b = data[i + 2]; // 蓝色 const a = data[i + 3]; // 透明度 } // 方式二：按坐标遍历（更直观） for (let y = 0; y < height; y++) { for (let x = 0; x < width; x++) { const index = (y * width + x) * 4; // 使用 index, index+1, index+2, index+3 } }

将 RGB 三个通道分离显示，帮助理解颜色组成

处理结果
// 提取红色通道（其他通道设为0） for (let i = 0; i < data.length; i += 4) { // 保留红色，清除绿色和蓝色 data[i + 1] = 0; // G = 0 data[i + 2] = 0; // B = 0 }

将每个像素的颜色反转（255 - 原值），类似照片底片效果

颜色反转结果
// 颜色反转算法 for (let i = 0; i < data.length; i += 4) { data[i] = 255 - data[i]; // R data[i + 1] = 255 - data[i + 1]; // G data[i + 2] = 255 - data[i + 2]; // B // Alpha 通道保持不变 }

调整图像亮度，理解 Uint8ClampedArray 的自动截断特性

亮度调整结果
// 亮度调整算法 const brightness = 50; // -255 到 255 for (let i = 0; i < data.length; i += 4) { // Uint8ClampedArray 自动将值限制在 0-255 data[i] += brightness; // R data[i + 1] += brightness; // G data[i + 2] += brightness; // B }
