# 10. 文本区域定位 (Text Localization)

## 学习目标

文本区域定位是从图像中找出包含文字区域的技术，是 OCR 流程中连接预处理和识别的桥梁。本章将帮助你掌握：

1. **区域特征筛选** - 基于连通域属性筛选文字区域
2. **投影分析** - 水平投影分割行，垂直投影分割字符
3. **RLSA 算法** - 游程平滑算法，连接同一行的字符
4. **文字行检测** - 从图像中检测并分割文字行
5. **字符分割** - 从文字行中分割出单个字符
6. **字符排序** - 按阅读顺序排列字符

## 核心概念

### 1. 从“几块像素”到“按顺序读哪几个字”

第 09 章已经能找出连通域，但它只说明哪些像素相连。识别器还需要知道：哪些块值得当作文字候选，它们各属于哪一行，应该从哪里裁出字符，又应该按什么顺序读取。

本章输入是经过预处理的黑字白底二值图，输出是**按阅读顺序排列的字符边界框**。框的形式是 `{x,y,width,height}`：左上角坐标、宽度和高度，单位都是像素。框里是什么字，要到第 12、13 章才开始判断。

用一个小例子贯穿本章。`#` 表示黑色前景，`.` 表示白色背景，图像宽 7、高 7，坐标从 0 开始：

```text
       x=0123456
y=0      .......
y=1      .##.##.
y=2      .##.##.
y=3      .......
y=4      ......#
y=5      .##....
y=6      .##....
```

我们把三个 2×2 方块当作教学字符，把 `(6,4)` 的独立像素当作噪点。目标是去掉噪点，找到两行、三个字符，并按“第一行左、第一行右、第二行”输出。这里只演示定位，方块没有真实字符含义。

### 2. 区域筛选：每个阈值到底筛什么

先对上图做第 09 章的 8 连通标记，得到四个区域。三个方块的前景面积都是 4，噪点面积是 1。若设 `minArea=2`，三个方块保留，噪点被删除。

| 参数或属性 | 含义与单位 | 怎样理解 |
|---|---|---|
| `minArea / maxArea` | 前景像素数的下限、上限 | 统计实际墨迹，不是外框面积 |
| `aspectRatio` | 框宽 / 框高，无单位 | 2×2 方块为 1；2×10 细条为 0.2 |
| `fillRatio` | 前景面积 / 框面积，无单位 | 实心 2×2 方块为 1，有空洞则更小 |
| 区域位置 | 框或质心的坐标，单位像素 | 留给后面的分行与排序使用 |

`filterCandidateCharacters` 将面积、宽高比、填充率条件一起检查，全部通过才保留。通过不代表“已证实是文字”，只是形状没有被规则排除；表格块也可能通过，小标点又可能被误删。

共享主流程的默认值是面积 30–10000、宽高比 0.1–5、填充率至少 0.1，适用于演示图的尺度。本章 7×7 小图必须把最小面积改小，否则连教学字符也会被删除。实际照片缩放后，像素面积和宽高会变化，阈值也要重新核对。

#### 筛选结果怎样进入后续计算

筛选后创建一张同尺寸白图，只把保留区域的**真实前景像素**画回去，这张图叫 `filteredImageData`，也可以理解为候选区域掩码。掩码表示保留哪些位置，不是把候选边界框全部涂黑。

这样，刚才噪点所在的第 4 行变成全白，之后的投影才不会把它误当成文字行。如果只打印“筛出了三个候选”，却仍对原图投影，噪点就没有真正退出流程。若填满整个边界框，则会抹掉字符内部的洞和空隙，同样会改变分割结果。

### 3. 投影：用一排计数找行，再用一排计数找字

#### 水平投影找文字行

水平投影统计每一像素行的黑像素数，第 07 章用它评价整齐程度，本章用它寻找文字出现的连续区间。

令 `F(x,y)` 在灰度小于 128 时等于 1，否则等于 0。这叫前景指示函数，只是在计算时把“黑像素”记作一次计数；`P_row[y]=Σx F(x,y)` 就是把第 y 行这些 1 加起来，数组长度是图高 H。

删掉噪点后，贯穿算例的投影为：

```text
行号：       0  1  2  3  4  5  6
黑像素数：   0  4  4  0  0  2  2
是否有文字： 否 是 是 否 否 是 是
```

若有效行的条件设为“计数大于 0”，连续的第 1、2 行组成第一行文字，第 5、6 行组成第二行文字。得到两个行框：

```text
第一行：{x:0,y:1,width:7,height:2}
第二行：{x:0,y:5,width:7,height:2}
```

行检测暂时保留全图宽度，下一步再沿每行的列方向切字。

#### 投影阈值是一个比例换算出来的数量

有噪声时，可以要求计数超过一定门槛。令 `ratio` 为比例，`maxProjection` 为当前投影数组中的最大值：

```text
threshold = maxProjection × ratio
有效位置条件：projection[i] > threshold
```

上例最大值是 4。`ratio=0.1` 时门槛是 0.4，计数 2 和 4 都通过；`ratio=0.5` 时门槛是 2，由于用的是严格大于，第二行文字的计数恰好为 2，就会被排除。比例增大让通过条件更严格，并不是“允许更大的文字间距”。

共享函数将行检测比例命名为 `projectionThreshold`。`minLineHeight` 则是一个连续区间至少有几行像素，单位是像素；本例设为 1，不能沿用默认的 10。

#### 垂直投影在每一行里找字符

对已经定位的第一行，只数这个行框范围内每一列的黑像素：

```text
列号：       0  1  2  3  4  5  6
黑像素数：   0  2  2  0  2  2  0
```

`P_col[x]=Σy F(x,y)` 表示列计数。这里求和只遍历当前文字行，不是重新统计整页。计数连续大于 0 的列 1、2 和列 4、5 分别形成一个字符框：

```text
{x:1,y:1,width:2,height:2}
{x:4,y:1,width:2,height:2}
```

对第二行同样处理，得到 `{x:1,y:5,width:2,height:2}`。字符分割的比例叫 `gapThreshold`，作用方式仍是“最大列计数乘以比例”；`minCharWidth` 是至少连续几列，本例也设为 1。

#### 区间的右端为什么不包含在内

数组 `[0,3,3,0,2]` 中，非零连续段对应下标 1、2，以及下标 4。代码常把它们写成 **半开区间** `[1,3)` 与 `[4,5)`：左端包含、右端不包含，长度分别直接算成 `3−1=2`、`5−4=1`。

扫描到背景时，前一个区间就结束了。但如果最后一个元素仍是前景，后面没有真实背景触发结束动作，怎么办？让循环额外走到数组长度那个位置，视作一次“结束信号”，把最后一段收起来。这就是末尾哨兵的作用，不是在图里增加真实像素。

边界框也遵守相同约定：x 到 `x+width−1` 属于框内，`x+width` 已经在框外。若只截取了一个局部行框，局部列下标 `dx` 还需要加上行框起点：`全图x=line.x+dx`。例如行框从全图 x=20 开始，局部第 3 列对应全图 x=23。

### 4. RLSA：跨过较短的空白，把相邻区域连起来 ⭐

有时我们想找一整行文字的范围，而不是立刻切出每个字。这时可以把字符之间的短空白补成前景，让同行字符先连成一个块。RLSA（Run Length Smoothing Algorithm，游程平滑）中的“游程”就是连续的一段相同像素。

水平 RLSA 从左到右扫描一行，记住上一个前景位置。遇到下一个前景时，计算它们之间的背景像素数：

```text
gap = 当前前景的 x − 上一个前景的 x − 1
```

两端的前景不算间隙，所以要减 1。例如前景在 x=1 和 x=4，中间是 x=2、3 两个背景像素，gap=2。若阈值为 2，就把它们填上。

```text
阈值为 3，# 为前景，_ 为背景：
输入：# _ _ # _ _ _ _ # _ #
间隙：  2个      4个     1个
输出：# # # # _ _ _ _ # # #
```

只填两个前景之间、长度不大于阈值的空白。行首和行尾只有一端前景的空白不会被填充，图像外也不虚构前景。垂直 RLSA 则将相同逻辑用于每一列。

阈值单位是背景像素个数，不是灰度，也不是比例。先测希望连接的字间距，再让阈值覆盖这些间隙，同时小于不应连接的栏间距。平均字符宽度的 1–2 倍可以作一个实验起点，不能当成固定标准；垂直连接尤其容易把相邻两行并在一起。

**RLSA 后的图适合估计行块，不能直接作为字符识别图。** 填过的空白已经改变笔画和字间距。通常用连接图找到行框，再回到未连接的二值图中裁剪。实验页的水平、垂直和组合 RLSA 是连接效果对照，主流程不会先把整行涂成一块再假装还能按空白切字。这里也没有复现原始版面分析系统的全部逻辑组合和区域分类步骤。

### 5. 文字行检测的三条路线

| 方法 | 从什么信息出发 | 怎样得到行 | 容易遇到的问题 |
|---|---|---|---|
| 水平投影 | 每行墨迹数量 | 找连续有效区间 | 倾斜或不同栏的内容混在同一行计数里 |
| RLSA + 连通域 | 邻近字符之间的空白 | 连接后提取大块边界框 | 阈值太大，跨行或跨栏合并 |
| 区域聚类 | 每个候选区域的中心高度 | 中心高度相近就分在同组 | 混合字号、标点和多栏会干扰分组 |

“聚类”在这里就是分组。`groupRegionsIntoLines` 先按候选区域的质心 y 排序，再依次与当前组的平均 y 比较。若差的绝对值不超过 `lineThreshold`，就加入当前行，并更新平均值；否则开始新行。

例如中心 y 为 10、12、30，容忍阈值为 5：10 先成一组，12 与 10 相差 2，加入后平均为 11；30 与 11 相差 19，另成一组。默认阈值为平均字符高度的 0.5 倍，单位是像素。这是同行中心能偏离多少的容忍量，不是两行之间的间距。

### 6. 字符分割：空白能切开的范围有多大

本章主流程在每个文字行中使用垂直投影找连续列区间，也提供基于连通域筛选字符的函数。两者解决的问题略有不同：

- 投影可以把水平范围重叠的断裂笔画放进同一列区间，但没有低谷时无法把两个连笔字拆开。
- 连通域能跟踪笔画实际连接关系，但字母 i 的点可能单独成块，粘连的两个字也可能成为一块。

发现过宽字符，可以尝试在其内部继续寻找低投影列；发现断裂，可参考高度、间距和重叠程度合并候选。这些是后处理思路，本章没有自动完成一般粘连分割与断裂合并。使用腐蚀或闭运算修补时，也要回看第 06 章对细笔画和错误连接的影响。

### 7. 字符排序：先确定行组，再比较左右

对本章的横排场景，阅读顺序是行从上到下、行内从左到右。贯穿算例最终应输出：

```text
(1,1,2,2) → (4,1,2,2) → (1,5,2,2)
每组四个数依次为 x、y、width、height。
```

不要简单按每个框的 y、x 连续排序：同一行几个字的顶部稍有高低，就可能先读完高处所有字，再回头读低处的字。`sortCharacters` 会先用框的中心高度分组，然后各组按 x 排序，最后逐行合并。这里由框构造的中心，与有真实像素坐标时计算的墨迹质心要区分。

也不宜在一次排序比较中写“两个 y 很近就比较 x，否则比较 y”。例如 A 的 `(x,中心y)=(20,0)`、B=(10,4)、C=(0,8)，阈值 5：按这个规则 B 在 A 前、C 在 B 前，却又要求 A 在 C 前，形成互相矛盾的顺序。先分组，组别固定后再比较，排序规则才一致。

这种中心阈值分组仍是简化方法，不负责竖排、多栏以及复杂版面的阅读顺序恢复。

## 算法实现

### 1. 区域筛选实现

`regions` 是第 09 章输出的区域属性数组。下面逐个检查区域，返回 `true` 才把它留在数组中；它本身不修改图像，后续要把保留的像素绘制成候选图。

```javascript
/**
 * 筛选候选字符区域
 *
 * @param {object[]} regions - 连通域区域属性数组
 * @param {object} options - 筛选参数
 * @returns {object[]} 候选字符区域
 */
function filterCandidateCharacters(regions, options = {}) {
    const {
        minArea = 30,           // 最小面积
        maxArea = 10000,        // 最大面积
        minAspectRatio = 0.1,   // 最小宽高比
        maxAspectRatio = 5.0,   // 最大宽高比
        minFillRatio = 0.1      // 最小填充率
    } = options;

    return regions.filter(region => {
        // 面积筛选
        if (region.area < minArea || region.area > maxArea) return false;
        // 宽高比筛选
        if (region.aspectRatio < minAspectRatio) return false;
        if (region.aspectRatio > maxAspectRatio) return false;
        // 填充率筛选
        if (region.fillRatio < minFillRatio) return false;

        return true;
    });
}
```

### 2. RLSA 算法实现

`lastForegroundX` 记住上一个前景横坐标，`gap` 就是两者之间的背景数。初值设得足够靠左，保证首个前景之前的空白不会满足填充条件。`pixel.r` 是灰度图的 R 通道，低于 128 计作黑色前景。

```javascript
/**
 * 水平 RLSA（游程平滑算法）
 *
 * @param {ImageData} imageData - 二值图像
 * @param {number} threshold - 连接阈值
 * @returns {ImageData} 处理后的图像
 */
function horizontalRLSA(imageData, threshold) {
    const { width, height } = imageData;
    const result = cloneImageData(imageData);

    for (let y = 0; y < height; y++) {
        let lastForegroundX = -threshold - 1;

        for (let x = 0; x < width; x++) {
            const pixel = getPixel(result, x, y);

            if (pixel.r < 128) { // 前景像素
                // 检查与上一个前景像素的距离
                const gap = x - lastForegroundX - 1;

                if (gap > 0 && gap <= threshold) {
                    // 填充中间的背景像素
                    for (let i = lastForegroundX + 1; i < x; i++) {
                        setPixel(result, i, y, 0, 0, 0);
                    }
                }

                lastForegroundX = x;
            }
        }
    }

    return result;
}
```

### 3. 投影分析检测文字行

`inLine` 表示当前是否已经进入一个文字区间；`lineStart` 记开始行。遇到背景或数组末尾，计算区间高度并输出框。循环允许 `y===height`，就是前面解释的末尾结束信号。

```javascript
/**
 * 使用投影分析检测文字行
 *
 * @param {ImageData} imageData - 二值图像
 * @param {object} options - 配置选项
 * @returns {object[]} 文字行边界框数组
 */
function detectTextLines(imageData, options = {}) {
    const {
        minLineHeight = 10,        // 最小行高
        projectionThreshold = 0.1  // 投影阈值（相对于最大投影值）
    } = options;

    const { width, height } = imageData;

    // 计算水平投影
    const projection = calculateHorizontalProjection(imageData);

    // 找到投影阈值
    const maxProjection = projection.reduce((max, value) => Math.max(max, value), 0);
    const threshold = maxProjection * projectionThreshold;

    // 检测行区域
    const lines = [];
    let inLine = false;
    let lineStart = 0;

    for (let y = 0; y <= height; y++) {
        if (!inLine && y < height && projection[y] > threshold) {
            inLine = true;
            lineStart = y;
        } else if (inLine && (y === height || projection[y] <= threshold)) {
            inLine = false;
            const lineHeight = y - lineStart;
            if (lineHeight >= minLineHeight) {
                lines.push({
                    y: lineStart,
                    height: lineHeight,
                    x: 0,
                    width: width
                });
            }
        }
    }

    // 处理最后一行
    if (inLine) {
        const lineHeight = height - lineStart;
        if (lineHeight >= minLineHeight) {
            lines.push({
                y: lineStart,
                height: lineHeight,
                x: 0,
                width: width
            });
        }
    }

    return lines;
}
```

## 在 OCR 中的应用

### 完整的文本定位流程

```text
输入黑字白底二值图
→ 连通域标记与属性提取
→ 面积、宽高比、填充率筛选
→ 仅保留候选的真实像素
→ 水平投影找行
→ 每行垂直投影找字符
→ 先分行组、再按 x 排序
→ 输出有序的字符框，交给后续特征提取与识别
```

这是当前 `localizeText` 的实际路径。RLSA 加连通域、按区域中心聚类是本章介绍并提供组件的其他分行思路；一般粘连切分、偏旁合并和复杂阅读顺序仍需进一步实现。

### 不同场景的策略选择

| 场景 | 推荐方案 | 说明 |
|------|----------|------|
| 标准印刷文档 | 投影分析 | 行列整齐，投影分析效率高 |
| 扫描文档 | RLSA + 连通域 | 可能有噪点，RLSA 能连接断裂字符 |
| 自然场景文字 | 深度学习检测 | 背景复杂，传统方法效果有限 |
| 手写文字 | 连通域 + 后处理 | 笔画可能连写，需要特殊处理 |

## 实际主流程及限制

共享函数 `localizeText` 将本章步骤连起来：连通域分析 → 候选筛选 → 绘制真实候选像素 → 水平投影分行 → 行内垂直投影切字 → 排序。它返回原始区域、候选区域、筛选图、行框、字符框以及各自数量，便于逐步追踪问题出现在哪一步。

对开头的 7×7 图，可以这样配置；这些较小参数是为了让读者手算，不能直接作为照片默认参数：

```javascript
const result = localizeText(binaryImage, {
    minArea: 2,
    minLineHeight: 1,
    minCharWidth: 1,
    projectionThreshold: 0,
    gapThreshold: 0,
});
// result.stats：4 个原始区域、3 个候选、2 行、3 个字符
// result.characters：上文按顺序列出的三个边界框
```

若结果为空，先看候选图：可能面积门槛已把所有墨迹删掉，再调投影不会解决问题。若候选图正确、行框缺失，再看行高和投影比例。规则阈值可能误删标点、点状偏旁与细笔画，最终框仍是候选定位结果，需通过真实样本评价。

## 数学公式总结

### 投影阈值计算

```
阈值 = 最大投影值 × 比例因子

常用比例因子：
- 行检测：0.05 ~ 0.2
- 字符分割：0.0 ~ 0.1（0 表示只将零计数列作为间隔）
```

### 聚类阈值计算

```
同行中心差容忍阈值 = 平均字符高度 × 系数

本章默认系数0.5。它是同行中心位置的容忍误差，不是行间距；应小于不同行中心间隔。不能按“稀疏排版”盲目增大到1.5~2.0，否则可能把两行并为一行。
```

### RLSA 阈值计算

```
水平阈值 = 平均字符宽度 × 字符间距系数

字符间距系数：
- 中文（全角）：0.5 ~ 1.0
- 英文（半角）：1.0 ~ 2.0
```

## 常见问题与解决方案

### 1. 字符粘连

**问题**：两个或多个字符被识别为一个连通域

**解决方案**：
- 使用垂直投影二次分割
- 设置宽度阈值，对过宽区域进行分割
- 使用形态学腐蚀分离

### 2. 字符断裂

**问题**：一个字符被分成多个连通域

**解决方案**：
- 使用 RLSA 连接相近区域
- 形态学闭运算填补断裂
- 合并水平位置接近且垂直重叠的区域

### 3. 行间距不均

**问题**：文字行检测不准确

**解决方案**：
- 使用自适应阈值
- 基于连通域质心聚类
- 结合区域高度信息辅助判断

## 自测问题

1. 水平与垂直投影分别在哪个范围内统计、用于什么？
2. 最大投影为 4，比例为 0.5，计数 2 能通过吗？
3. 前景在 x=1 与 x=4，RLSA 间隙是多少？会填行首空白吗？
4. 为什么区域筛选后要画真实像素掩码，不能只数候选或填满框？
5. 如何面对粘连与断裂，为什么不能指望投影总能切出字符？
6. 为什么先分行组，再按左右排序？

<details>
<summary>点击查看答案</summary>

1. 水平投影统计整张候选图每行的前景数，用来找行；随后只在每个行框内统计各列前景，用来切字。

2. 不能。阈值为 2，判断使用严格大于；计数恰好为 2 会作为无效位置。

3. 间隙是 4−1−1=2 个背景像素。只填被前景两端包夹且长度不超过阈值的间隙，不填行首行尾空白。

4. 只有让被删区域退出实际投影输入，筛选参数才会影响结果；填满框则会抹掉字内孔洞和间隔。

5. 投影依赖低谷，没有低谷的连笔不能可靠拆开；断裂可能需要区域合并。可研究二次分割或形态学修补，但本章没有完整自动处理所有粘连与断裂。

6. 同一行的字可能上下错开。先固定组别再按 x 排序，能避免单纯按 y 打乱同行，也避免带成对容忍阈值的比较规则产生排序矛盾。

</details>
