# 10. 文本区域定位 (Text Localization)

## 学习目标

文本区域定位是从图像中找出包含文字区域的技术，是 OCR 流程中连接预处理和识别的桥梁。本章将帮助你掌握：

1. **区域特征筛选** - 基于连通域属性筛选文字区域
2. **投影分析** - 水平投影分割行，垂直投影分割字符
3. **RLSA 算法** - 游程平滑算法，连接同一行的字符
4. **文字行检测** - 从图像中检测并分割文字行
5. **字符分割** - 从文字行中分割出单个字符
6. **字符排序** - 按阅读顺序排列字符

## 核心概念

### 1. 文本区域定位的作用

文本区域定位是 OCR 流程的关键步骤，位于预处理和识别之间：

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          OCR 完整流程                                     │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  输入图像 → 预处理 → [文本区域定位] → 字符识别 → 后处理 → 输出文本      │
│                            ↑                                            │
│                       当前学习                                           │
│                                                                          │
│  文本区域定位的子任务：                                                   │
│  1. 区域筛选：从连通域中筛选文字区域                                      │
│  2. 文字行检测：将文字区域组织成行                                        │
│  3. 字符分割：将每行分割为单个字符                                        │
│  4. 字符排序：按阅读顺序排列                                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**为什么需要文本区域定位？**

- 图像中可能有非文字内容（图形、装饰、噪点）
- 需要将分散的连通域组织成有序的文字序列
- 识别器通常只处理单个字符或单行文字

### 2. 区域特征筛选

基于连通域的属性筛选可能的文字区域：

```
┌──────────────────────────────────────────────────────────────────┐
│                    区域筛选特征                                    │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────┐    筛选条件：                                      │
│  │          │    • 面积：去除太小（噪点）或太大（背景）           │
│  │  连通域  │    • 宽高比：字符通常在 0.2 ~ 5.0 之间              │
│  │          │    • 填充率：字符区域较紧凑（> 0.1）                │
│  └──────────┘    • 位置：文字通常成行排列                         │
│       ↓                                                          │
│  ┌──────────┐                                                    │
│  │  候选    │    结果：筛选出可能是字符的区域                     │
│  │  字符    │                                                    │
│  └──────────┘                                                    │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**典型筛选参数（需根据实际调整）：**

| 参数 | 印刷体 | 手写体 | 说明 |
|------|--------|--------|------|
| 最小面积 | 30 | 20 | 去除噪点 |
| 最大面积 | 10% 图像面积 | 20% | 去除大块区域 |
| 宽高比 | 0.2 ~ 3.0 | 0.1 ~ 5.0 | 字符形状约束 |
| 填充率 | > 0.15 | > 0.1 | 紧凑程度 |

### 3. 投影分析

投影分析是文字行检测和字符分割的核心技术。

#### 水平投影（Horizontal Projection）

统计每行的前景像素数量，用于检测文字行：

```
原始二值图：                      水平投影：
┌──────────────────┐             
│ ████  ███  ██   │─────────────→ ████████████ (多)
│                 │─────────────→             (少)
│ ██  ████  ███   │─────────────→ ███████████  (多)
│                 │─────────────→             (少)
│ ███  ██  ████   │─────────────→ ████████████ (多)
└──────────────────┘             

分析：
• 峰值（投影值大）= 文字行位置
• 谷值（投影值小）= 行间距位置
• 通过阈值分割可以定位每一行
```

#### 垂直投影（Vertical Projection）

统计每列的前景像素数量，用于分割字符：

```
单行文字：
┌────────────────────────────────────┐
│  ██  │  █████ │ ███ │ ████        │
│  █   │  ███   │ █   │ ██          │
│ ████ │  █████ │ ████│ ████        │
└────────────────────────────────────┘
  ↓       ↓       ↓      ↓
 ┌─┐     ┌───┐   ┌──┐  ┌───┐
 │█│     │███│   │██│  │███│
 └─┘     └───┘   └──┘  └───┘
  ↓  谷   ↓  谷   ↓ 谷  ↓
  
分析：
• 峰值 = 字符位置
• 谷值（投影为 0 或很小）= 字符间隔
• 通过谷值分割可以定位每个字符
```

### 4. RLSA 算法（游程平滑算法）⭐

RLSA（Run Length Smoothing Algorithm）是一种连接相邻像素的算法，常用于将同一行的字符连接成文字块。

```
┌──────────────────────────────────────────────────────────────────┐
│                    RLSA 算法原理                                   │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  基本思想：                                                       │
│  - 扫描每一行（水平 RLSA）或每一列（垂直 RLSA）                   │
│  - 如果两个前景像素之间的背景像素数 ≤ 阈值，则填充为前景          │
│  - 结果是将相近的前景区域连接起来                                  │
│                                                                  │
│  示例（阈值 = 3）：                                               │
│                                                                  │
│  原始：  █ _ _ █ _ _ _ _ █ _ █                                   │
│  结果：  █ █ █ █ _ _ _ _ █ █ █                                   │
│          └─┴─┘           └─┘                                     │
│        间隔≤3，填充    间隔≤3，填充                               │
│                                                                  │
│  用途：                                                           │
│  - 水平 RLSA：连接同一行的字符，形成文字行块                      │
│  - 垂直 RLSA：连接上下相邻的内容                                   │
│  - 水平 + 垂直 RLSA：可以形成段落块                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**RLSA 参数选择：**

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 水平阈值 | 字符平均宽度的 1~2 倍 | 连接同一行字符 |
| 垂直阈值 | 行高的 0.5~1 倍 | 连接多行文字 |

### 5. 文字行检测

文字行检测是将字符组织成行的过程：

```
┌──────────────────────────────────────────────────────────────────┐
│                    文字行检测方法                                   │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  方法一：基于投影分析                                              │
│  ─────────────────                                               │
│  1. 计算水平投影                                                  │
│  2. 通过阈值检测峰值区域                                           │
│  3. 每个连续峰值区域对应一行                                       │
│                                                                  │
│  方法二：基于 RLSA + 连通域                                       │
│  ────────────────────────                                        │
│  1. 对二值图应用水平 RLSA（连接同行字符）                          │
│  2. 对结果进行连通域分析                                           │
│  3. 每个连通域对应一个文字行块                                     │
│  4. 提取每个块的边界框作为行区域                                   │
│                                                                  │
│  方法三：基于连通域聚类                                            │
│  ─────────────────────                                           │
│  1. 获取所有候选字符的边界框                                       │
│  2. 按 Y 坐标（质心）对字符聚类                                    │
│  3. Y 坐标接近的字符归为同一行                                     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 6. 字符分割

从文字行中分割出单个字符：

```
┌──────────────────────────────────────────────────────────────────┐
│                    字符分割方法                                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  方法一：基于垂直投影                                              │
│  ─────────────────                                               │
│  1. 对文字行区域计算垂直投影                                       │
│  2. 找到投影值为 0 或很小的位置（谷值）                            │
│  3. 在谷值位置分割                                                 │
│                                                                  │
│  优点：简单高效                                                    │
│  缺点：对连笔字或倾斜字符效果差                                     │
│                                                                  │
│  方法二：基于连通域                                                │
│  ─────────────────                                               │
│  1. 对文字行进行连通域分析                                         │
│  2. 每个连通域视为一个字符                                         │
│                                                                  │
│  优点：适合分离良好的印刷体                                        │
│  缺点：可能将断开的笔画分为多个区域                                 │
│                                                                  │
│  实际应用：通常结合两种方法                                        │
│  1. 先用连通域分析初步分割                                         │
│  2. 对过宽的区域用垂直投影二次分割                                 │
│  3. 对过窄的相邻区域考虑合并                                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```


## 算法实现

### 1. 区域筛选实现

```javascript
/**
 * 筛选候选字符区域
 * 
 * @param {object[]} regions - 连通域区域属性数组
 * @param {object} options - 筛选参数
 * @returns {object[]} 候选字符区域
 */
function filterCandidateCharacters(regions, options = {}) {
    const {
        minArea = 30,           // 最小面积
        maxArea = 10000,        // 最大面积
        minAspectRatio = 0.1,   // 最小宽高比
        maxAspectRatio = 5.0,   // 最大宽高比
        minFillRatio = 0.1      // 最小填充率
    } = options;
    
    return regions.filter(region => {
        // 面积筛选
        if (region.area < minArea || region.area > maxArea) return false;
        // 宽高比筛选
        if (region.aspectRatio < minAspectRatio) return false;
        if (region.aspectRatio > maxAspectRatio) return false;
        // 填充率筛选
        if (region.fillRatio < minFillRatio) return false;
        
        return true;
    });
}
```

### 2. RLSA 算法实现

```javascript
/**
 * 水平 RLSA（游程平滑算法）
 * 
 * @param {ImageData} imageData - 二值图像
 * @param {number} threshold - 连接阈值
 * @returns {ImageData} 处理后的图像
 */
function horizontalRLSA(imageData, threshold) {
    const { width, height } = imageData;
    const result = cloneImageData(imageData);
    
    for (let y = 0; y < height; y++) {
        let lastForegroundX = -threshold - 1;
        
        for (let x = 0; x < width; x++) {
            const pixel = getPixel(result, x, y);
            
            if (pixel.r < 128) { // 前景像素
                // 检查与上一个前景像素的距离
                const gap = x - lastForegroundX - 1;
                
                if (gap > 0 && gap <= threshold) {
                    // 填充中间的背景像素
                    for (let i = lastForegroundX + 1; i < x; i++) {
                        setPixel(result, i, y, 0, 0, 0);
                    }
                }
                
                lastForegroundX = x;
            }
        }
    }
    
    return result;
}
```

### 3. 投影分析检测文字行

```javascript
/**
 * 使用投影分析检测文字行
 * 
 * @param {ImageData} imageData - 二值图像
 * @param {object} options - 配置选项
 * @returns {object[]} 文字行边界框数组
 */
function detectTextLines(imageData, options = {}) {
    const {
        minLineHeight = 10,        // 最小行高
        projectionThreshold = 0.1  // 投影阈值（相对于最大投影值）
    } = options;
    
    const { width, height } = imageData;
    
    // 计算水平投影
    const projection = calculateHorizontalProjection(imageData);
    
    // 找到投影阈值
    const maxProjection = Math.max(...projection);
    const threshold = maxProjection * projectionThreshold;
    
    // 检测行区域
    const lines = [];
    let inLine = false;
    let lineStart = 0;
    
    for (let y = 0; y < height; y++) {
        if (!inLine && projection[y] > threshold) {
            inLine = true;
            lineStart = y;
        } else if (inLine && projection[y] <= threshold) {
            inLine = false;
            const lineHeight = y - lineStart;
            if (lineHeight >= minLineHeight) {
                lines.push({
                    y: lineStart,
                    height: lineHeight,
                    x: 0,
                    width: width
                });
            }
        }
    }
    
    // 处理最后一行
    if (inLine) {
        const lineHeight = height - lineStart;
        if (lineHeight >= minLineHeight) {
            lines.push({
                y: lineStart,
                height: lineHeight,
                x: 0,
                width: width
            });
        }
    }
    
    return lines;
}
```

## 数学公式总结

### 投影阈值计算

```
阈值 = 最大投影值 × 比例因子

常用比例因子：
- 行检测：0.05 ~ 0.2
- 字符分割：0.0 ~ 0.1（更严格）
```

### 聚类阈值计算

```
行间距阈值 = 平均字符高度 × 系数

常用系数：
- 紧凑排版：0.5 ~ 1.0
- 标准排版：1.0 ~ 1.5
- 稀疏排版：1.5 ~ 2.0
```

### RLSA 阈值计算

```
水平阈值 = 平均字符宽度 × 字符间距系数

字符间距系数：
- 中文（全角）：0.5 ~ 1.0
- 英文（半角）：1.0 ~ 2.0
```

## 常见问题与解决方案

### 1. 字符粘连

**问题**：两个或多个字符被识别为一个连通域

**解决方案**：
- 使用垂直投影二次分割
- 设置宽度阈值，对过宽区域进行分割
- 使用形态学腐蚀分离

### 2. 字符断裂

**问题**：一个字符被分成多个连通域

**解决方案**：
- 使用 RLSA 连接相近区域
- 形态学闭运算填补断裂
- 合并水平位置接近且垂直重叠的区域

### 3. 行间距不均

**问题**：文字行检测不准确

**解决方案**：
- 使用自适应阈值
- 基于连通域质心聚类
- 结合区域高度信息辅助判断

1. **水平投影**用于检测文字行（统计每行的前景像素数，峰值对应文字行）；**垂直投影**用于分割字符（统计每列的前景像素数，谷值对应字符间隔）。

2. RLSA（游程平滑算法）用于连接相近的前景像素。水平 RLSA 可以将同一行的字符连接成文字块。阈值选择：水平阈值通常设为字符平均宽度的 1~2 倍，垂直阈值设为行高的 0.5~1 倍。

3. 处理字符粘连的方法：
   - 使用垂直投影找到谷值位置分割
   - 设置宽度阈值，对过宽的区域进行二次分割
   - 使用形态学腐蚀操作分离粘连区域

4. OCR 识别器输出的字符需要按阅读顺序组织成有意义的文本。如果不排序，识别结果会是乱序的，无法正确还原原始文字内容。

5. **投影分析法**：优点是简单高效，适合整齐排列的印刷体文档；缺点是对倾斜、不规则排列的文字效果差。**连通域法**：优点是能处理各种形态的文字区域；缺点是可能将断裂字符分成多个区域，需要后处理合并。
