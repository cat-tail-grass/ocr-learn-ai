# 13. KNN 分类器 (K-Nearest Neighbors)

## 学习目标

模板匹配在“标准字体 + 干净图像”场景下效果不错，但它只看“一个最近模板”。KNN 分类器会看 **K 个最近邻**，通过投票决定类别，鲁棒性更强。

本章你将掌握：

1. **KNN 算法原理**：距离最近的 K 个样本共同决定分类结果
2. **距离度量选择**：欧氏距离、曼哈顿距离、余弦距离、相关距离
3. **K 值选择策略**：K 过小易过拟合，K 过大易欠拟合
4. **训练 / 验证 / 测试集**：验证集选参数，冻结后用独立测试集评估
5. **准确率评估**：准确率、拒识率、混淆矩阵

## 核心概念

### 1. KNN 的核心思想

KNN 是一种“**懒惰学习（Lazy Learning）**”算法：

- 训练阶段：几乎不做参数学习，只保存样本
- 预测阶段：计算输入样本与训练样本的距离
- 从最近的 K 个邻居中投票，得出最终类别

```
输入字符特征 x
    ↓
与所有训练样本计算距离
    ↓
排序，取前 K 个最近邻
    ↓
多数投票 / 加权投票
    ↓
输出预测类别
```

---

### 2. K 值的影响

- **K = 1**：边界非常灵活，容易受噪声影响（高方差）
- **K = 3 或 5**：通常是较稳妥的起点
- **K 很大**：决策更平滑，但可能忽略局部细节（高偏差）

经验建议：

1. 从 `K=3` 开始
2. 在验证集上比较 `K = [1,3,5,7,9]`
3. 选择准确率最高且稳定的 K

---

### 3. 多数投票 vs 加权投票

#### 普通投票（Majority Voting）

每个邻居 1 票：

- 简单
- 对离群点敏感

#### 加权投票（Distance Weighted Voting）

距离越近，权重越大：

- 常见权重：`w = 1 / (d + ε)`
- 更重视“最近邻”的信息
- 让较近邻居有更大影响；是否优于普通投票需要验证，异常近邻也可能被放大

---

### 4. 训练、验证与测试集

机器学习里不能只看“训练集识别效果”。

推荐流程：

1. 准备样本来源信息；先按原图或书写者分组，再划分训练、验证、测试，所有派生增强继承原分组。
2. 训练：保存训练特征；若使用数据集级标准化，只在训练集拟合统计量。
3. 调参：仅在验证集比较K、距离、投票方式和拒识阈值。
4. 冻结选择后的配置，在测试集评估一次。根据测试错误再次改参数，就把该集用于了开发，不能继续叫未见测试。

默认Node与HTML共用 `shared/13-knn-classifier/demoDataset.js`：固定种子20260911，12个程序化造字配置先分为6/3/3组；训练每组10类各3种变体，共180张，验证与测试各30张。各分区sourceId互斥；它们仍来自同一造字器和基础数字形状，不能据此宣称真实手写者泛化。先在验证集比较K∈{1,3,5,7,9}及普通/加权投票，同分先选较小K、再选普通投票；测试结果不参与选择。页面手动调K的结果属于探索，不是一次新的独立测试。

例：测试准确率K=1为90%、K=3为95%，若据此选择K=3再宣传95%，已用测试集选模型。正确做法是在验证集选K，再在未参与选择的样本上评估。参见[官方数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)。

---

### 5. 评估指标

#### 5.1 准确率 (Accuracy)

`Accuracy = 正确样本数 / 总样本数`

#### 5.2 混淆矩阵 (Confusion Matrix)

用来观察“哪些类别容易混淆”。例如：

- 真实 `0` 被预测成 `8`
- 真实 `1` 被预测成 `7`

#### 5.3 拒识率 (Rejection Rate)

当最近邻距离超过阈值时，输出“未知字符（REJECTED）”：

- 规则是最近距离 `d>threshold` 才拒识；降低阈值更严格，提高阈值接受更多样本。
- 被接受子集可能更准，但所有合法测试样本的准确率仍以总数为分母，拒识算未正确识别；同时单列拒识率。
- 演示中的0.85是未校准的课堂参数，不能作为不同特征或真实照片的通用阈值。

## 与模板匹配的关系

| 方法 | 决策依据 | 优点 | 局限 |
|------|----------|------|------|
| 模板匹配 | 1 个最近模板 | 简单直观 | 对噪声/变形敏感 |
| KNN | K 个最近样本投票 | 可利用多个邻居，效果需验证 | 预测时计算量更大 |

当模板匹配也使用相同特征、距离与最近样本决策时，1-NN与它对应。更大的K是否更鲁棒取决于数据覆盖与噪声，不能保证优于模板匹配：

- 模板匹配：`K = 1`
- KNN：`K >= 1`，并支持投票策略
