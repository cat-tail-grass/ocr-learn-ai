# 22. 文本检测网络：EAST、DBNet 与可检查的后处理

检测回答“文字在哪里”，识别回答“写了什么”。本章把网络预测与几何后处理分开检查：先看 EAST 如何表达旋转文字框，再计算 DB 的软二值图和梯度，最后将预测图转成区域记录。

**实现边界：本章提供真实运行的核心运算，不提供已训练的 EAST/DBNet 主干。** 默认 P/T 是公式合成的预测场；四邻域连通域、轴对齐包围框、矩形扩张和普通 NMS 是可阅读的后处理实验。它们没有文字语义，也不能测量真实照片检测精度。调整灰度阈值并不等于实现了 DBNet。

读本章时，要一直区分三类数：灰度是照片中一个像素有多亮；P 是网络认为一个位置有多像文字的预测值；区域 score 是把多个位置的预测汇总得到的分数。三者即使都画成黑白图，也不代表含义相同。

本章按“预测什么 → 怎样变成框 → 框怎样回到原图”的顺序阅读。EAST 用几何距离直接描述框；DBNet 用预测图描述文字区域。下面分别用小数值说明它们的核心步骤。

## 学习目标、前置知识与 OCR 位置

学习后应能解释多方向文字为何需要旋转框/多边形；追踪 EAST 的 score/geometry 维度；推导 DB 的前向与导数；区分训练分支和推理分支；检查阈值、区域评分、扩张、NMS、缩放还原各步的影响。

前置知识：第04章二值化，第09章连通域，第10章传统文本定位，第15章 CNN 特征图，第14章链式法则。尤其要区分像素灰度、网络文本概率与区域置信分数三种量。

```text
整张照片
  → 缩放/归一化
  → 检测网络：文字概率、几何或分割图
  → [阈值、轮廓/连通域、恢复框、筛选、坐标还原]
  → 文字区域裁剪/矫正
  → 识别器（CRNN、Transformer、分割后 CNN 等）
  → 字符串与评估
```

第一版第25章面向白纸、有基本间隔的单行数字，复用传统定位与分割，不强制部署通用检测网络。本章用于解释更复杂背景、方向与区域定位的另一条路线。

## 1. 从连通域到学习式检测

### 动机与表示能力

在简单白纸上，二值化后相邻笔画容易形成明显区域；在街景上，窗格、树枝和阴影也可能有强边缘。传统阈值只利用像素及局部统计，神经检测器通过标注学习哪些视觉模式更像文字。网络输出仍需转换为几何对象，后处理是接口的一部分。

| 表示 | 参数量（每候选） | 能表达什么 | 主要局限 |
|---|---:|---|---|
| 轴对齐矩形 | 4 | 水平区域或粗包围 | 斜长文字会包含大量背景 |
| 旋转矩形 RBOX | 5 | 有统一方向的文字行 | 不能精确贴合任意弯曲边界 |
| 四边形 QUAD | 8 | 透视变形下的四角区域 | 弧线仍无法用四条直边精确表示 |
| 像素/多边形 | 与轮廓复杂度相关 | 更一般的区域形状 | 分离实例、轮廓质量和后处理更关键 |

### 具体几何代价

设一个宽20、高4的矩形转45°。其轴对齐包围宽高都为 `(20+4)/√2≈16.97`，包围面积约288；真实旋转矩形面积为80。外接框多含208的背景面积，约为真实面积的2.6倍。这解释了斜长文本用轴对齐 IoU 做抑制时可能误删的原因。

实现时应先确定输出表示，再决定解码器和后处理。不能用“画出了框”推断框内一定有完整字符；截断、方向、阅读顺序都影响下游识别。

## 2. EAST：直接预测分数与几何

### 网络思想与输出维度

EAST 用多尺度特征融合后预测文本分数和几何。论文提供 RBOX/QUAD 两种输出设计，随后恢复候选区域并去除重复预测。核验依据为 [EAST 原论文 §3](https://arxiv.org/html/1704.03155v2)。

输入 H、W 是照片的高宽，3 表示 RGB 三个颜色通道。输出步幅 stride=4 表示：预测图相邻两格，在输入图上隔 4 像素，因此预测图更小。下面假设 H、W 能被 4 整除，输出高宽分别为 H′=H/4、W′=W/4；F 是网络融合后的特征。

同一预测位置分出两组结果：score 给文字分数，geometry 给框的几何信息：

```text
多尺度特征 → 融合特征 F
              ├→ score：H'×W'×1
              └→ RBOX ：H'×W'×5
                  或 QUAD：H'×W'×8
```

RBOX的五个量是 `(top,right,bottom,left,θ)`。四条距离从当前特征图位置对应的图像点出发，指向矩形边界；θ表示矩形朝向。QUAD用四个顶点相对当前像素的八个坐标偏移；论文§3.2/3.3.2将方向描述为从顶点到像素，因此若记为 `Δᵢ=a−pᵢ`，恢复顶点应为 `pᵢ=a−Δᵢ`，不能直接反向相加。本章未实现QUAD解码；接入成品模型时核对其偏移正负号、角点顺序及 NCHW/NHWC 布局。

输入320×640，步幅4时 score 为80×160×1，RBOX为80×160×5，共有12,800个分数和64,000个几何量。12,800不是“文字数量”，只是候选预测位置数。

### 动机：为何不用每个像素直接回归绝对四角

同一文本内部许多位置都能预测它的边界，用相对距离可使几何与当前位置联系更清楚；多个位置预测同一文本又必然产生冗余，因此不能省略候选筛选与抑制。论文还使用收缩后的内部区域作为部分监督目标，避免相邻区域边界含混。

### 本章的坐标约定与恢复公式

本地接口规定图像坐标 x向右、y向下，θ正值为**图像坐标顺时针**，弧度为单位。不同成品模型对θ的符号和角点起始次序可能不同，不能直接照搬本约定。

先把预测图上的位置换回输入图：s 是步幅，预测图 `(x,y)` 对应输入图的参考点 `a=(s×x,s×y)`，称为锚点。例如 `(2,3)`、步幅 4，就对应输入像素坐标 `(8,12)`。

t、r、b、l 分别是从锚点到矩形上、右、下、左四边的距离，单位已经是**输入图像像素**。先假装框没旋转，把锚点当作局部原点，四角相对它的位置便是：

\[
(-l,-t),\quad(r,-t),\quad(r,b),\quad(-l,b).
\]

例如左上角要向左走 l、向上走 t，所以是 `(−l,−t)`。对任意一个局部角点 `(u,v)`，先按角度 θ 旋转，再加回锚点坐标，就得到真正的图像角点 `(x′,y′)`：

\[
x'=sx+u\cos\theta-v\sin\theta,\quad
y'=sy+u\sin\theta+v\cos\theta.
\]

这里t/r/b/l已经以图像像素为单位，只给锚点乘stride。若模型的距离单位是特征图像素，调用方应先明确换算，不能在不知单位时重复缩放。

### 可手算例子与代码

输入 `x=2,y=3,s=4,t=1,r=3,b=2,l=2`：锚点为(8,12)。θ=0时四角为：

```text
(6,11), (11,11), (11,14), (6,14)
宽=5，高=3，面积=15
```

θ=π/2时 `cosθ=0,sinθ=1`，局部点(−2,−1)映射到 `(8+1,12−2)=(9,10)`；四角依次为 `(9,10),(9,15),(6,15),(6,10)`。面积仍为15，朝向改变。

```javascript
const { decodeEastRBox } = require('../shared/22-text-detection-networks');
const box = decodeEastRBox({
  x: 2, y: 3, top: 1, right: 3, bottom: 2, left: 2,
  angle: Math.PI / 2, score: 0.9
}, 4);
// box.polygon 是四角；x0/y0/x1/y1 是轴对齐外接框。
```

具体步骤是验证距离非负与边长大于0→恢复锚点→列出局部四角→逐点旋转平移→取极值得到外接框。页面同时画出旋转框和外接框，以便看到两种表示的差异。返回坐标可以越出图像；尚未提供输入图像尺寸时不能擅自裁掉。

### 训练目标怎样约束几何

EAST训练同时监督文本分数与区域几何，RBOX几何使用与重叠及角度有关的损失。理解角度项可先看 `1−cos(θ̂−θ*)`：预测误差0时损失0，误差π/2时为1；它不是直接把角度差当普通距离。本章没有实现这些主干训练损失或论文的 locality-aware NMS，只演示几何解码与通用NMS，不能将二者的速度或精度混同。

## 3. DB：让二值化拥有可用于学习的导数

### 动机：硬阈值为什么妨碍这一段链式传播

第 04 章直接判断一个值是否超过阈值，输出只有 0 或 1。现在把被比较的数换成文字概率 P。如果 P 从 0.30 微调到 0.31，而阈值是 0.50，硬输出仍然是 0；模型无法从这一小变化看到输出怎样改善。在阈值点它又突然跳变。

因此训练时想通过“二值化之后的损失”调整 P 与阈值 T，需要一条平滑过渡。DB（Differentiable Binarization，可微二值化）用 Sigmoid 近似这次跳变：

DB用平滑的阶跃近似：

\[
\hat B_{ij}=\sigma(z_{ij}),\quad z_{ij}=k(P_{ij}-T_{ij}),\quad
\sigma(z)=\frac1{1+e^{-z}}.
\]

P 是每个位置的文字概率，T 是该位置的阈值；两张图尺寸相同，都是 H 行 W 列、数值在 0–1。i、j 选择行列，k 是大于 0 的陡峭度参数；z 是差值 P−T 放大 k 倍后的中间数；B̂ 是通过 Sigmoid 后的连续结果。

例如 P=0.7、T=0.5、k=50，先得差值 0.2，再得 z=10，最后 B̂≈0.999955。它看起来接近 1，但仍是一个连续数，而不是已经取出的文字框。本地默认k=50与 [DB论文公式(2)](https://arxiv.org/html/1911.08947v2) 的实验设置相符，但不保证任何数据都适合这个值。

### 推导与手算

因 `dσ/dz=σ(1−σ)`，且 `dz/dP=k,dz/dT=−k`：

\[
\frac{\partial\hat B}{\partial P}=k\hat B(1-\hat B),\quad
\frac{\partial\hat B}{\partial T}=-k\hat B(1-\hat B).
\]

`b(1−b)=¼−(b−½)²≤¼`，因此最大导数是k/4，在P=T时达到。

取T=0.5,k=50：

| P | z=k(P−T) | B̂ | ∂B̂/∂P |
|---:|---:|---:|---:|
| 0.3 | −10 | 0.0000453979 | 0.0022697904 |
| 0.5 | 0 | 0.5 | 12.5 |
| 0.7 | 10 | 0.9999546021 | 0.0022697904 |

这张表直接由Node实验1及Jest复现。P=T时的0.5不是“像素一半属于字符”，而是该连续映射的中心值。

### 实现步骤与数值稳定性

1. 验证P/T为同形矩阵、元素有限且位于[0,1]。
2. 逐像素计算z。
3. 对z≥0用 `1/(1+exp(-z))`；对z<0用 `exp(z)/(1+exp(z))`，避免计算过大的正指数。
4. 计算B̂和两份解析导数；返回新矩阵，不覆盖P/T。导数用等价式 `k·u/(1+u)²`，其中 `u=exp(−|z|)`，避免先将B̂舍入为1再计算 `B̂(1−B̂)` 而提前失去正侧梯度。

```javascript
const { differentiableBinarize } = require('../shared/22-text-detection-networks');
const result = differentiableBinarize([[0.3, 0.5, 0.7]], [[0.5, 0.5, 0.5]], 50);
// result.binary / dProbability / dThreshold 均为1×3矩阵。
```

浮点反例：k=50、P−T=±1时，两侧解析导数均约 `9.64374924e−21`。正侧B̂在JavaScript双精度下已显示为1，但导数仍可表示；“显示成1”不等于数学导数为0。极端到指数项本身下溢时仍会得到0，本实现不是任意精度运算。

### 参数影响与一个常见误读

k变大，边界附近梯度峰值增高，显著梯度区域变窄；远处趋于饱和。它不会自动让错误预测变正确。对任意正k，`B̂>0.5` 与 `P>T` 等价，所以页面改变k能改变软图，却通常不改变这条对照支路的二值区域。若最后阈值是q而非0.5，则条件变成 `P−T>log(q/(1−q))/k`，此时k才会改变该阈值对应的边界。

## 4. 从 DB 运算到 DBNet：监督与推理不能混为一谈

### 为什么有两个预测图

完整网络从图像通过特征主干和多尺度融合获得F，用预测头产生P和T，再通过DB公式得到B̂。学习出的P/T来自图像和标注；本章用公式直接制造P/T，只验证它们之后的运算。

```text
实际 DBNet 训练：图像 → 主干/融合F → P ──┐
                                    T ──┴→ B̂
                         P监督、T监督、B̂监督共同形成损失

本章合成实验：已知公式 → P,T → 同一DB公式 → 数值/导数/区域对照
```

一行文字对应一个实例，即一个需要单独框出的区域。如果两个文字区域很近，完整边界上的预测容易粘在一起，所以训练时常把标注多边形向里收缩，先让模型学到彼此分离的核心区域。论文用面积A、周长L、收缩比例r估计偏移距离 `D=A(1−r²)/L`。例如长100、宽20的矩形，A=2000,L=240,r=0.4，D=7；注意这是一种偏移距离设定，不等于缩放后矩形边长都乘0.4。T还需边界区域监督。只训练P−T而无其他约束时，P/T存在共同平移的歧义，不能据此说已经学到有意义的两个分支。

### 以 BCE 为例完成链式推导

刚才的导数只回答“P 变一点，B̂ 变多少”。真正训练还需要知道 B̂ 离正确答案多远。令 y 是这一像素的监督标签，文字为 1、非文字为 0；用二元交叉熵 L 衡量预测 B̂ 与 y 的差距：

\[
L=-y\log\hat B-(1-y)\log(1-\hat B).
\]

将它和sigmoid连接，梯度简化为：

\[
\frac{\partial L}{\partial z}=\hat B-y,\quad
\frac{\partial L}{\partial P}=k(\hat B-y),\quad
\frac{\partial L}{\partial T}=-k(\hat B-y).
\]

这与仅有 `∂B̂/∂P` 不同。例如y=1而B̂≈0，DB自身导数可能小，但BCE对P的梯度仍接近−k，因此不能只看sigmoid饱和就断言这条损失的学习信号消失。

稳定损失用 `max(z,0)−zy+log(1+exp(−|z|))`，避免直接取 `log(0)`。本实现用 `Math.log1p` 保留较小指数项的精度。反向在z≥0时用等价残差 `(1−y)−σ(−z)` 代替 `σ(z)−y`；例如z=50、y=1时，对P的导数约 `−9.64374924e−21`，不能因σ(z)已舍入为1而提前返回0。

### 一步数值核对

取P=0.51,T=0.48,y=1,k=12：

```text
z=0.36
B̂=0.5890404341
L=0.5292604490
∂L/∂P=−4.9315147913
∂L/∂T=+4.9315147913
```

这两个梯度的方向也有意义：目标是文字 y=1，负的 P 梯度让梯度下降提高 P；正的 T 梯度让梯度下降降低 T。两者都会增大 P−T，进而提高 B̂。如果只监督这个差，P 与 T 一起加同样的数不会改变它，所以完整网络还需其他监督来约束各分支。

Node 实验 2 比较解析梯度与 `ε=1e-6` 的中心差分，Jest还独立检查T方向。本函数的梯度是对**概率值P/T**的梯度，若预测头实际输出logit，还需继续乘其sigmoid导数，不能把它直接当主干参数的梯度。

论文总目标分别包含概率图、二值图和阈值图损失；本章BCE函数只演示其中一种逐像素损失的链式法则，未实现整套标签生成、难负样本选择、区域损失组合或训练器。作者代码也可能采用与论文示意不同的损失组合，复现实验应固定代码版本和配置。

### 推理时是否一定需要T

不一定。[作者官方预测头代码](https://github.com/MhLiao/DB/blob/master/decoders/seg_detector.py) 在非训练模式直接返回概率预测分支；其中变量名称 `binary` 沿用历史命名，不应仅凭名字认定它就是B̂。由训练中DB帮助优化后的P可以直接做固定阈值后处理。

因此页面默认并列展示：P>固定阈值的推理思路，以及B̂>0.5的教学对照。后者有助理解自适应阈值的作用，不能写成“真实DBNet部署总要同时输出T和B̂”。

## 5. 从像素图到候选区域：阈值、连通域、评分和扩张

### 动机与一步步处理

模型给出每个位置的值，识别器需要一块可裁剪的区域。单个高概率像素不能作为有效文字框，还需要区域完整性、面积和评分规则。

本地 `extractBoxes(map,options)` 按以下步骤实现：

1. 用严格 `map[y][x]>threshold` 选前景，相等时归背景。
2. 四邻域广度优先搜索，一次记录一个连通分量；使用队列头索引，避免反复 `shift()`。
3. 累积像素数、坐标极值和scoreMap的概率和。
4. 以组件内的平均P评分，过滤面积小于minArea或分数小于minScore的区域。
5. 将整数像素坐标转为半开区间框 `[x0,y0,x1,y1)`。
6. 按矩形面积/周长估计扩张距离，最后裁到图像边界。

这条路径复用第09章的连通性思想，但用独立概率矩阵接口，避免把网络输出反复编码为RGBA再解码。

### 手算连通域与区域评分

```text
P = [0.9 0.9 0.0 0.0]
    [0.9 0.9 0.0 0.9]
    [0.0 0.0 0.9 0.9]
threshold=0.5, minArea=3, minScore=0.5
```

左上区域包含4个像素，框 `[0,0,2,2)`，分数3.6/4=0.9。右侧区域包含(3,1)、(2,2)、(3,2)共3个像素，框 `[2,1,4,3)`，分数0.9。二者有对角邻接却不按四邻域合并。minArea改为4后只保留左上区域。

右侧区域的框宽 2、高 2，矩形面积是 4，但其中只有三个位置属于前景，所以组件 area=3。区域面积为**前景像素数**，不是外接矩形面积。scoreMap可与二值化map不同：B̂用来圈区域，P用来评价区域。若B̂为0.99但相应P仅为0.2，minScore=0.5时仍应拒绝；不能把陡峭映射制造出的高值当更可靠的检测置信度。

### 扩张的动机与边界

收缩区域可能遗漏字符边缘，因此后处理常将轮廓向外偏移。作者 [官方后处理](https://github.com/MhLiao/DB/blob/master/structure/representers/seg_detector_representer.py) 使用多边形面积A和周长L，按 `d=A×unclip_ratio/L` 做多边形offset，并处理轮廓、最小旋转矩形等。

本章只用**轴对齐矩形**的面积与周长估计d，然后四边各扩d。比如宽10、高4，A=40,L=28，ratio=1.4，则d=2，扩张后尺寸14×8；靠图像边缘时会裁切。它不是多边形unclip的精确实现，也不是严格逆转训练收缩。

ratio太大可能合并/覆盖邻行，太小可能截断笔画。四邻域不能解决笔画断裂，组件只要通过一个像素桥连接就会合并。真实DBNet的实例边界与轮廓恢复比这里复杂，普通阈值没有能力自动判断桥接像素是否语义上属于文字。

## 6. IoU 与 NMS：为什么多个预测只保留一个

### 定义、推导与数值例子

同一段文字可能被多个预测位置重复框出。我们先衡量两个框重叠多少：IoU（交并比）=交集面积/并集面积；再用 NMS（非极大值抑制）优先保留高分框，删除与它重叠过多的低分候选。

公式中 A、B 是两个框；x₀、y₀ 是左上边界，x₁、y₁ 是右下边界；I_w、I_h 分别是交集的宽和高。先取两框较靠右的左边界、较靠左的右边界，差值若为负就说明没有横向交集，要取 0。高度同理：

\[
I_w=\max(0,\min(x_{1A},x_{1B})-\max(x_{0A},x_{0B})),
\]
\[
I_h=\max(0,\min(y_{1A},y_{1B})-\max(y_{0A},y_{0B})),\quad
IoU=\frac{I_wI_h}{|A|+|B|-I_wI_h}.
\]

本地框使用连续半开坐标，宽度为x1−x0，**不加1**。框 `[0,0,4,4)` 与 `[2,0,6,4)` 各有面积16，交集宽2高4=8，并集24，IoU=1/3。实现要求面积也可表示为有限正数；计算比例时先按同一个最大面积缩放分子分母，避免两个有限的大面积相加溢出，使相同框的IoU错误变成0。

若分数分别0.9和0.8，阈值0.3时后者被抑制，阈值0.4时都保留。实现采用 `IoU>threshold` 才抑制；相等时保留。

### 逐步实现与限制

1. 校验每个候选的正面积与有限坐标/分数。
2. 复制并按分数降序排列；分数平局保持原输入次序。
3. 从高到低检查候选，与每个已保留框比较IoU。
4. 和所有已保留框的IoU都不超阈值才加入输出。

最坏复杂度O(n²)。NMS不会修复错框，也不能将同一行多个相邻字符自动合成行框；它只执行约定的抑制规则。阈值低易误删邻近区域，阈值高易留下重复框。对旋转四边形直接使用本章外接框IoU是近似，斜长文本尤其可能被误删；完整EAST路径应使用匹配几何的重叠和其后处理方法。

## 7. 坐标恢复与失败状态

### 为什么要记录预处理变换

网络看到的是缩放、补边后的图，裁剪必须在原图中进行。若P图又比网络输入小，还要先从输出图坐标还原到网络输入坐标。少一次乘法可能把框缩小4倍，多一次则放大4倍。

设原图一个位置叫 `(x_orig,y_orig)`，先缩放 s_x、s_y 倍，再在左侧和顶部补 p_x、p_y 像素，才成为网络输入坐标 `(x_net,y_net)`。这些缩放倍数和补边量要在预处理时记下来：

\[
x_{net}=s_xx_{orig}+p_x,\quad y_{net}=s_yy_{orig}+p_y,
\]

则 `xorig=(xnet−px)/sx`、`yorig=(ynet−py)/sy`。必须先减padding，再除缩放；先除再减是另一种变换。

例如输入框 `[8,10,20,18)`，padding=(4,6)，scale=(2,2)，还原后为 `[2,2,8,6)`。若一整个框位于padding区，裁到原图后成为零面积，函数返回null。

```javascript
const { mapBoxToOriginal } = require('../shared/22-text-detection-networks');
const restored = mapBoxToOriginal(boxInNetworkPixels, {
  scaleX: 2, scaleY: 2, padX: 4, padY: 6, width: 20, height: 10
});
```

该函数的axis-aligned框会裁到原图；若携带polygon，其顶点只做仿射反变换，**未做多边形边界裁剪**，可能仍在图外。这是接口边界，调用方不能把裁过的外接框等同于已裁过的polygon。

### 排障表

| 现象 | 优先检查 | 可验证动作 |
|---|---|---|
| 框整体偏移 | padding是否撤销 | 用上面的已知变换做往返测试 |
| 框统一大/小4倍 | stride和几何距离单位 | 检查锚点与距离是否重复乘stride |
| 高k但仍无正确框 | P/T来源和监督 | 先显示P，不用B̂的饱和值判断模型质量 |
| 同一行被切碎 | 概率断裂、连通性、阈值过高 | 显示前景连通域；不能盲目扩大所有框 |
| 相邻行合并 | 概率桥接、扩张过大 | 分别观察扩张前后的框与面积 |
| 斜框被误删 | 是否使用外接框IoU | 显示旋转框与外接框面积差 |
| 没有区域 | 阈值/面积/分数过滤或空输入 | 返回空数组和无区域状态，不伪造零框 |

## 8. 完整模型接入与方法选择

| 路线 | 主要输出 | 更适合讨论的问题 | 本章实现 |
|---|---|---|---|
| 传统定位 | 阈值/投影/连通域 | 背景简单、易检查 | 前章已有 |
| EAST | score + RBOX/QUAD | 多方向矩形/四边形检测 | 自定义约定下RBOX解码、普通NMS |
| DBNet | 学习到的P/T及训练DB分支 | 分割边界与实例分离 | DB核心算子、梯度和简化后处理 |

本项目未安装/调用完整预训练检测器。[OpenCV官方文本检测教程](https://docs.opencv.org/4.13.0/d4/d43/tutorial_dnn_text_spotting.html) 给出了 `TextDetectionModel_EAST`、`TextDetectionModel_DB` 的模型加载、输入参数和检测流程，可作为使用预训练模型的外部对照路径。该教程的原生API不等于浏览器的OpenCV.js一定包含这些能力，也不等于TensorFlow.js自动支持这些模型格式。

接入真实网络时按以下步骤准备可复核的契约：

1. 固定模型来源、文件校验值、版本、许可和训练数据说明。
2. 按模型文档匹配颜色顺序、数值范围、mean/std、输入尺寸、resize/padding方法。
3. 核对输出名称、布局、stride、P是否已经sigmoid，以及EAST角度/距离约定。
4. 使用与模型匹配的轮廓、polygon恢复或旋转NMS；若使用本章近似，单独报告影响。
5. 保存原图和变换参数，恢复坐标后显示叠加图，再交给识别器。
6. 在独立标注集上评价检测Precision/Recall等；端到端CER/整串准确率还需要识别结果。

为了独立调试第4步，Node提供一个已计算预测图接口：

```json
{"P":[[0.9,0.9,0],[0.9,0.9,0]],"options":{"threshold":0.3,"minArea":3,"minScore":0.5,"expandRatio":0}}
```

```bash
node 22-text-detection-networks/index.js /absolute/path/prediction-map.json
```

它读取P并执行本章后处理，**不做模型推理**。页面内置合成例子、预训练模型对照、本项目自己训练的识别器是不同来源，不互相冒充。

| 共享接口 | 输入/输出 |
|---|---|
| `differentiableBinarize(P,T,k=50)` | 同形概率矩阵→`{binary,dProbability,dThreshold}` |
| `dbBinaryCrossEntropy(p,t,y,k=50)` | 标量概率与目标→loss、binary、两份梯度 |
| `extractBoxes(map,options)` | 矩阵→区域数组；默认阈值.3、minArea3、minScore.5、expandRatio0 |
| `boxIoU(a,b)` | 正面积半开矩形→[0,1] |
| `nms(boxes,threshold=.3)` | 候选数组→按分数保留的拷贝，不改输入 |
| `decodeEastRBox(geometry,stride=4)` | 本章几何约定→polygon及轴对齐外接框 |
| `mapBoxToOriginal(box,transform)` | 框及仿射变换→原图框或null |
| `createDetectionExample(options)` | 48×24合成P/T、DB结果与两支路框；默认expandRatio1；`blank:true`生成空P |

区域字段 `{x0,y0,x1,y1,score,area}` 中area是扩张前组件像素数，不随框扩张改变。所有图为按 `[y][x]` 索引的有限 `number[][]`，缺失行或数组空洞不是合法概率，直接报错。边长、阈值、维度、概率范围不合法会抛错。

默认实测P支路保留2个区域，组件面积121/169，分数0.68127418/0.61759338；B̂支路保留2个区域，面积103/124。这个差异来自边界定义，不是检测准确率比较。BCE算例实测损失0.5292604490；DB导数、EAST0°/90°角点、IoU、NMS阈值、坐标恢复、空图及错误输入均由独立测试覆盖。
