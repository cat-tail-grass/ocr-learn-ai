🖼️ 01. 数字图像基础

📚 核心概念

🔲 像素 (Pixel)

图像的最小组成单位，每个像素包含颜色信息。一张图像由成千上万个像素组成。

📐 分辨率 (Resolution)

图像的尺寸，用 宽度×高度 表示。例如 1920×1080 表示有约200万个像素。

🎨 RGB 色彩空间

每个像素由红(R)、绿(G)、蓝(B)三个通道组成，每个通道取值 0-255。

📊 矩阵表示

图像在计算机中以矩阵形式存储，可以通过数组访问每个像素的值。

💾 ImageData 内存布局

在 Canvas 中，图像数据存储在一维数组中，每4个连续的值表示一个像素的 RGBA 值

// 获取 Canvas 上下文和图像数据 const canvas = document.getElementById('myCanvas'); const ctx = canvas.getContext('2d'); const imageData = ctx.getImageData(0, 0, width, height); // imageData.data 是一个 Uint8ClampedArray // 结构: [R₀, G₀, B₀, A₀, R₁, G₁, B₁, A₁, ...] // 访问第 n 个像素的 RGB 值 const n = 5; // 第5个像素 const r = imageData.data[n * 4 + 0]; // 红色通道 const g = imageData.data[n * 4 + 1]; // 绿色通道 const b = imageData.data[n * 4 + 2]; // 蓝色通道 const a = imageData.data[n * 4 + 3]; // Alpha通道（透明度）
