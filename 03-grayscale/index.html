🎨 03. 灰度化 (Grayscale Conversion)

📚 为什么要灰度化？

灰度化是 OCR 预处理的第一步。将彩色图像转换为灰度图像可以： 降低计算复杂度、去除颜色干扰、为后续二值化做准备。

加权公式权重可视化

人眼对不同颜色的敏感度决定了权重分配

红色 (R)
0.299
绿色 (G)
0.587
蓝色 (B)
0.114
// 加权平均法（ITU-R BT.601 标准） Gray = 0.299 × R + 0.587 × G + 0.114 × B // 为什么绿色权重最大？ // 人眼有三种视锥细胞，对绿色最敏感 // 绿色对亮度感知的贡献最大

📖 灰度化算法详解

算法 公式 特点 适用场景
加权平均法 ⭐ 0.299R + 0.587G + 0.114B 最接近人眼感知 通用场景，OCR首选
平均值法 (R + G + B) / 3 简单快速 对质量要求不高时
最大值法 max(R, G, B) 结果偏亮 提取高亮区域
最小值法 min(R, G, B) 结果偏暗 提取暗色区域
单通道法 R 或 G 或 B 只取一个通道 特定颜色分析
// 加权平均法实现 function grayscaleWeighted(imageData) { const data = imageData.data; for (let i = 0; i < data.length; i += 4) { // 获取 RGB 值 const r = data[i]; const g = data[i + 1]; const b = data[i + 2]; // 加权公式（ITU-R BT.601） const gray = Math.round( 0.299 * r + 0.587 * g + 0.114 * b ); // 将 RGB 都设为灰度值 data[i] = gray; // R data[i + 1] = gray; // G data[i + 2] = gray; // B // Alpha 保持不变 } return imageData; }
