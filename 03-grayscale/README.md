## 核心概念

### 1. 什么是灰度图？

灰度图是只有一个通道的图像，每个像素用一个值（0-255）表示亮度：
- **0** = 纯黑
- **255** = 纯白
- 中间值 = 不同程度的灰色

```
彩色图像（3通道）         灰度图像（1通道）
┌─────────────────┐      ┌─────────────┐
│ R: 255          │      │             │
│ G: 128          │  →   │ Gray: 162   │
│ B: 64           │      │             │
└─────────────────┘      └─────────────┘
```

### 2. 为什么要灰度化？

| 原因 | 说明 |
|------|------|
| **降低复杂度** | 数据量减少 2/3（从 3 通道变 1 通道） |
| **去除颜色干扰** | 文字识别不需要颜色信息 |
| **简化后续处理** | 二值化、边缘检测等操作更简单 |
| **提高处理速度** | 计算量大大减少 |

### 3. 灰度化算法

#### 算法一：平均值法 (Average)

```
Gray = (R + G + B) / 3
```

**特点**：简单快速，但不符合人眼感知

#### 算法二：加权平均法 (Weighted Average) ⭐ 推荐

```
Gray = 0.299 × R + 0.587 × G + 0.114 × B
```

**特点**：
- 基于人眼对颜色的敏感度
- 人眼对绿色最敏感（权重 0.587）
- 对红色次之（权重 0.299）
- 对蓝色最不敏感（权重 0.114）
- 这是 **ITU-R BT.601** 标准

#### 算法三：最大值法 (Maximum)

```
Gray = max(R, G, B)
```

**特点**：保留最亮的通道，结果偏亮

#### 算法四：最小值法 (Minimum)

```
Gray = min(R, G, B)
```

**特点**：保留最暗的通道，结果偏暗

#### 算法五：单通道法 (Single Channel)

```
Gray = R  (或 G 或 B)
```

**特点**：只取一个通道，适合特定场景

### 4. 灰度直方图

灰度直方图统计图像中每个灰度值（0-255）出现的次数。

```
频率
 │
 │    ▓▓
 │   ▓▓▓▓
 │  ▓▓▓▓▓▓▓
 │ ▓▓▓▓▓▓▓▓▓▓
 └──────────────── 灰度值
   0     128    255
```

**用途**：
- 分析图像亮度分布
- 选择二值化阈值
- 图像增强

## 与 OCR 的关联

灰度化是 OCR 预处理流水线的第一步：

```
彩色图像 → [灰度化] → 灰度图像 → [二值化] → 二值图像 → [后续处理]
              ↑
           当前学习
```

| 作用 | 说明 |
|------|------|
| 数据预处理 | 统一输入格式，简化后续算法 |
| 降低干扰 | 去除颜色对文字识别的影响 |
| 性能优化 | 减少 2/3 的数据量 |
