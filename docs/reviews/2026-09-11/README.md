## 建议重新阅读的技术点

| 章节 | 原先容易讲错的地方 | 修正后的关键结论 |
|---|---|---|
| 01–04 | alpha/灰度混同、偶数中位数、Otsu分组与方差尺度 | alpha是透明度；偶数中位数取中间两值均值；Otsu黑类g≤t、方差用概率权重 |
| 05–06 | 把互相关叫数学卷积、把高斯说成边缘保持、忽略形态学前景极性 | 卷积翻核；高斯仍模糊边缘；明确前景、锚点、有限画布和二值/灰度区别 |
| 07–10 | 校正角重复取反、错误旋转中心/NMS方向、漏掉边界与候选筛选 | 返回直接施加的校正角；中心取像素网格中心；梯度与邻域遵守同一坐标系 |
| 11–13 | 栅格Hu严格不变、常量NCC=1、页面特征维度不同、用测试选K | 栅格变换仅近似不变；常量相关未定义；统一85维组合；先按来源分区，再增强、验证选参、冻结测试 |
| 16–17 | 末批loss当最终模型loss、固定seed误称每批独立Dropout、无条件套用p−y | 最终权重重新评估；新默认Dropout每次采样；Layers概率裁剪与融合logits损失存在差异，epsilon依后端而变 |
| 18–20 | “四个LSTM门”、直接状态偏导当总梯度、CTC巨大logits偏移误归一化 | 三门加候选；注明导数路径；先减最大值再保持移位后的logSoftmax计算 |
| 21–23 | 饱和softmax/DB小梯度消失、教学检测与完整模型混同 | 稳定计算可表示尾部梯度；明确教学算法和完整EAST/DBNet/ViT/TrOCR的范围 |
| 24–26 | 模型得分等于正确率、失败状态代替文本评分、缺来源默认实拍、重复样本扩大分母 | CER比较实际交付文本；缺来源归unknown；校验清单唯一性；新流程使用独立版本标识 |
