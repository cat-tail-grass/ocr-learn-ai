# 12. 模板匹配 (Template Matching)

## 学习目标

模板匹配是最直观的字符识别方法，通过将待识别字符与预先存储的标准模板进行比对来确定字符类别。本章将帮助你掌握：

1. **模板匹配原理** - 理解模板匹配的基本思想
2. **相似度度量** - 欧氏距离、余弦相似度、相关系数等
3. **模板库构建** - 如何创建和管理标准字符模板
4. **归一化处理** - 尺寸归一化、特征归一化的重要性
5. **匹配决策** - 最近邻匹配与阈值判断
6. **模板匹配的局限性** - 了解何时适用、何时不适用

## 核心概念

### 1. 什么是模板匹配？

模板匹配是一种基于比较的识别方法：将待识别对象与一组已知模板逐一比较，找出最相似的模板作为识别结果。

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          模板匹配基本流程                                  │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   待识别字符                    模板库                                    │
│   ┌─────────┐                  ┌─────────────────────────────────┐      │
│   │         │                  │  ┌───┐ ┌───┐ ┌───┐     ┌───┐   │      │
│   │   ?     │ ──比较──────────→│  │ 0 │ │ 1 │ │ 2 │ ... │ 9 │   │      │
│   │         │                  │  └───┘ └───┘ └───┘     └───┘   │      │
│   └─────────┘                  └─────────────────────────────────┘      │
│       ↓                                     ↓                            │
│   提取特征                            计算相似度                          │
│       ↓                                     ↓                            │
│   [特征向量] ←───────────────→ [d₀, d₁, d₂, ..., d₉]                    │
│                                             ↓                            │
│                                      选择最小距离                         │
│                                             ↓                            │
│                                    识别结果："3"                          │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 2. 相似度度量方法

选择合适的相似度度量是模板匹配的关键。

#### 2.1 欧氏距离（Euclidean Distance）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          欧氏距离                                         │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   公式：d = √(Σ(aᵢ - bᵢ)²)                                              │
│                                                                          │
│   示例：                                                                  │
│   向量 A = [1, 2, 3]                                                     │
│   向量 B = [4, 6, 3]                                                     │
│   d = √((1-4)² + (2-6)² + (3-3)²)                                       │
│     = √(9 + 16 + 0)                                                      │
│     = √25 = 5                                                            │
│                                                                          │
│   特点：                                                                  │
│   ✓ 直观，几何意义明确                                                    │
│   ✓ 距离越小越相似                                                        │
│   ✗ 对特征尺度敏感（需要归一化）                                          │
│   ✗ 受高维度影响（维度灾难）                                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 2.2 余弦相似度（Cosine Similarity）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          余弦相似度                                       │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   公式：cos(θ) = (A · B) / (||A|| × ||B||)                              │
│                = Σ(aᵢ × bᵢ) / (√Σaᵢ² × √Σbᵢ²)                          │
│                                                                          │
│   取值范围：[-1, 1]                                                       │
│   • 1 = 完全相同方向                                                      │
│   • 0 = 正交（无关）                                                      │
│   • -1 = 完全相反方向                                                     │
│                                                                          │
│   特点：                                                                  │
│   ✓ 只关注向量方向，不关注大小                                            │
│   ✓ 对缩放不敏感                                                          │
│   ✓ 相似度越大越相似（与距离相反）                                        │
│   ✗ 可能忽略重要的幅度信息                                                │
│                                                                          │
│   余弦距离 = 1 - cos(θ)  （转换为距离形式）                               │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 2.3 归一化相关系数（Normalized Cross-Correlation, NCC）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          归一化相关系数                                    │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   公式：NCC = Σ((aᵢ - μₐ)(bᵢ - μ_b)) / (n × σₐ × σ_b)                   │
│                                                                          │
│   其中：                                                                  │
│   • μₐ, μ_b = 向量 A, B 的均值                                           │
│   • σₐ, σ_b = 向量 A, B 的标准差                                         │
│                                                                          │
│   取值范围：[-1, 1]                                                       │
│   • 1 = 完全正相关                                                        │
│   • 0 = 无相关性                                                          │
│   • -1 = 完全负相关                                                       │
│                                                                          │
│   特点：                                                                  │
│   ✓ 对亮度和对比度变化鲁棒                                                │
│   ✓ 常用于图像匹配                                                        │
│   ✓ 值越大越相似                                                          │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 2.4 各种度量方法对比

| 度量方法 | 取值范围 | 相似性判断 | 计算复杂度 | 特点 |
|----------|----------|------------|------------|------|
| 欧氏距离 | [0, ∞) | 越小越相似 | O(n) | 直观，对尺度敏感 |
| 曼哈顿距离 | [0, ∞) | 越小越相似 | O(n) | 计算快，抗噪声 |
| 余弦相似度 | [-1, 1] | 越大越相似 | O(n) | 对尺度不敏感 |
| 相关系数 | [-1, 1] | 越大越相似 | O(n) | 对亮度/对比度鲁棒 |

### 3. 模板库构建

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          模板库构建                                        │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   方法一：单模板法                                                        │
│   ─────────────                                                          │
│   每个类别只有一个模板（通常是标准字体）                                   │
│                                                                          │
│   模板库：{ '0': 模板₀, '1': 模板₁, ..., '9': 模板₉ }                    │
│                                                                          │
│   优点：简单、快速                                                        │
│   缺点：无法处理字体变化                                                  │
│                                                                          │
│   ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│   方法二：多模板法                                                        │
│   ─────────────                                                          │
│   每个类别有多个模板（不同字体、手写样本等）                               │
│                                                                          │
│   模板库：{                                                               │
│     '0': [模板₀₁, 模板₀₂, 模板₀₃, ...],                                  │
│     '1': [模板₁₁, 模板₁₂, 模板₁₃, ...],                                  │
│     ...                                                                   │
│   }                                                                       │
│                                                                          │
│   匹配策略：                                                              │
│   • 最小距离：取所有模板中距离最小的                                      │
│   • 类内平均：计算与每类所有模板的平均距离                                 │
│                                                                          │
│   优点：更好的泛化能力                                                    │
│   缺点：计算量增加、需要更多存储                                          │
│                                                                          │
│   ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│   方法三：原型法（聚类中心）                                              │
│   ───────────────────────                                                │
│   对每类的多个样本进行聚类，用聚类中心作为模板                            │
│                                                                          │
│   优点：既有泛化能力，又保持效率                                          │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 4. 预处理与归一化

在模板匹配之前，必须对图像进行预处理，确保待识别字符和模板具有可比性。

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          预处理步骤                                        │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   Step 1: 二值化                                                         │
│   ─────────────                                                          │
│   确保字符图像是清晰的黑白图像                                            │
│                                                                          │
│   Step 2: 尺寸归一化                                                     │
│   ─────────────────                                                      │
│   将所有字符缩放到统一尺寸（如 28×28）                                    │
│   • 保持宽高比，添加边距                                                  │
│   • 或直接拉伸（简单但可能变形）                                          │
│                                                                          │
│   Step 3: 居中对齐                                                       │
│   ─────────────                                                          │
│   使字符的质心位于图像中心                                                │
│   减少位置偏移对匹配的影响                                                │
│                                                                          │
│   Step 4: 特征提取                                                       │
│   ─────────────                                                          │
│   可选择使用：                                                            │
│   • 原始像素值                                                            │
│   • 统计特征 + Hu 矩                                                      │
│   • 投影特征 + 网格特征                                                   │
│   • HOG 特征                                                              │
│                                                                          │
│   Step 5: 特征归一化                                                     │
│   ─────────────────                                                      │
│   使用 L2 归一化或 Min-Max 归一化                                         │
│   确保不同特征维度的贡献均衡                                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 5. 匹配决策

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          匹配决策策略                                      │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   策略一：最近邻匹配（Nearest Neighbor）                                  │
│   ───────────────────────────────────                                    │
│   选择距离最小的模板对应的类别                                            │
│                                                                          │
│   result = argmin_c distance(input, template_c)                          │
│                                                                          │
│   问题：即使最近的模板也可能很远（不可靠的匹配）                          │
│                                                                          │
│   ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│   策略二：阈值判断                                                        │
│   ──────────────                                                         │
│   设置距离阈值，超过阈值的匹配视为"拒绝识别"                              │
│                                                                          │
│   if min_distance > threshold:                                           │
│       result = "未知字符"                                                 │
│   else:                                                                   │
│       result = 最近模板的类别                                             │
│                                                                          │
│   优点：可以识别出不在模板库中的字符                                      │
│                                                                          │
│   ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│   策略三：置信度评估                                                      │
│   ────────────────                                                       │
│   计算匹配的置信度，返回多个候选结果                                      │
│                                                                          │
│   confidence = 1 - (distance / max_distance)                             │
│   或                                                                      │
│   confidence = similarity_score                                          │
│                                                                          │
│   返回：[(类别1, 置信度1), (类别2, 置信度2), ...]                        │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 6. 模板匹配的局限性

```
┌──────────────────────────────────────────────────────────────────────────┐
│                          模板匹配的局限性                                  │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   ❌ 对变形敏感                                                           │
│   ─────────────                                                          │
│   • 旋转：字符略微旋转就可能匹配失败                                      │
│   • 缩放：尺寸归一化可以缓解，但无法完全解决                              │
│   • 倾斜：斜体字与正体字匹配困难                                          │
│                                                                          │
│   ❌ 对字体变化敏感                                                       │
│   ───────────────                                                        │
│   • 不同字体的相同字符可能差异很大                                        │
│   • 需要大量模板才能覆盖各种字体                                          │
│                                                                          │
│   ❌ 对手写字符效果差                                                     │
│   ─────────────────                                                      │
│   • 手写体变化极大，难以用有限模板覆盖                                    │
│   • 需要机器学习方法（KNN、神经网络）                                     │
│                                                                          │
│   ❌ 计算效率问题                                                         │
│   ───────────────                                                        │
│   • 模板数量增加会线性增加匹配时间                                        │
│   • 高维特征会加剧问题                                                    │
│                                                                          │
│   ❌ 无法处理新类别                                                       │
│   ───────────────                                                        │
│   • 只能识别模板库中已有的字符                                            │
│   • 添加新类别需要重新构建模板库                                          │
│                                                                          │
│   ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│   ✅ 适用场景                                                             │
│   ─────────────                                                          │
│   • 标准印刷体识别（OCR-A、OCR-B 字体）                                   │
│   • 固定格式文档（银行支票、表格）                                        │
│   • 字符类别有限且标准化的场景                                            │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 算法实现

### 1. 模板匹配器类

```javascript
/**
 * 模板匹配器类
 * 
 * 功能：
 * - 管理模板库
 * - 执行字符识别
 * - 返回匹配结果和置信度
 */
class TemplateMatcher {
    constructor(options = {}) {
        this.templates = new Map();  // 模板库：Map<label, features[]>
        this.options = {
            distanceMetric: 'euclidean',  // 距离度量方法
            featureType: 'combined',       // 特征类型
            imageSize: 28,                 // 归一化尺寸
            rejectThreshold: null,         // 拒绝阈值（null 表示不拒绝）
            ...options
        };
    }
    
    /**
     * 添加模板
     */
    addTemplate(label, features) {
        if (!this.templates.has(label)) {
            this.templates.set(label, []);
        }
        this.templates.get(label).push(features);
    }
    
    /**
     * 识别字符
     */
    recognize(features) {
        let bestMatch = null;
        let bestDistance = Infinity;
        const results = [];
        
        // 与所有模板比较
        for (const [label, templateList] of this.templates) {
            for (const template of templateList) {
                const distance = this.calculateDistance(features, template);
                
                if (distance < bestDistance) {
                    bestDistance = distance;
                    bestMatch = label;
                }
                
                results.push({ label, distance });
            }
        }
        
        // 检查是否超过拒绝阈值
        if (this.options.rejectThreshold !== null && 
            bestDistance > this.options.rejectThreshold) {
            return { label: null, distance: bestDistance, rejected: true };
        }
        
        return { 
            label: bestMatch, 
            distance: bestDistance, 
            rejected: false,
            allResults: results.sort((a, b) => a.distance - b.distance)
        };
    }
    
    /**
     * 计算距离
     */
    calculateDistance(a, b) {
        switch (this.options.distanceMetric) {
            case 'euclidean':
                return euclideanDistance(a, b);
            case 'cosine':
                return 1 - cosineSimilarity(a, b);
            case 'manhattan':
                return manhattanDistance(a, b);
            default:
                return euclideanDistance(a, b);
        }
    }
}
```

### 2. 相关系数计算

```javascript
/**
 * 计算归一化相关系数 (NCC)
 * 
 * @param {number[]} a - 向量 A
 * @param {number[]} b - 向量 B
 * @returns {number} 相关系数 [-1, 1]
 */
function normalizedCrossCorrelation(a, b) {
    const n = a.length;
    
    // 计算均值
    const meanA = a.reduce((sum, v) => sum + v, 0) / n;
    const meanB = b.reduce((sum, v) => sum + v, 0) / n;
    
    // 计算标准差和协方差
    let varA = 0, varB = 0, covar = 0;
    
    for (let i = 0; i < n; i++) {
        const diffA = a[i] - meanA;
        const diffB = b[i] - meanB;
        varA += diffA * diffA;
        varB += diffB * diffB;
        covar += diffA * diffB;
    }
    
    const stdA = Math.sqrt(varA / n);
    const stdB = Math.sqrt(varB / n);
    
    if (stdA === 0 || stdB === 0) return 0;
    
    return covar / (n * stdA * stdB);
}
```

### 3. 从图像创建模板

```javascript
/**
 * 从图像创建模板
 * 
 * @param {ImageData} imageData - 输入图像
 * @param {string} label - 字符标签
 * @param {object} options - 配置选项
 * @returns {object} 模板对象
 */
function createTemplate(imageData, label, options = {}) {
    const {
        targetSize = 28,
        featureType = 'combined'
    } = options;
    
    // 1. 预处理：裁剪并居中
    const processed = cropAndCenter(imageData, targetSize);
    
    // 2. 提取特征
    let features;
    
    switch (featureType) {
        case 'pixel':
            features = extractPixelFeatures(processed, { normalize: true });
            break;
        case 'statistical':
            const stats = extractStatisticalFeatures(processed);
            features = statisticalFeaturesToVector(stats);
            break;
        case 'combined':
            features = extractCombinedFeatures(processed, {
                includePixels: false,
                includeStats: true,
                includeHuMoments: true,
                includeProjection: true,
                includeZone: true,
                includeHOG: false
            }).all;
            break;
        default:
            features = extractPixelFeatures(processed, { normalize: true });
    }
    
    return {
        label,
        features,
        imageData: processed
    };
}
```

## 在 OCR 中的应用

### 完整的模板匹配 OCR 流程

```
┌──────────────────────────────────────────────────────────────────────────┐
│                     模板匹配 OCR 完整流程                                  │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   一、模板库构建阶段（离线）                                               │
│   ──────────────────────────                                             │
│   1. 收集标准字符图像（每个类别至少 1 个）                                 │
│   2. 对每个图像进行预处理（二值化、归一化、居中）                          │
│   3. 提取特征向量                                                        │
│   4. 存储到模板库                                                        │
│                                                                          │
│   二、识别阶段（在线）                                                    │
│   ────────────────────                                                   │
│                                                                          │
│   输入：包含文字的图像                                                    │
│     ↓                                                                    │
│   Step 1: 预处理                                                         │
│   - 灰度化 → 二值化 → 去噪 → 倾斜校正                                    │
│     ↓                                                                    │
│   Step 2: 文本检测                                                       │
│   - 连通域分析 → 文字行检测 → 字符分割                                    │
│     ↓                                                                    │
│   Step 3: 字符识别（模板匹配）                                            │
│   For each 字符区域:                                                      │
│     a. 提取字符图像                                                      │
│     b. 预处理（尺寸归一化、居中）                                         │
│     c. 提取特征向量                                                      │
│     d. 与模板库中所有模板计算距离                                         │
│     e. 选择距离最小的模板作为识别结果                                     │
│     ↓                                                                    │
│   Step 4: 组合结果                                                       │
│   - 按阅读顺序排列识别出的字符                                            │
│   - 输出最终文本                                                         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 不同场景的参数选择

| 场景 | 特征类型 | 距离度量 | 模板数量 | 说明 |
|------|----------|----------|----------|------|
| 标准数字 | 组合特征 | 欧氏距离 | 每类 1 个 | 0-9 共 10 个模板 |
| 多字体 | HOG 特征 | 余弦相似度 | 每类多个 | 每种字体一个模板 |
| 简单印刷体 | 像素特征 | 相关系数 | 每类 1 个 | 快速但不鲁棒 |

## 数学公式总结

### 距离与相似度

| 名称 | 公式 | 说明 |
|------|------|------|
| 欧氏距离 | d = √(Σ(aᵢ - bᵢ)²) | L2 距离 |
| 曼哈顿距离 | d = Σ\|aᵢ - bᵢ\| | L1 距离 |
| 余弦相似度 | cos(θ) = (A·B)/(‖A‖×‖B‖) | 方向相似 |
| 相关系数 | r = cov(A,B)/(σₐ×σ_b) | 线性相关 |

### 置信度计算

本章“置信度”是当前候选集合内的归一化匹配分数，未校准为真实正确概率。距离相差1的两候选，在T=1时得到约73.11%/26.89%；将两距离同时增加1000，分数仍相同。因此绝对距离很大、没有合适模板时，softmax仍可能给出很高分；只有一个候选时甚至恒为1。拒识应结合在验证集上确定的绝对距离阈值，不能只靠候选分数。

```
置信度 = 1 - (最小距离 / 归一化因子)

或者使用 Softmax：
置信度ᵢ = exp(-dᵢ/T) / Σexp(-dⱼ/T)
其中 T 是有限且严格大于0的温度参数。
稳定实现：令 dmin=min(d)，先算 exp(-(dᵢ-dmin)/T)，再除以总和。
```

NCC的两个输入必须具有非零方差。常量向量即使相同，分母也是0，数学上相关系数未定义；本API选择返回0作为退化哨兵（相关距离为1），不能解释为“完全相关”或已证明统计不相关。空白图会在匹配前拒识。定义与边界可对照[SciPy官方Pearson说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)。

网页、Node与shared现在使用同一套特征：默认combined为85维（统计5+Hu7+投影32+网格16+低分辨率像素25），HOG默认为324维。HOG选项会实际调用HOG，未知特征类型直接报错；不会悄悄退回combined。L2归一化使整个向量模长一致，不能保证不同特征组的贡献均衡，混合特征还需考虑尺度和权重。

## 常见问题与解决方案

### 1. 匹配准确率低

**可能原因：**
- 预处理不充分（尺寸不统一、未居中）
- 特征选择不当
- 模板质量差

**解决方案：**
- 确保严格的预处理流程
- 尝试不同的特征组合
- 使用高质量的标准模板

### 2. 相似字符混淆

**问题**：如 0/O、1/l/I、6/9 等容易混淆

**解决方案：**
- 添加区分性特征（如上下文信息）
- 使用更精细的特征（如 HOG）
- 引入后处理校正

### 3. 新字符无法识别

**问题**：模板库中没有的字符会被错误识别

**解决方案：**
- 设置拒绝阈值
- 返回置信度，低于阈值标记为"未知"
- 扩展模板库

## 自测问题

学完本章后，你应该能回答以下问题：

1. 模板匹配的基本原理是什么？
2. 欧氏距离和余弦相似度有什么区别？什么时候用哪个？
3. 为什么需要对图像进行归一化处理？
4. 模板匹配有哪些主要局限性？
5. 如何处理模板库中没有的字符？

<details>
<summary>点击查看答案</summary>

1. **模板匹配原理**：将待识别字符的特征与预先存储的模板特征逐一比较，选择最相似（距离最小）的模板对应的类别作为识别结果。

2. **欧氏距离 vs 余弦相似度**：
   - 欧氏距离关注向量的绝对位置，对尺度敏感
   - 余弦相似度只关注向量方向，对尺度不敏感
   - 特征已归一化时用欧氏距离；需要忽略幅度差异时用余弦相似度

3. **归一化的必要性**：
   - 尺寸归一化：确保所有字符图像大小一致，特征向量长度相同
   - 居中对齐：减少位置偏移的影响
   - 特征归一化：使不同特征维度的贡献均衡

4. **模板匹配的局限性**：
   - 对变形敏感（旋转、倾斜）
   - 对字体变化敏感
   - 对手写体效果差
   - 计算量随模板数量线性增长
   - 无法识别新类别

5. **处理未知字符**：
   - 设置拒绝阈值，距离超过阈值判定为"未知"
   - 计算置信度，低置信度结果标记为不确定
   - 返回 Top-N 候选结果供人工复核
