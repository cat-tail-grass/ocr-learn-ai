# 07. 倾斜校正 (Deskewing / Skew Correction)

## 学习目标

文档图像经常因为拍摄角度或扫描不当而产生倾斜，这会严重影响 OCR 识别效果。本章将帮助你掌握：

1. **倾斜的概念** - 什么是文档倾斜，为什么需要校正
2. **投影分析法** - 通过水平投影方差检测倾斜角度（重点）
3. **霍夫变换** - 检测图像中的直线来确定倾斜角度
4. **仿射变换** - 图像旋转的数学基础
5. **双线性插值** - 旋转后像素值的计算方法
6. **完整的倾斜校正流程** - 从检测到校正的完整实现

## 核心概念

### 1. 什么是文档倾斜？

文档倾斜是指文字行相对于水平方向产生的偏转角度。

```
正常文档：                     倾斜文档（顺时针5°）：
┌─────────────────────┐       ┌─────────────────────┐
│ 这是第一行文字       │       │   这是第一行文字     │
│ 这是第二行文字       │       │     这是第二行文字   │
│ 这是第三行文字       │       │       这是第三行文字 │
└─────────────────────┘       └─────────────────────┘
```

**倾斜的影响：**
- ❌ 文本行检测失败
- ❌ 字符分割错误
- ❌ OCR 识别准确率大幅下降
- ❌ 排版信息丢失

**常见倾斜原因：**
- 扫描时文档放置不正
- 拍照时相机角度不正
- 原始文档本身就是倾斜的

### 2. 倾斜检测方法

#### 方法一：投影分析法（推荐）⭐

投影分析法的原理：**对规整的多行文档，水平时投影通常更"尖锐"（启发式，并非任意图像的定理）**。

```
原理图解：

水平投影 = 统计每一行的黑色像素数量

正常文档的水平投影：          倾斜文档的水平投影：
文字 ▓▓▓▓▓▓▓▓▓▓  →  ██████     文字 ▓▓▓▓▓▓▓▓  →  ████
空白             →                 混合      →  ███
文字 ▓▓▓▓▓▓▓▓▓▓  →  ██████     文字 ▓▓▓▓▓▓▓▓  →  █████
空白             →                 混合      →  ██
文字 ▓▓▓▓▓▓▓▓▓▓  →  ██████     文字 ▓▓▓▓▓▓▓▓  →  ████

峰值明显，波谷清晰            峰值平缓，对比度低
方差大                        方差小
```

**算法步骤：**

1. 将图像旋转不同角度（如 -15° 到 +15°，步长 0.5°）
2. 对每个角度计算水平投影直方图
3. 计算投影直方图的方差
4. 方差最大的**试转角是校正角**，输入倾斜角为它的相反数

```
伪代码：
for angle in range(-15, 15, 0.5):
    rotated = rotate(image, angle)
    projection = horizontalProjection(rotated)
    variance = calculateVariance(projection)
    if variance > maxVariance:
        maxVariance = variance
        bestAngle = angle
```

#### 方法二：霍夫变换 (Hough Transform)

霍夫变换是一种检测图像中直线的经典方法。

**极坐标表示直线：**

```
笛卡尔坐标：y = kx + b （斜率+截距）
极坐标：ρ = x·cos(θ) + y·sin(θ)

其中：
- ρ（rho）：沿法线的带符号距离，可正可负
- θ（theta）：垂线与 x 轴的夹角

为什么用极坐标？
- 笛卡尔坐标无法表示垂直线（斜率无穷大）
- 极坐标可以表示任意方向的直线
```

**霍夫变换原理：**

```
图像空间的一个点 → 参数空间的一条正弦曲线
图像空间的一条直线 → 参数空间的一个交点

┌──────────────────┐      ┌──────────────────┐
│ 图像空间          │      │ 参数空间 (ρ-θ)   │
│   •               │      │   ╲  ╱           │
│     •             │  →   │    ╲╱            │
│       •           │      │    ╱╲ ← 交点     │
│ 三个点共线        │      │   ╱  ╲           │
└──────────────────┘      └──────────────────┘
```

**霍夫变换检测倾斜角度步骤：**

1. 对二值图像进行边缘检测（或直接使用二值图）
2. 建立霍夫累加器（ρ-θ 空间的二维数组）
3. 对每个前景像素，计算所有可能的 (ρ, θ) 值并累加
4. 找出累加器中的峰值点
5. 统计所有检测到的直线的角度
6. 将法线角转成直线方向，再转成校正角。本章取水平附近每个θ的最大ρ票数作教学评分，校正角 `c=θ−90°`（当前y向下、正旋转视觉逆时针约定）。例如水平线 `θ=90°`，校正角0；向右下倾斜5°的线，法线θ=95°，校正角+5°。

不能把同一θ下全部ρ票数相加来选角：每个黑像素对每个θ都投一票，总和恒等于黑像素总数。我们取 `score(θ)=maxρ accumulator(θ,ρ)`；这是单个最强直线的简化估计，不是完整的峰检测/多行鲁棒统计。表格边框或长线可能盖过文字。

### 3. 图像旋转原理

**统一坐标与API语义：** 像素中心 `(x,y)` 为整数，x向右、y向下，`rotateImage(+θ)` 表示视觉逆时针。中心为 `cx=(W−1)/2, cy=(H−1)/2`。`detectSkewAngle().angle` 为可直接应用的校正角 `c`，`skewAngle=−c` 为推断的输入倾斜角；`deskew().angle` 与 `correctionAngle` 都等于 `c`。例如模拟 `+5°` 后检测约 `−5°`，误差是 `|c+5°|`，绝不能再旋转 `−c`。

#### 仿射变换 (Affine Transformation)

仿射变换是一种保持直线和平行线性质的几何变换。

```
仿射变换矩阵（2D旋转）：

┌ x' ┐   ┌ cos(θ)   sin(θ) ┐ ┌ x ┐   ┌ tx ┐
│    │ = │                 │ │   │ + │    │
└ y' ┘   └-sin(θ)   cos(θ) ┘ └ y ┘   └ ty ┘

其中：
- (x, y) 是原始坐标
- (x', y') 是变换后的坐标
- θ 是旋转角度
- (tx, ty) 是平移量（用于绕图像中心旋转）
```

**绕图像中心旋转的完整公式：**

```javascript
// 1. 将坐标原点移到图像中心
const cx = (width - 1) / 2;
const cy = (height - 1) / 2;

// 2. 对于目标图像的每个像素 (x', y')
//    计算它在原图中的对应位置 (x, y)
// 使用逆变换：
x = (x' - cx) * cos(θ) - (y' - cy) * sin(θ) + cx;
y = (x' - cx) * sin(θ) + (y' - cy) * cos(θ) + cy;
```

#### 为什么使用逆变换？

```
正向变换的问题：
原图像素 → 目标位置可能不是整数 → 目标图像出现空洞

┌───────┐    正向     ┌───────┐
│ • • • │    ────→    │ •   • │  ← 有空洞！
│ • • • │             │   •   │
└───────┘             └───────┘

逆向变换的解决方案：
遍历目标的每个像素 → 计算它对应原图的哪个位置 → 采样得到颜色值

┌───────┐    逆向     ┌───────┐
│       │    ←────    │ • • • │  ← 无空洞！
│       │             │ • • • │
└───────┘             └───────┘
```

### 4. 插值算法

逆变换得到的原图坐标通常不是整数，需要用插值算法计算像素值。

#### 最近邻插值 (Nearest Neighbor)

```
最简单的方法：取最近的整数坐标

(3.7, 2.3) → (4, 2)

优点：快速
缺点：锯齿明显，图像粗糙
```

#### 双线性插值 (Bilinear Interpolation) ⭐

```
使用周围4个像素的加权平均

     x1        x2
   ┌───┬───────┬───┐
y1 │ Q11│       │Q12│
   ├───┼───●───┼───┤  ← (x, y) 落在这里
   │   │ (x,y) │   │
y2 │ Q21│       │Q22│
   └───┴───────┴───┘

计算步骤：
1. 在 x 方向插值：
   R1 = Q11 × (x2-x) + Q12 × (x-x1)
   R2 = Q21 × (x2-x) + Q22 × (x-x1)

2. 在 y 方向插值：
   P = R1 × (y2-y) + R2 × (y-y1)

优点：平滑，效果好
缺点：比最近邻稍慢
```

#### 双三次插值 (Bicubic Interpolation)

```
使用周围16个像素进行插值

优点：可改善平滑度并保留部分细节
缺点：计算量大，部分核会过冲或振铃；本章未实现
```

**本章选择：** 搜索使用最近邻，保持0/255；最终可切换最近邻与双线性。双线性会产生中间灰度，后续若要求严格二值应再二值化。它没有适用于所有OCR输入的最优保证。

**插值算例和边界：** `Q11=0,Q12=100,Q21=200,Q22=240`，`u=0.25,v=0.5`，`R1=25,R2=210,P=117.5`，四舍五入输出118。公式默认 `x2−x1=y2−y1=1`。图外采样点用指定常量背景，保留最右列/最下行整数像素；0°灰度旋转必须逐像素恒等，1×1也不能变白。输出尺寸固定，所以非零角可能裁剪角落内容；这不是透视或90°方向分类器。

### 5. 完整的倾斜校正流程

```
原始图像
    ↓
  灰度化（如果是彩色图）
    ↓
  二值化（Otsu 自动阈值）
    ↓
  倾斜检测（投影分析法 / 霍夫变换）
    ↓
  获得可直接应用的校正角 c
    ↓
  图像旋转（仿射变换 + 双线性插值）
    ↓
校正后图像
```

## 在 OCR 中的应用

倾斜校正在 OCR 预处理链中的位置：

```
彩色图 → 灰度图 → 二值图 → 去噪 → 形态学 → [倾斜校正] → 文字检测 → 文字识别
                                                ↑
                                           当前学习
```

### OCR 中倾斜校正的注意事项

| 场景 | 处理建议 |
|------|---------|
| 小角度倾斜 (±5°以内) | 使用细步长检测（如 0.1°） |
| 大角度倾斜 (5°-15°) | 使用粗步长 + 细化（先 1° 再 0.1°） |
| 90° 倍数倾斜 | 先检测是否需要 90° 旋转 |
| 透视变形 | 需要透视校正（超出本章范围） |

### 性能优化技巧

```
1. 缩小图像检测角度
   - 检测阶段使用缩小的图像（如 1/4 尺寸）
   - 旋转阶段使用原始图像

2. 两阶段检测
   - 第一阶段：粗搜索（-15° 到 +15°，步长 1°）
   - 第二阶段：细搜索（最佳角度 ±粗步长，并限制在原搜索范围，步长 0.1°）

3. 缓存三角函数
   - 预计算 sin(θ) 和 cos(θ)
   - 避免在循环中重复计算
```

## 搜索评分的限制

`H[y]` 长度为图高，值为该行黑像素数；总和为前景数。例如 `[0,4,0,4]` 均值2、总体方差4。搜索K个角度复杂度约 `O(KWH)`。粗搜索和细化均包含端点，细化区间固定，步长须为正；分数相同优先绝对值较小的旋转。全白/全黑没有方向证据，返回0°且 `informative=false`。这个标志只排除常量图，不是置信度。稀疏单字、图形、多栏、裁剪或大角度超出范围时，最大方差仍可能不是真实方向。

## 数学公式总结

### 投影方差计算

```
方差 = Σ(xi - μ)² / n

其中：
- xi = 第 i 行的黑色像素数
- μ = 平均每行黑色像素数
- n = 行数
```

### 旋转变换（绕中心点）

```
逆变换公式（用于计算目标像素对应的原图位置）：

x_src = (x_dst - cx) * cos(θ) - (y_dst - cy) * sin(θ) + cx
y_src = (x_dst - cx) * sin(θ) + (y_dst - cy) * cos(θ) + cy

其中：
- (x_dst, y_dst) = 目标图像坐标
- (x_src, y_src) = 原图像坐标
- (cx, cy) = 图像中心点
- θ = 旋转角度（弧度）
```

### 双线性插值

```
f(x, y) = f(x1,y1)*(x2-x)*(y2-y) + f(x2,y1)*(x-x1)*(y2-y)
        + f(x1,y2)*(x2-x)*(y-y1) + f(x2,y2)*(x-x1)*(y-y1)

其中：
- (x1, y1), (x2, y2) 是 (x, y) 周围的整数坐标
- f(xi, yi) 是对应位置的像素值
```

学完本章后，你应该能回答以下问题：

1. 为什么文档倾斜会影响 OCR 识别效果？
2. 投影分析法检测倾斜角度的原理是什么？
3. 为什么图像旋转要使用逆变换？
4. 双线性插值和最近邻插值有什么区别？
5. 如何优化倾斜检测的性能？

<details>
<summary>点击查看答案</summary>

1. 倾斜导致：文本行检测困难、字符分割错误、投影分析失效，因为 OCR 算法通常假设文字是水平排列的。

2. 文档水平时，水平投影会出现明显的峰谷交替（文字行是峰，行间距是谷）；倾斜时这种规律被破坏。通过旋转图像到不同角度，计算投影方差，方差最大的试转角就是可直接应用的校正角，其相反数为估计的输入倾斜角。

3. 正向变换时，原图的整数坐标映射到目标图像可能是小数坐标，导致目标图像有空洞。逆变换遍历目标图像的每个整数坐标，反算原图位置（可以是小数），通过插值得到像素值，确保目标图像每个位置都有值。

4. 最近邻插值简单快速但有锯齿；双线性插值使用周围4个像素的加权平均，结果更平滑，需按二值性与平滑度要求选择。

5. 优化方法：(1) 检测阶段使用缩小的图像；(2) 两阶段搜索（粗搜索 + 细化）；(3) 缓存三角函数值；(4) 只在必要区域采样计算投影。
