# 18. 循环神经网络：RNN、LSTM 与双向状态

## 学习目标与前置知识

第 15–17 章的 CNN 把二维图像变成特征。单个数字可以直接分类，整行数字还需要保留“从左到右”的次序。本章研究怎样让一个位置的计算使用其他位置的信息。第 19 章解决特征序列和字符标签的对齐，第 20 章再把图像、循环网络和对齐损失接起来。

学完应能：

1. 写出并手算 RNN 的时间展开，区分输入、状态和参数。
2. 用链式法则解释梯度为什么会消失或爆炸。
3. 按输入门、遗忘门、候选记忆、输出门计算 LSTM。
4. 解释双向网络如何看见右侧上下文，以及为什么不能直接用于零延迟流式预测。
5. 对照同一份 JavaScript 算法检查 Node 与浏览器的数值结果。

前置知识：第 14 章矩阵乘法、tanh/sigmoid、链式法则和梯度下降；第 15 章通道与特征；第 16 章张量维度。这里不依赖第 17 章权重或数据文件。

**实验边界：** 本章权重由人设置，用于追踪前向计算和标量状态灵敏度；没有训练一个文字识别器。可训练的 CNN + BiLSTM + CTC 在第 20 章。

## 1. 状态为什么能携带次序

若对每列图像独立分类，相同局部笔画很难区分；若把所有列平均，又会丢掉顺序。RNN 将上一步状态作为下一步输入的一部分：

```text
x₀ ──→ [同一组参数] ──→ h₀
                         ↓
x₁ ──→ [同一组参数] ──→ h₁
                         ↓
x₂ ──→ [同一组参数] ──→ h₂
```

图里的时间步 `t` 在 OCR 中通常是图像从左到右的**特征列索引**，不是字符序号，也不是拍照时间。一个字符可以覆盖多列，一个列特征也可能包含两个相邻字符的笔画。

时间展开画了多个单元，但它们共享同一组权重。输入变长增加运算量和训练时的中间状态，不增加模型参数数量。训练若保留整段计算图，必须为反向传播保存各步激活，内存会随长度增加。

## 2. RNN 公式、符号与维度

本章采用**行向量**约定，与代码的 `x * Wx` 一致：

\[
a_t=x_tW_x+h_{t-1}W_h+b_h,\qquad h_t=\tanh(a_t)
\]

如果还要逐帧预测 K 个类别：

\[
z_t=h_tW_y+b_y,\qquad p_{t,k}=\frac{e^{z_{t,k}}}{\sum_j e^{z_{t,j}}}
\]

| 符号 | 维度 | 含义 |
|---|---|---|
| T | 标量整数 | 特征序列长度 |
| D | 标量整数 | 每步输入特征数 |
| H | 标量整数 | 隐藏状态宽度 |
| xₜ | `[D]` 或批次 `[B,D]` | 当前列的特征 |
| hₜ | `[H]` 或 `[B,H]` | 当前隐藏状态 |
| Wₓ | `[D,H]` | 输入到状态的参数 |
| Wₕ | `[H,H]` | 上一步状态到当前状态的参数 |
| bₕ | `[H]` | 状态偏置 |
| Wᵧ、bᵧ | `[H,K]`、`[K]` | 可选输出投影 |

核心单元参数量为 `D×H + H×H + H`；若 D=16、H=8，为 `128+64+8=200`。输出层参数另计。本章 `rnnForward` 只返回隐藏状态，不暗中做字符分类。

初始状态通常取零。代码用 `h_{-1}=0`、时间步从 0 开始；写作 `h_0=0`、输入从 1 开始也是同一个计算，比较公式时需先对齐索引。

### 手算四步

设 D=H=1、Wₓ=0.5、Wₕ=0.8、b=0，输入 `[1,0,-1,1]`：

1. `a₀ = 1×0.5 + 0×0.8 = 0.5`，`h₀=tanh(0.5)=0.462117`。
2. `a₁ = 0×0.5 + 0.462117×0.8 = 0.369694`，`h₁=0.353724`。
3. `a₂ = -0.5 + 0.353724×0.8 = -0.217021`，`h₂=-0.213677`。
4. `a₃ = 0.5 - 0.213677×0.8 = 0.329059`，`h₃=0.317675`。

即使第二步 x=0，输出也不必为 0，因为 h 传入了历史信息。序列重排通常改变结果。

## 3. 从时间展开到 BPTT

Backpropagation Through Time 是在展开的计算图上使用普通链式法则。它没有增加另一种神秘梯度规则。同一个 Wₕ 被使用 T 次，因此来自各时间步的参数梯度需要**相加**。

为书写 Jacobian，把隐藏状态看作列坐标；由于前向使用行向量，有：

\[
J_t=\frac{\partial h_t}{\partial h_{t-1}}
=\operatorname{diag}(1-h_t^2)W_h^\top
\]

\[
\frac{\partial h_t}{\partial h_s}=J_tJ_{t-1}\cdots J_{s+1},\quad -1\le s<t<T
\]

这里 Jacobian 的行是当前输出坐标、列是先前状态坐标，维度为 `[H,H]`。沿用本章零起点：T 步的最后状态是 `h_{T−1}`，初始状态是 `h_{−1}`，所以初始到最终的乘积为 `J_{T−1}⋯J₀`。反传损失的列梯度使用相应 Jacobian 的转置。

这条长乘积解释了梯度尺度问题：

- 许多方向的局部伸缩小于 1，乘积可能迅速接近 0，早期信息对损失的影响难以学习。
- 部分方向反复放大，乘积可能增长到数值不稳定。
- `tanh` 饱和时 `1-h²` 接近 0；所以只看 Wₕ 大小不足以判断实际梯度。
- 矩阵问题还受方向、奇异值和每步状态影响，不能把所有网络概括成一个标量权重的幂。

### 可核验的一维实验

`scalarSensitivity` 沿真实前向轨迹计算：

\[
\frac{\partial h_{T-1}}{\partial h_{\mathrm{init}}}
=\prod_{t=0}^{T-1} W_h(1-h_t^2),\quad h_{\mathrm{init}}=h_{-1}
\]

零输入、初始状态零时所有 h 都等于 0，所以 20 步后：

| Wₕ | 精确导数 Wₕ²⁰ |
|---|---:|
| 0.5 | 0.000000953674 |
| 0.9 | 0.121576655 |
| 1.2 | 38.337599924 |

把每步输入换成 4，Wₕ=1.2 时得到约 `2.16×10⁻⁷⁶`。这是饱和的反例：权重大于 1，真实梯度仍然可能消失。

独立测试还使用中心差分：`[h(init+ε)-h(init-ε)]/(2ε)` 核对解析导数。这比只断言某个函数返回某个常量更能检查链式法则是否正确。

### 常见缓解方法的分工

| 方法 | 能帮助什么 | 不能保证什么 |
|---|---|---|
| 梯度裁剪 | 限制一次更新的全局梯度范数 | 恢复已经消失的梯度 |
| 合理初始化 | 改善初期的传播尺度 | 所有训练阶段都稳定 |
| 截断 BPTT | 限制反向图长度和内存 | 学到截断窗口外的直接梯度依赖 |
| LSTM/GRU | 提供受控的记忆更新路径 | 任意长距离都完美记忆 |

第 20 章使用全局范数裁剪：`g ← g × min(1, 5/(||g||₂+ε))`，不是逐元素把梯度限制到 `[-5,5]`。

## 4. LSTM：让记忆以加法更新

本章实现常见的**带遗忘门、无 peephole 的 LSTM**，不把它等同于 1997 年论文每个细节。LSTM 的历史来源见原论文；后续双向 LSTM 论文与当前 TensorFlow.js 单元说明可对照现代门结构。[原作者资料](https://www.bioinf.jku.at/software/lstm/)、[Graves 与 Schmidhuber，2005](https://www.cs.toronto.edu/~graves/nn_2005.pdf)。

\[
\begin{aligned}
i_t&=\sigma(x_tW_{xi}+h_{t-1}W_{hi}+b_i)\\
f_t&=\sigma(x_tW_{xf}+h_{t-1}W_{hf}+b_f)\\
g_t&=\tanh(x_tW_{xg}+h_{t-1}W_{hg}+b_g)\\
o_t&=\sigma(x_tW_{xo}+h_{t-1}W_{ho}+b_o)\\
c_t&=f_t\odot c_{t-1}+i_t\odot g_t\\
h_t&=o_t\odot\tanh(c_t)
\end{aligned}
\]

`σ(a)=1/(1+exp(-a))`，`⊙` 是逐元素乘法。所有门、候选、c、h 都是 `[H]`，批量时为 `[B,H]`。

| 量 | 取值范围 | 作用 |
|---|---|---|
| i | (0,1) | 控制写入候选记忆的比例 |
| f | (0,1) | 控制旧记忆保留的比例 |
| g | (-1,1) | 提议新记忆内容，可正可负 |
| o | (0,1) | 控制记忆向外暴露的比例 |
| c | 无固定有限区间 | 沿时间携带的 cell 状态 |
| h | (-1,1) | 向下一层输出的隐藏状态 |

本章将 sigmoid 控制量 i、f、o 称为**三个门**，把 g 称为候选记忆分支；有些框架文档也称 g 为 cell gate，但它的 tanh 值不表示[0,1]的保留比例。门是连续数值，不是非黑即白的逻辑开关。不同维度可以有不同门值。表中开区间描述实数运算；浮点 sigmoid/tanh 在强饱和时可能舍入到端点，导数计算也可能下溢。

把上一步 `(c,h)` 视为单元的两个独立输入，在本章无 peephole 结构中，固定 `hₜ₋₁` 的直接记忆路径有 `∂cₜ/∂cₜ₋₁=diag(fₜ)`，维度为 `[H,H]`；只有一维或逐坐标书写时才简写为 f。f 接近 1 时更容易保留信息。但完整时间展开还经过 h 到三个门及候选的路径，输出端还有 tanh 和输出门，不能从这个局部偏导推导“LSTM 永不梯度消失”。

例如将完整状态排成 `[c;h]`，记 `A=∂cₜ/∂hₜ₋₁`、`F=diag(fₜ)`、`Q=diag(oₜ⊙(1−tanh²(cₜ)))`、`R=diag(tanh(cₜ))∂oₜ/∂hₜ₋₁`，则单步完整 Jacobian 是分块矩阵 `[[F,A],[QF,QA+R]]`，尺寸 `[2H,2H]`。长期梯度涉及这些完整矩阵的乘积，不能直接等同于遗忘门的连乘。

### 门值与 cell 的数值计算

本章演示取 H=D=1：`i=o=0.5`，`f=σ(1)=0.73105858`，`g=tanh(x)`，初始 c=h=0。

当 x=1：

```text
g = 0.76159416
c = 0.73105858×0 + 0.5×0.76159416 = 0.38079708
h = 0.5×tanh(0.38079708) = 0.18169974
```

第二步 x=0 时 g=0，`c=0.73105858×0.38079708=0.27838497`，`h=0.13570484`。输入归零仍保留部分记忆。

代码把四次仿射变换合并：`Wx[D,4H]`、`Wh[H,4H]`、`b[4H]`，列顺序固定为 **i、f、g、o**。参数量 `4H(D+H+1)`，D=16、H=8 时为 800。顺序是本模块的契约，导入别的框架权重时必须检查，不能凭变量名猜测。TensorFlow.js 4.22 高层 `layers.lstm` 的门激活默认是 `hardSigmoid`；要与本章数值对齐，需显式设 `recurrentActivation:'sigmoid'`，并对齐门顺序、权重与偏置。[4.22 官方源码](https://github.com/tensorflow/tfjs/blob/tfjs-v4.22.0/tfjs-layers/src/layers/recurrent.ts)

## 5. 双向 RNN / BiLSTM

两个独立网络分别从左到右和从右到左扫描：

\[
\overrightarrow h_t=F(x_t,\overrightarrow h_{t-1}),\quad
\overleftarrow h_t=G(x_t,\overleftarrow h_{t+1}),\quad
u_t=[\overrightarrow h_t;\overleftarrow h_t]
\]

每个方向 H 维，拼接后是 2H 维。两方向有各自参数；可以手设为相同数值做演示，但实际训练不强制共享。双向机制见[原作者双向 LSTM 论文](https://www.cs.toronto.edu/~graves/nn_2005.pdf)。

实现时先反转输入计算反向状态，再**把反向状态反转回来**，才能和正向状态在同一个图像位置拼接。忘了第二次反转就会把左端正向特征和右端反向特征错误配对。

测试把最后一个输入由 0 改成 2：前向第一步状态不变，反向第一步状态变化。这直接证明右側信息进入了左端表示。

整张照片已经拿到时，使用右侧信息是合法的离线建模；如果输入必须边到达边立即输出，双向模型要等待未来输入或分块处理，延迟与边界上下文都需要重新设计。

## 6. 原理到代码与运行

### 逐步实现：从仿射变换到循环

`affine` 对每个输出坐标先放入偏置，累加输入贡献，再累加历史状态贡献。这与公式一一对应，可以在两个内层循环分别打断点：

```javascript
const output = b.slice();
for (let j = 0; j < b.length; j++) {
    for (let k = 0; k < x.length; k++) {
        output[j] += x[k] * Wx[k][j];
    }
    for (let k = 0; k < h.length; k++) {
        output[j] += h[k] * Wh[k][j];
    }
}
```

普通RNN随后对每项做tanh，保存新h，再处理下一帧。LSTM先把合并仿射结果按H切成i/f/g/o四段，再执行门激活、cell加法与输出乘法。不要把四段都做sigmoid：i/f/o三个门用sigmoid，候选g需要允许负值，所以用tanh。

双向实现的关键代码：

```javascript
const forward = rnnForward(inputs, forwardParameters).states;
const reversedInputs = inputs.slice().reverse();
const backward = rnnForward(reversedInputs, backwardParameters).states.reverse();
const states = forward.map((h, t) => h.concat(backward[t]));
```

RNN每步主要为 `O(DH+H²)`，LSTM的三个门加候选分支约有四倍同类仿射工作，双向再计算两条链。减少序列长度能减计算，但在OCR中会改变第19章的可对齐长度条件，不能只按吞吐调参。

### 方法与参数对照

| 选择 | 状态 | 主要机制 | 参数/使用边界 |
|---|---|---|---|
| 普通RNN | h | 非线性递归 | 最简；长乘积梯度受饱和影响 |
| LSTM | h、c | 门控写入、保留和输出 | 三个门加候选四组参数；记忆仍可衰减 |
| 双向RNN/LSTM | 每方向独立状态 | 同位置拼接左右上下文 | 输出维度翻倍；依赖未来输入 |

固定初始c=1、零候选写入，20步后的cell恰好为 `σ(b_f)^20`。Node实验5比较b_f为−2、0、1、3；偏置增大使初始遗忘门更接近1。但如果训练任务需要及时忘记旧字符，把所有门永远设置到1也不合适。浏览器的遗忘门偏置滑块可观察同一输入的c/h变化，默认b_f=1。

## 7. 适用条件、局限与常见误区

- RNN 有顺序归纳偏置，适用于特征列、语音帧等序列；隐藏状态不是天然可读的字符意义。
- 更大 H 增加容量，也增加循环矩阵计算与参数；不能仅凭隐藏维度宣称识别率提升。
- LSTM 的 c 与 h 不同，不能只保存 h 再假装完整恢复了单元状态。
- BiLSTM 能用两侧上下文，但不会自动解决字符重复、blank 或长度不一致；这些属于 CTC 问题。
- 随机或手设权重的前向可视化只展示计算，不证明模型学会了 OCR。
- 第 25 章最终现场路线采用“分割 + CNN”，本章是整行序列识别路线的必要理论对照。

## 8. 自测与答案

**题 1：** D=16、H=8 的普通 RNN 核心有多少参数？长度从 10 增至 100 会增加参数吗？

**答：** `16×8+8×8+8=200`。参数共享，不增加参数；前向运算和需保存的中间状态增加。

**题 2：** 为什么第二步输入 0 时，RNN 状态不一定为 0？

**答：** 仍有 `hₜ₋₁Wₕ+b`，除非这些恰好为 0。

**题 3：** Wₕ=1.2 能保证梯度爆炸吗？

**答：** 不能，真实局部导数是 `1.2(1-h²)`。饱和的 tanh 可以把乘积压到很小。

**题 4：** 假设 f=0.9、i=0、旧 c=2，新 c 是多少？能从这些信息唯一确定 h 吗？

**答：** c=1.8；h 还需要输出门 o，`h=o·tanh(1.8)`。

**题 5：** 双向 H=8 拼接后多大？反向输入翻转后是否可以直接拼接？

**答：** 16 维。必须把反向输出恢复到原始时间顺序，再按同一位置拼接。

**题 6：** 本章的状态曲线能直接作为识别出的字符吗？

**答：** 不能，状态没有经过训练和类别投影；即使有逐帧类别，还要通过第 19 章的长度与对齐处理得到字符串。

## 9. 分享重点与衔接

建议以四步数值表开场，接着修改最后一个输入对比两个方向，再用循环权重滑块展示梯度的数量级。最后手算一次 LSTM 的 c 与 h，强调“加法记忆路径”和完整梯度的区别。

应保留的三张图/表：时间展开图、RNN/LSTM 维度表、单步三门与候选计算。收尾提出：图像有 10 列特征但真值只有“001”三个字符，逐帧监督标签从哪来？第 19 章用 CTC 对所有合法对齐求和回答这个问题。
