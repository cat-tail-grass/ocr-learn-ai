# 安装与使用

把整个 build-learning-course 文件夹复制到工具的技能目录，保留 scripts、references、assets、agents。只复制 SKILL.md 会缺少站点模板和检查程序。

- Codex：放入 `~/.codex/skills/build-learning-course/`；使用自定义 CODEX_HOME 时放入其 skills 目录。若当前会话尚未发现，重新打开任务。
- Claude Code：放入 `~/.claude/skills/build-learning-course/` 供个人项目使用，或项目下 `.claude/skills/build-learning-course/`。参见[官方技能说明](https://code.claude.com/docs/en/skills)。
- 其他支持 Agent Skills 的工具：按其技能安装方式导入整个目录，需要文件读写和命令执行能力。

技能本身没有 API Key 或付费插件要求。完整工作流需要宿主具备子代理能力：主会话提供上下文，每章由独立上下文的子代理生成并回报。生成阅读站需要 Node.js ≥22.18.0，首次安装依赖需要联网；浏览器检查使用宿主已有工具。普通聊天网页不能自动完成文件生成和运行验证。

## 开始一个课程

把下面的请求发给安装了技能的 Agent；Claude Code 也可以通过 `/build-learning-course` 调用。

> 使用 build-learning-course。我想系统学习微积分，会基础代数但没学过极限。目标是能解释并计算简单函数的导数，每周投入3小时。中文讲解，先给完整路线和一节包含交互实验的标杆课。

> 使用 build-learning-course。我想学习日常英语，认识基础单词，目标是能描述日常安排并应对临时变化。请用情境示范、网页练习与有解释的自测，先生成标杆课。

主会话先保存完整大纲，再逐章委派：准备本章上下文 → 子代理生成、自检并回报 → 主会话验收或退回修订。每章都有 tasks 任务单和 reviews 验收记录。每批可以交付几章，但每次子代理只生成一章，通过后才推进下一章。

你会先得到课程路线、一节完整标杆课和本地预览。阅读后反馈讲解深度、练习效果和页面体验；确认合适后，告诉 Agent 继续下一批。工具没有子代理能力时，Agent 会先交付大纲与任务单并说明限制；只有你明确接受，才改由主会话生成。

## 调整与继续

> 本章符号出现得太早。请先给一个具体情境，用同一例子逐步解释；保留推导，把长接口表折叠。修订标杆后，将这条偏好记录进课程。

> 标杆课的深度和交互我认可，请按同一标准继续下一批，并复核知识正确性与实验结果。

## 分享时说明

本技能封装了教学结构、现有课程站模板、生成节奏与质量检查。它帮助复用打磨过程；不同知识领域、模型和工具条件仍会影响结果。先展示已检验的标杆，再决定是否扩写整套课程。

阅读框架与教学尺度提炼自 ocr-learn-ai；课程主题、章节数量、术语和实践入口均可配置，不需要同时安装原项目。参考依据见 references/runtime.md，具体结构见 references/planning.md。
