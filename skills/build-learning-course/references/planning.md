# 规划与学科适配

## 学习终点与路线

把目标写成可观察的能力或作品，并说明边界。先列出支撑目标的知识依赖，再划分章节；每章要能独立讲透，并连向后续能力。阶段末安排一个综合任务，最后的任务覆盖目标，但不机械使用每一种方法。

在生成章节正文前完成大纲。OUTLINE.md 除目录表外，还需写出每章的学习目标、前置知识、内容边界、实践成果及验收依据。主会话核对它与 course.json 一致，再据此准备单章任务单；执行分工遵循[逐章委派协议](chapter-delegation.md)。

完整路线不等于立即生成所有讲义。标杆优先选基础之后第一个有代表性的核心点；其前置知识必须已由学习者具备、在标杆中作足够解释，或先生成必要的小节。避免选择仅需罗列名词的绪论作为质量样本。

## 载体选择

| 学科 | 可核对的示例 | 合适的实践 | 自测与边界 |
| --- | --- | --- | --- |
| 微积分 | 同一函数、相同取值逐步计算变化率 | 调节增量观察割线和数值，脚本复算 | 新取值计算、错误推导、不可用情形 |
| 英语 | 固定人物与情境，逐步比较表达 | 选句、补全、纠错和自由表达的参考评价 | 区分形式错误、含义变化与同样正确的变体 |
| 后端开发 | 请求经过路由、服务、存储的全过程 | 可运行 API、请求对照、错误处理 | 异常输入、并发/数据约束与失败解释 |
| 工程原理 | 单位明确的模型和理想化假设 | 仿真、观测、比例实验与模型对照 | 单位检查、适用边界、模型与实际工程的差异 |

只在载体确实帮助掌握目标时采用。纯静态结果不能代替可操作实验；开放表达不能仅用一个字符串作为正确答案。使用者希望学习的编程语言与工具，由课程目标决定。

## course.json

它是目录顺序、阶段、实践入口和材料状态的唯一来源。以下为配置格式示例，主题与章节需按实际课程替换；示例只用于说明格式。

```json
{
  "schemaVersion": 1,
  "title": "变化率入门",
  "description": "从平均变化率逐步理解瞬时变化率。",
  "lang": "zh-CN",
  "audience": "会代数运算、尚未学过微积分的学习者",
  "outcome": "能计算并解释简单函数的变化率，识别计算的适用边界",
  "terms": ["平均变化率", "瞬时变化率"],
  "calibration": { "lesson": "01-average-rate", "status": "pending", "feedback": "" },
  "stages": [{
    "title": "从区间变化到局部变化",
    "lessons": [
      { "slug": "01-average-rate", "title": "平均变化率", "prerequisites": [], "status": "planned", "web": true, "node": true },
      { "slug": "02-instantaneous-rate", "title": "瞬时变化率", "prerequisites": ["01-average-rate"], "status": "planned", "web": true, "node": true }
    ]
  }]
}
```

- 初始化时所有章节 status 均为 planned；子代理完整写好某章后只将该章改为 draft，并登记实际入口。主会话依质量表验收、在 reviews/<slug>.md 写明结论后，才可改为 verified。verified 是材料验收，不表示学习者掌握。
- slug 从 01 连续编号，用英文小写短横线命名；prerequisites 只引用前面的章节。学习者已有的外部基础写入 COURSE_BRIEF 和本章前置知识。
- web=true 对应该章 index.html，node=true 对应 index.js；两者可各自选择。无入口时为 false，站点会隐藏对应按钮。
- terms 填本课程的重要术语，供中文搜索保留词组。
- calibration.status 由使用者校准结果决定，生成器或测试通过不能代替使用者认可。
- 新增章节、修改阶段或入口后重启开发服务，避免使用旧目录缓存。

## 继续已有项目

课程范围、语言和已确认尺度优先使用项目记录，同时读取本章 tasks、子代理回报和主会话验收结论。文件事实与旧记录冲突时以实际文件、最新验证和使用者最新自述分别校正。若用户只要求修订一章，保持其余章节与学习状态，不扩大任务。
