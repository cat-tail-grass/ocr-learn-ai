# 14. 神经网络基础：从数值梯度到可学习的 MLP

本章用 JavaScript 手写前向传播、二元交叉熵、反向传播和梯度下降。先验证每个参数的导数，再让网络学习 XOR，最后解释这些运算怎样迁移到字符识别。所有演示使用同一份共享算法，没有框架自动求导，也不依赖尚未学习的章节。

## 学习目标与 OCR 中的位置

完成本章实践后，应能独立解释并计算：

1. 感知机的加权和与决策边界，以及隐藏层为什么需要非线性。
2. Sigmoid、tanh、ReLU 的值、导数和饱和/失活条件。
3. 每一层的输入、权重、偏置、激活与维度变化。
4. 从概率得到损失，从损失经链式法则得到每个参数的梯度。
5. 用数值差分验证解析梯度，再执行可复现的真实训练。
6. 区分训练拟合、数值正确性、泛化成绩和模型得分。

前置知识是第 11–13 章的特征向量、分类和训练/验证/测试划分，再加向量点积与一元函数求导。不要求重新学习图像预处理。

```text
照片 → 预处理 → 定位与分割 → 单字符图像 → 特征表示 → 分类得分 → 字符
                                                   ↑
                 本章解释如何通过损失学习“表示与分类器”的参数
```

KNN 主要保存样本并计算邻居距离；MLP 将训练样本的规律压入权重。输入可以是第 11 章的特征向量，也可以是展开后的像素。输出为 0–9 时需要十类分类头，本章先限定为二分类，集中讲透梯度计算；这里的 XOR 模型不能直接拿来识别数字。

## 1. 先给梯度建立一个独立的验算标准

### 动机与直觉

反向传播有时写错了索引、转置或平均因子，但损失仍然下降。仅看“能训练”无法证明实现正确。梯度的定义给了我们第二条计算路径：轻轻增加某个参数，再轻轻减少它，观察损失变化。

令所有参数组成向量 θ，θᵢ 是第 i 个参数，eᵢ 仅第 i 位为 1。保持输入、标签和其他参数不变：

```text
g_num[i] = (L(θ + εeᵢ) − L(θ − εeᵢ)) / (2ε)
```

对光滑函数在 θ 附近作泰勒展开，正负扰动相减后，偶数阶项抵消：

```text
L(θ+εeᵢ) = L(θ) + εgᵢ + ε²Hᵢᵢ/2 + O(ε³)
L(θ−εeᵢ) = L(θ) − εgᵢ + ε²Hᵢᵢ/2 − O(ε³)
中心差分 = gᵢ + O(ε²)
```

这解释了为什么使用中心差分，而不是只做一次向前扰动。本章用双精度 `Float64Array`，默认 ε=10⁻⁵。

### 可手算例子

先不涉及网络：L(w)=w²，w=3，ε=0.01。

```text
L(3.01)=9.0601，L(2.99)=8.9401
g_num=(9.0601−8.9401)/0.02=6
g_analytic=2w=6
```

网络中只需把 `w*w` 替换成完整的前向损失。对于 P 个参数，中心差分约需 2P 次损失计算；反向传播一次即可得到全部梯度。因此数值差分用于小模型验算，不用于大模型日常训练。

### 对应实现与误差判据

`gradientCheck(model,samples)` 先复制模型，对每个权重和偏置分别扰动，只调用前向损失函数；解析结果来自另一条 `backward` 路径。原模型不会被改变。

```javascript
const check = gradientCheck(model, samples, { epsilon: 1e-5 });
console.log(check.passed, check.maxAbsError, check.maxRelativeError);
console.table(check.entries); // 参数名、解析值、数值值、误差
```

误差同时看绝对值与尺度：

```text
absError = |g_num − g_analytic|
relativeError = absError / max(10⁻⁸, |g_num| + |g_analytic|)
通过条件：absError ≤ 10⁻⁷ + 10⁻⁴ × (|g_num| + |g_analytic|)
```

很小的导数容易出现“相对误差大、绝对误差极小”；不能只用相对误差否定实现。ε 太大时不再局部，太小时两个相近浮点数相减损失精度。ReLU 在 0 不可导，跨折点的中心差分也不能与一个指定的单侧导数直接比较。应先用光滑的 tanh 或 Sigmoid，在非饱和的小网络上检查。

## 2. 感知机：可调参数怎样形成决策边界

### 动机与定义

例如已有两个字符特征 x₁、x₂，想把它们组合成一个“属于目标类别”的分数。单个神经元先做仿射变换：

```text
z = w₁x₁ + w₂x₂ + b = wᵀx + b
ŷ = 1[z ≥ 0]
```

x 是输入，w 是权重，b 是偏置，z 是阈值判断前的分数。权重控制特征的方向和相对贡献，偏置移动边界。二维中 `w₁x₁+w₂x₂+b=0` 是直线；高维中是超平面。

固定例子：w=[1,1]、b=−1.5，则 [0,0]、[0,1]、[1,0] 的 z 分别为 −1.5、−0.5、−0.5，[1,1] 的 z=0.5，所以能表达 AND。

经典感知机在分类错误时可按下式更新：

```text
w ← w + η(y−ŷ)x
b ← b + η(y−ŷ)
```

这里 η 是学习率；这是感知机的误分类更新规则。本章实现的 MLP 使用后文的可微交叉熵目标，并不对硬阈值直接求导。

### XOR 为什么需要新表示

XOR 的四个点为 00→0、01→1、10→1、11→0。假设一条直线能够在阈值 `z≥0` 下全分对，就必须有：

```text
b<0，w₂+b≥0，w₁+b≥0，w₁+w₂+b<0
```

中间两式相加得 `w₁+w₂+2b≥0`，于是 `w₁+w₂+b≥−b>0`，与最后一式矛盾。这个困难来自表示能力，不是“训练次数不够”。

实现对照可以直接设 `sizes:[2,1]`，得到单个 logistic 分类器；它的概率是平滑的，但 0.5 决策边界仍是同一条直线。加隐藏层并加入非线性后，网络可先把输入映射到新空间，再作线性分类。

**参数影响与局限：**增加层宽能增加表达能力，也增加参数和过拟合可能；不保证优化成功。把多个没有非线性的仿射层叠起来仍然只是一个仿射层，因为 `W₂(W₁x+b₁)+b₂=(W₂W₁)x+(W₂b₁+b₂)`。

## 3. 激活函数：改变表示，也改变梯度

### 定义、导数与数值

| 激活 | 定义 a=f(z) | 导数 f′(z) | z=0 | 主要用途与限制 |
|---|---|---|---|---|
| Sigmoid | 1/(1+e⁻ᶻ) | a(1−a) | a=0.5，导数=0.25 | 二分类概率；隐藏层深时容易饱和 |
| tanh | (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ) | 1−a² | a=0，导数=1 | 零中心的隐藏表示；两端仍饱和 |
| ReLU | max(0,z) | z>0 为1，z<0 为0 | 不可导，本章选0 | 正半轴不饱和；负半轴可能长期无梯度 |

Sigmoid 的导数从商式求导可得：

```text
d/dz (1+e⁻ᶻ)⁻¹ = e⁻ᶻ/(1+e⁻ᶻ)²
                  = [1/(1+e⁻ᶻ)] × [e⁻ᶻ/(1+e⁻ᶻ)]
                  = a(1−a)
```

手算 `z=ln(3)`：e⁻ᶻ=1/3，a=3/4，导数=3/16=0.1875。ReLU 在 z=−2 时输出与导数均为0；在 z=2 时输出2、导数1。

### 实现步骤与稳定性

1. 计算加权和 z，先检查是否为有限数。
2. 隐藏层按激活类型映射得到 a，并保留 z 供反向使用。
3. 最后一层保留原始 logit；概率仅由最终 Sigmoid 得到。
4. 求隐藏层导数时，必须使用同一次前向的 z。

Sigmoid 的稳定实现分正负分支：z≥0 使用 `1/(1+exp(-z))`；z<0 令 e=exp(z)，返回 `e/(1+e)`。这避免 z=−1000 时计算 `exp(1000)`。

**参数影响：**特征或初始权重过大会让 Sigmoid/tanh 接近饱和；此时改变参数对输出影响很小，导数也小。多个层的导数相乘可能逐层变小。ReLU 的正半轴改善了这类饱和，但若某单元对所有训练样本都处于负半轴，梯度为0，它可能无法恢复。浏览器允许切换激活并重置，Node 表格同时打印值和导数，不用口头判断“哪个总是最好”。

## 4. 前向传播：先把维度写清楚

对第 l 层，输入宽度 dₗ₋₁，输出宽度 dₗ：

```text
a⁽⁰⁾ = x                  形状 [d₀]
W⁽ˡ⁾                      形状 [dₗ,dₗ₋₁]
b⁽ˡ⁾                      形状 [dₗ]
z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾+b⁽ˡ⁾  形状 [dₗ]
a⁽ˡ⁾ = f(z⁽ˡ⁾)            形状 [dₗ]，仅隐藏层
```

默认 2→4→1 的参数计算：

| 层 | 输入 | W | b | 输出 | 参数数量 |
|---|---|---|---|---|---|
| 隐藏层 | [2] | [4,2] | [4] | [4] | 4×2+4=12 |
| 输出层 | [4] | [1,4] | [1] | logit [1] | 1×4+1=5 |
| 合计 | | | | | 17 |

`weights[o*inputSize+i]` 表示第 o 个输出对第 i 个输入的权重。每一行计算一个输出神经元：

```javascript
let z = biases[o];
for (let i = 0; i < inputSize; i++) {
    z += weights[o * inputSize + i] * previous[i];
}
```

`forward` 返回 `preActivations`、`activations`、`logit` 和 `probability`。其中 `activations[0]` 是输入；最后一个 `activations` 元素保留 logit，不是最终概率。这是明确的实现约定，便于把输出层与稳定损失组合。

### 手算 2→2→1 前向

令 x=[1,2]、y=1，隐藏激活为 Sigmoid：

```text
W¹ = [ 0.1  0.2 ]    b¹=[0,0]
     [-0.1  0.1 ]
W² = [0.3 -0.2]       b²=[0.1]

z¹=[0.1×1+0.2×2, −0.1×1+0.1×2]=[0.5,0.1]
a¹=[0.6224593312,0.5249791875]
z²=0.3×0.6224593312−0.2×0.5249791875+0.1
  =0.1817419619
p=σ(z²)=0.5453108405
```

本章 `traceExample()` 用上述权重调用真实共享函数，并返回更新前后模型。没有另一套写死的“正确结果计算器”。

**适用条件与局限：**前向传播只是确定函数值，不会学习；输入归一化和参数顺序必须与训练一致。MLP 将像素展开后不显式利用二维邻接关系，28×28 到128个隐藏单元就有 `(784+1)×128=100480` 个参数，这正是下一章引入局部连接的动机之一。

## 5. 损失函数：为什么分类准确率不能直接训练

### 从概率模型得到二元交叉熵

0/1 准确率只在跨越阈值时变化，大部分位置没有可用的梯度。希望预测正确类别的概率越大越好，可使用 Bernoulli 似然：

```text
P(y|x)=pʸ(1−p)¹⁻ʸ，y∈{0,1}
ℓ = −log P(y|x) = −y log p − (1−y)log(1−p)
L = (1/N) Σₙ ℓₙ
```

p 是模型给正类的概率，ℓ 是单样本损失，L 是 N 个样本的平均损失。独立样本的似然相乘，取对数后变成求和；取负号后最小化损失等价于最大化似然。

数值例子：当 y=1，p=0.8 时 ℓ≈0.223144；p=0.2 时 ℓ≈1.609438；p=0.5 时 ℓ≈0.693147。预测越自信地错，代价越高。上节算例 y=1、p≈0.545311，得到 ℓ≈0.6063992975。

### 为什么直接用 logit 算损失

代入 p=σ(z) 可化简为 `softplus(z)−yz`。稳定写法为：

```text
ℓ(z,y)=max(z,0)−yz+log(1+exp(−|z|))
```

它避免 `log(0)`，并让指数项始终不大于1。z=1000、y=0 时损失=1000；z=−1000、y=1 时也为1000，而不是 NaN。组合 Sigmoid 与 BCE 来获得稳定计算，是官方 [`BCEWithLogitsLoss`](https://docs.pytorch.org/docs/2.14/generated/torch.nn.BCEWithLogitsLoss.html) 所说明的处理方式；本章用 JavaScript 手写该数学关系，未依赖 PyTorch。

### 损失选择对照

| 目标 | 常见输出 | 损失例子 | 本章实现范围 |
|---|---|---|---|
| 连续数值回归 | 无界实数 | ½(ŷ−y)² | 用于解释，不作为 MLP 训练目标 |
| 两类互斥分类 | 单 logit→Sigmoid | 二元交叉熵 | 已实现，训练标签限0/1 |
| K类互斥分类 | K logits→Softmax | −log pᵧ | 下一步扩展，当前 MLP 不支持 |

Sigmoid 概率上也可定义平方误差，但链式求导会额外包含 `p(1−p)`，在错误且饱和的输出上梯度可能更弱。损失是对任务的建模选择，不能把损失小等同于所有真实照片都识别准确。

## 6. 反向传播：链式法则与路径累加

### 输出层导数从哪里来

对单样本，把 BCE 对 p 的导数与 Sigmoid 导数相乘：

```text
∂ℓ/∂p = −y/p + (1−y)/(1−p)
∂p/∂z = p(1−p)
∂ℓ/∂z = p−y
```

所以代码已经用 `p−y` 后，不能再乘一遍 Sigmoid 导数。对批次平均损失，本章在输出处一次性除以 N：`δᴸ=(p−y)/N`，后面不再平均。

### 从一层反传到上一层

令 δ⁽ˡ⁾=∂L/∂z⁽ˡ⁾，则：

```text
∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ (a⁽ˡ⁻¹⁾)ᵀ       [dₗ,1] × [1,dₗ₋₁]
∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾                    [dₗ]
δ⁽ˡ⁻¹⁾ = ((W⁽ˡ⁾)ᵀ δ⁽ˡ⁾) ⊙ f′(z⁽ˡ⁻¹⁾)
```

⊙ 表示逐元素乘。为什么有 W 的转置？第 i 个上层输入影响所有下层输出，需对 o 求和：`upstream[i]=Σₒ W[o,i]δ[o]`。为什么权重梯度是外积？因为 `z[o]` 对 `W[o,i]` 的局部导数就是 `a[i]`。

批次中的同一个参数参与每个样本的计算，所有样本的贡献也要累加。这既是链式法则，也是后续卷积“共享权重梯度要跨空间位置求和”的基础。

### 手算同一个 2→2→1 例子

```text
δ²=p−y=−0.4546891595
∂ℓ/∂W²=δ²[a¹₀,a¹₁]=[−0.2830255102,−0.2387023455]
∂ℓ/∂b²=−0.4546891595

δ¹₀=δ²×0.3×0.6224593312×(1−0.6224593312)=−0.0320560921
δ¹₁=δ²×(−0.2)×0.5249791875×(1−0.5249791875)=0.0226777164

∂ℓ/∂W¹=[−0.0320560921  −0.0641121842]
        [ 0.0226777164   0.0453554329]
∂ℓ/∂b¹=[−0.0320560921,0.0226777164]
```

请特别核对第二列梯度是第一列的两倍，因为 x₂=2、x₁=1。这是容易手工检查的外积关系。

### 从原理到代码

1. 前向缓存每层 z 与 a。
2. 为每层权重和偏置创建同形状的零梯度数组。
3. 对每个样本计算输出 δ=(p−y)/N。
4. 从最后一层往前，做 `gradW[o,i]+=δ[o]*aPrev[i]` 和 `gradB[o]+=δ[o]`。
5. 用当前 W 的转置乘 δ，再乘上一层的激活导数。
6. 所有样本算完后返回梯度，随后统一更新参数。

不要一边反传一边修改 W，否则前层 δ 使用的已不是此次前向的参数。`backward` 的测试会检查模型未变、重复批次的平均梯度不变，并对 Sigmoid/tanh/ReLU 的多隐藏层模型验证所有参数。

**局限：**反向传播算的是给定目标的导数，并不保证目标合适，也不保证梯度下降找到全局最优。本实现缓存和遍历方式为教学可读性设计，没有向量化/GPU加速。

## 7. 梯度下降：一次更新、学习率与初始化

### 为什么沿负梯度走

一阶近似 `L(θ+Δθ)≈L(θ)+∇LᵀΔθ`。取 `Δθ=−η∇L`，一阶变化为 `−η||∇L||²`。对于足够小的正 η，通常能下降；η 过大时一阶近似失效，不能保证损失减小。

```text
θ_new = θ_old − ηg
```

用上节梯度、η=0.1：

| 参数 | 更新前 | 梯度 | 更新后 |
|---|---:|---:|---:|
| W¹₀₀ | 0.1 | −0.0320560921 | 0.1032056092 |
| W¹₀₁ | 0.2 | −0.0641121842 | 0.2064112184 |
| W¹₁₀ | −0.1 | 0.0226777164 | −0.1022677716 |
| W¹₁₁ | 0.1 | 0.0453554329 | 0.0954644567 |
| b¹₀ | 0 | −0.0320560921 | 0.0032056092 |
| b¹₁ | 0 | 0.0226777164 | −0.0022677716 |
| W²₀ | 0.3 | −0.2830255102 | 0.3283025510 |
| W²₁ | −0.2 | −0.2387023455 | −0.1761297654 |
| b² | 0.1 | −0.4546891595 | 0.1454689160 |

全部更新后重新前向，单样本损失 `0.6063992975→0.5718183471`。不能拿部分新参数和部分旧参数做这个复算。

### 批量方式对照

| 方式 | 一次更新用多少样本 | 代价和特点 |
|---|---|---|
| 全量梯度下降 | 全部训练样本 | 目标确定，小数据易检查；大数据每步昂贵 |
| 随机梯度下降 | 1个 | 单步便宜，梯度噪声大 |
| 小批次 | B个 | 计算效率与噪声折中，框架训练常用 |

本章 XOR 只有4个样本，所以一轮 epoch 恰好就是一次全量更新。大数据训练中“一轮”和“一次更新”通常不是同一概念。这里不实现 Adam、动量、正则化或数据打乱。

### 为什么要随机初始化

若两个隐藏单元的入边权重、偏置相同，而且出边权重也保持交换这两个单元的对称性，它们会得到相同激活与梯度，更新后仍然相同，宽度优势消失。全网权重都初始化为0就是这种情况。仅入边相同并不足以推出梯度相同：反传还依赖出边权重。

例如输入x=1，两个Sigmoid隐藏单元的入边权重和偏置都为0，激活都为0.5；输出权重分别为1、2，输出偏置0，标签y=1。输出logit为1.5、δ=σ(1.5)−1≈−0.182426，两个隐藏权重梯度分别为 `δ×1×0.25≈−0.045606` 和 `δ×2×0.25≈−0.091213`，并不相同。随机权重可以打破网络的对称性；偏置可以初始化为0。

本章采用固定种子 LCG；非 ReLU 隐藏层和输出层使用 Xavier uniform：`W~U(−a,a)`，`a=√(6/(fanIn+fanOut))`。其方差 `a²/3=2/(fanIn+fanOut)` 控制跨层尺度。该思路见 [Glorot 与 Bengio 原论文](https://proceedings.mlr.press/v9/glorot10a.html)。ReLU 隐藏层使用 He uniform，`a=√(6/fanIn)`，方差为 `2/fanIn`，对应对整流激活的方差补偿，见 [He 等原论文](https://arxiv.org/abs/1502.01852)。

**参数影响：**相同种子和配置可复现实验；跨 JavaScript 引擎的超越函数可能有末位差异，因此报告用容差比较。初始化是起点而非正确答案，不保证任何种子、激活、学习率组合都同样收敛。

## 8. 真实实验：学会 XOR，以及学不会的对照

默认配置：种子42、2→4→1、tanh、学习率0.5、5000次全量更新，没有手工设置分类边界。

相同初始2→4→1/tanh模型的一次更新对照：

学习率10这一例实际升高了损失，说明“走负梯度”并不自动保证任意步长下降。

种子42、学习率0.5、1500次更新的结构/激活对照：

| 配置 | 最终损失 | 四点拟合率 |
|---|---:|---:|
| 2→1，无隐藏层 | 0.6931471806 | 75%（概率都约0.5，受末位影响） |
| 2→4→1，tanh | 0.0019283845 | 100% |
| 2→4→1，Sigmoid | 0.0378017964 | 100% |
| 2→4→1，ReLU | 0.4775243401 | 75% |

这是固定预算下的教学对照，不是激活函数普遍排名。ReLU采用对应的He初始化，初始化分布与其他配置不同；切换激活时同时采用匹配初始化，不能把变化全部归因于导数形式。

### 建议按顺序做的对照

1. 先检查梯度，展开任意一个权重的解析值和数值值。
2. 训练一次，核对当前损失与初始概率的变化。
3. 训练5000次，观察曲线与决策边界；点击停止后可继续。
4. 换成2→1并重置再训练。这个模型不能让四点同时正确；最终概率可能几乎都等于0.5，微小浮点差异会影响阈值准确率，应该连同损失和逐点概率一起看。
5. 保持种子、结构和训练次数，比较 Sigmoid/tanh/ReLU；再单独改变学习率，避免多个因素一起改变。
6. 把学习率设成非法数值，检查界面说明；Node 异常实验捕获空批次、错误维度等输入。

热图在四点之间显示的是模型的函数延拓，不是额外测试集。这里没有独立的泛化分数：四个真值点全部用于训练，100%表示成功拟合这个有限任务。真实手写字迹要按独立划分测量，不能把 XOR 成绩外推。

## 9. 共享接口与使用约定

```javascript
const { createMLP, forward, backward, applyGradients, train,
        evaluate, gradientCheck, xorSamples } = require('../shared/14-neural-network-basics');
const model = createMLP({ sizes: [2,4,1], activation: 'tanh', seed: 42 });
const samples = xorSamples();
const { gradients } = backward(model, samples);
applyGradients(model, gradients, 0.5);
console.log(forward(model, [0,1]).probability);
```

| 接口 | 返回/行为 |
|---|---|
| `createMLP(options)` | `{sizes,activation,seed,layers}`；层宽正整数，输出宽度固定1 |
| `forward(model,input)` | `{logit,probability,activations,preActivations}`；不修改输入/模型 |
| `backward(model,samples)` | `{loss,gradients}`；平均损失与各层同形状梯度 |
| `applyGradients(model,gradients,learningRate)` | **原地更新模型**；验证全部梯度后统一写回 |
| `train(model,samples,options)` | **原地训练**；返回模型、含epoch0的历史、最终损失/拟合率/预测 |
| `evaluate(model,samples)` | `{loss,accuracy,count,predictions}`；不隐含独立测试划分 |
| `gradientCheck(model,samples,options)` | 全参数逐项误差、最大误差、通过状态；在副本上扰动 |
| `cloneModel(model)` | 深复制参数数组，用于公平对照 |
| `traceExample()` | 固定手算案例的模型、缓存、梯度和一次更新 |
| `sigmoid/activate/activationDerivative` | 激活函数与导数，非有限值/未知激活报错 |
| `binaryCrossEntropyWithLogits(z,y)` | 稳定单样本损失，允许 y∈[0,1]；训练数据另限0/1 |
| `createRandom(seed)/xorSamples()` | 带种子的随机函数/新建四点数据 |

输入可使用普通数组或数值 TypedArray，模型与梯度使用 Float64Array。`samples` 必须是非空数组，每项 `{input,target}`。拒绝非有限值、维度不符、非法层宽、负训练次数、非正学习率。`train(...,{epochs:0})` 仅评估；`recordEvery` 是正整数。

有限差分不改变模型，训练和更新会改变模型。这一区别对于“相同初始化比较两个学习率”很关键，必须先复制模型，不能先训练A后拿已改变的权重作为B起点。

## 10. 与已有方法比较、常见误区与适用边界

| 方法 | 训练阶段 | 预测依据 | OCR 中主要代价 |
|---|---|---|---|
| 模板匹配 | 建模板库 | 与模板相似度 | 对字体/对齐变化敏感 |
| KNN | 保存特征样本 | 邻居投票 | 存储与查询依赖样本量 |
| MLP | 优化各层权重 | 学到的非线性映射 | 需标签、优化与独立评估 |
| CNN | 优化共享局部权重 | 分层空间特征 | 有空间先验，仍需匹配数据与预处理 |

常见错误及其可检查症状：

- **把反向传播叫“反着预测”**：反向计算损失的偏导，不会从标签重建输入。
- **输出层多乘一次 p(1−p)**：梯度数值检查失败，或错误饱和时训练异常慢。
- **按样本求和却把损失打印为均值**：批次复制后梯度翻倍；本章专门测试此项。
- **更新后再计算前层梯度**：梯度不再对应同一个 θ；缓存与更新分离可避免。
- **Sigmoid 隐藏激活等于输出概率**：只有最后的二分类解释是概率，隐藏单元没有这个标签语义。
- **损失下降就等于泛化提高**：训练目标下降只说明该批数据的目标变小。
- **数值检查通过就能生产部署**：检查只能验证局部数学实现，不能替代数据、任务和系统验证。

本模块只支持二分类、普通稠密层、全量梯度下降。没有批量矩阵内核、自动求导图、GPU、模型文件格式、正则化和大规模数据管道。它适合教学、排查公式和少量数值实验，不作为完整训练框架。

## 12. 分享重点与下一章

适合一节原理分享的演示顺序：先问“如何证明导数是对的”，展示数值检查；再手算一个神经元与一层外积；接着展示一轮更新前后损失；最后对比 XOR 的线性模型与隐藏层模型。

应让听众带走四个可以复述的结论：前向定义函数；损失定义学习目标；反向利用链式法则高效求全部导数；优化器根据导数更新参数。模型结构、目标、求导和更新是四件相关但不同的事。

下一章把稠密层的连接改成“局部连接+空间参数共享”，保留本章的前向、链式法则和梯度累加逻辑。这样能够解释 CNN 怎样处理字符图像，以及为什么 Sobel 图像梯度和训练参数梯度是不同概念。
